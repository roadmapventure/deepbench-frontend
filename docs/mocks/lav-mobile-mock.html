What changed vs. desktop

  • Canvas is the main window — it sits exactly where CHI mobile puts chat.
  • These are two VIEWS of one canvas, user-picked. Legend hard left, Active | Bench hard right, one row at the top of the canvas — the legend grows rightward into the middle as more edge meanings light up. Toggle matches the legend's height; a transparent ::after takes its touch box to ~36px so that costs nothing in tappability.
  • No Answer pill on the canvas — Answer is a tab and only a tab.
  • Bench is the default, and shows only the agents this run actually called. Empty slots stay empty; the gap is the information.
  • Every agent has a permanent slot, derived from its index in the mi roster — never from the order it was engaged. Same agent, same place, every run. This mirrors homeLayout()'s existing rule (AgentNetwork.jsx L281: computed from roster order, no hand-authored position table, no hand-listed agent id), so a 12th agent added to the bench group claims the next slot with no code change.
  • Active view — the current hand-off at full card size (name, role, model tag, pattern pill all legible).
  • Auto-switch on orchestration is dropped — Bench being the default already covers it, and a view that reassigns itself mid-read is worse than one that doesn't. The toggle is the only thing that moves the view.
  • Dropdown arrow — tokens.js L78 already gives every <select> a chevron; the app's inline background shorthand wipes it. Mock uses background-color, which keeps it.
  • Suppressed: subtitle, Choreographed/Static toggle, prompt-box overlay, 2 of 4 meters, agent task text in the feed (terse:true, CHI-88's locked call).
  • Moved: Harness Trace console + waterfall + assembled prompt → the Harness Trace › full-screen overlay, mirroring CHI's Agent & Data Info ›.
