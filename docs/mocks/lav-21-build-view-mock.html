Decided — John, 2026-08-04

  • Answer drawer renamed Deliverable (its behavior otherwise untouched).
  • New drawer named Assembly, header idiom Assembly · N stages.
  • Newest on top, oldest at bottom — the feed's own order.
  • Open by default; body fills to the harness trace console's top edge; gradient fade + thin scrollbar; scroll pinned to top so the latest event always shows.
  • Run-start narration: the drawer is never blank during a live run — “Assembly under way…” chrome in the sub-second before the first frame, then Evidence fills with the same frame that lights Eleanor on the canvas, so the drawer explains her while the status explains Marcus.
  • Question picker numbered 1–3 (index-derived from the picker's own list, both desktop and mobile call sites) so questions can be referenced by number. Not shown in these frames — the picker lives in the title bar, not this column.

Flagged call: the terminal “build complete” line caps the stack at the top — it is the newest thing. Say the word to move it.

What derives each part no invention

  • Stage — the hop's declared work (the existing RUN_TASK_KIND derivation, extended) + span parentage. Never the agent's identity.
  • Evidence — fetch events: source + chunk count.
  • Draft — qa_answer: citation count + confidence tier.
  • Verification — the gate's verdict + verbatim critique (already streams). A guardrail block renders as its own honest stage state.
  • Final form — display_format: real headline + key-data-point count.
  • A field that didn't stream → its line is omitted, never filled in (§19j). No per-criterion scores anywhere — sealed non-derivable (§19q).
