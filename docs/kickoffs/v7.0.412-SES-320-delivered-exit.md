## 2. CONTEXT

**Measured at the M7 gate, 2026-09-02.** `public.ladder_work_class()` returns NULL for P1, P3 and P4, so `class_autonomy()` never grants auto-done to those classes, and a class below `auto_done_rung` (bug_fix at 1, enhancement at 1, invention at 0) ships `delivered`. `public.sweep_decision_windows()` finalises a `kind='ship'` decision past its 72-hour window and **never touches `backlog_items`**. So a delivered ticket has no exit since `SES-285` retired the Accept tap. Sixteen general-board rows sit at `delivered` today.

**Decided (M7 gate, ruling iv):** the finalisation of a ship decision IS the exit. When the sweep finalises a `kind='ship'` decision whose ticket is still `delivered`, the sweep writes `done` on that ticket, any class, any epic. `M5-14`'s timing is preserved: `original`/`gate-review` work may still auto-done at ship via the rung; everything else reaches `done` through a verdict plus John's window, never his tap. The attended path (session-setup 3e: a block writes `delivered`) is untouched — a block records no ship decision, so nothing finalises.

**The legacy rows.** The 16 delivered rows predate `record_ship_decision()` (`v7.0.395`) and carry no ship decision. Ten have a `shipped` `runner_cycles` row with a `push_sha`; six (`LOG-41`, `SES-131`, `SES-165`, `SES-166`, `SES-222`, `SES-275`) do not. Disposition: one attended decision (kind `ship-backfill`) writes `done` on every delivered row whose ticket id appears in an `origin/dev` commit subject older than 72 hours (`git log origin/dev --grep=<ID> --format=%H --before='72 hours ago'`); a row with no such commit is left `delivered` and named in the decision's reasoning as needing its own look. Before-image per row; John's one Reverse undoes the batch.

## 6. DESIGN RULES

- **The finalisation is the exit; nothing else writes `done` for a delivered ticket.** No new status, no new column.
- **The close joins the ship decision's undo set** — one Reverse, one restore, never two decisions for one delivery.
- **A block never finalises** because it never records a ship decision; the attended block-writes-delivered path is untouched.
- **Backfill only on git evidence**, never on a status alone.
