**4b. Pinned decision footer.** Root cause (measured live this session): `MobileBody`'s steps-tab wrapper (~3288) is `{flex:1,minHeight:0,overflowY:"auto",padding:14}` — an auto-scroll parent gives children unbounded height, so `EvidenceColumn`'s whole flex column inflated to 2,236px inside a 210px scroller and its own CHI-13/CHI-18 scroll-body + pinned-footer anatomy never engages (footer parked mid-document, ~3 window-heights deep). Fix: change that wrapper to `{flex:1,minHeight:0,overflow:"hidden",padding:14,display:"flex",flexDirection:"column"}`. Nothing inside `EvidenceColumn` changes — the desktop-proven internal scroll region (`evidenceScrollRef`, MI-54) and pinned footer slot (~2419) simply activate on mobile too. Do NOT build a parallel footer mechanism.

**4c. Read more touch target** (~2687–2692, the one shared button in `RoutingActivityLine`): gate on `useIsMobile()`; on mobile, style adds `padding:"11px 14px 11px 0"` and `margin:"-9px 0 -9px"` (visual position identical, hit box grows 13px → ~35px tall). Desktop style byte-identical to today.
