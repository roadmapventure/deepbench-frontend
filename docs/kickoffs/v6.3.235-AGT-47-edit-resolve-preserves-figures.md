### Why `S-AGT-47`'s shipped fix didn't close the row

Case 6 (`upgrade-cycles`) is hardcoded to the `edit` resolution (`CASE_RESOLUTIONS`,
`chi-true-regression.mjs:153`) — the regression's own beta-gate criterion is measured against the
**edit-resolve** artifact, never the first patch draft. On that path, both the screen and the
driver build `edited_task_context` from the reviewer's edited text **alone**:

```js
// MarketIntelligenceScreen.jsx:4339-4340, today
const edited_task_context = resolution === "edit"
  ? { disputed_chunk_id, correction: editedText, user_reasoning: editedText }
  : null;
```

`user_reasoning` never carries the original theory-test figures on this branch — there's nothing
for `S-AGT-47`'s (correctly working) instruction to carry forward, because Nadia never receives
the figures on this call. Confirmed live 2026-07-30 by the coding session: the fixed instruction
performs perfectly when it's given the figures (decoy-market test, all four figures preserved
verbatim); the edit-resolve regression run still fails, because its input never has them.
