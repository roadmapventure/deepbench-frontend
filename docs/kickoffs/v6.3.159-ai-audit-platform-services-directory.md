- Fetch `platform_services` once per page load (module-level cache, same shape as `usePatternVocabulary`'s), ordered by `sort_order`.
- New matcher `platformServiceForRow(entry)`: evaluate **feature-key matches before ai_type-only matches** (§19m — e.g. `feature: web-memory` beats `ai_type: reinforcement`; feature compared against `split(':')[0]` head). Match against each service's `match_keys`.
