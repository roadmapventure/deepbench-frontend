## 2. CONTEXT

Evidence panel's hypothesis-flow stage copy misattributes Data Room usage, confirmed against the real `skill_profiles` content (not just the code comment):

- **`hyp-generation-intent`** (the "generating" stage): its real `method` grounds hypotheses in what the Data Room "**could plausibly show**" — there is no mandated fresh query at this stage. Current copy ("Priya is generating theories **from the Data Room**") overstates it as an active lookup.
- **`hyp-hypothesis-test-intent`** (the "testing" stage): its real `method` explicitly instructs "**Query the Data Room fresh** against the hypothesis text itself." This is the stage that actually queries the Data Room — but its current copy ("Priya is testing this theory against **the evidence**") never mentions the Data Room at all.

The labeling reads backwards from what each stage actually does. Design call made with John (2026-07-14): **copy-only reword**, not a change to `hyp-generation-intent`'s actual method/behavior (that's a separate, bigger, not-yet-scoped option — tightening real hypothesis-grounding behavior deserves its own session and eval, not a rider on a copy-accuracy fix).
