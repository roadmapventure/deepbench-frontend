  in `lib/activity-log.js` changes.
- The read-time guard: extend the existing `paired.has(row.id) ? 0 : (…)` shape at
  `useAIActivity.js:262` and `:1164` to `(paired.has(row.id) || row.call_source === 'session') ? 0 : (…)`.
  `call_source` is already in the `.select()` at line 1127 — no query change.
- The one wall expression: `select coalesce(sum(cost_usd),0) from ai_activity_log where created_at

  `call_source` filter** — non-billable rows carry NULL and NULL adds nothing, which is what makes
  this one number rather than two filters kept in step.
