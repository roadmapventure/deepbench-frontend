**Decided at the gate (M6-01):** (1) a `BEFORE UPDATE` trigger on `backlog_items` refuses `status = 'done'` for a Selfbuild-epic ticket with no `runner_verdicts` row for its `backlog_id` — fail closed; (2) the attended close-out gains the verifier step; (3) `CLAUDE-DESIGN.md` 5c cites it.

**The exemptions, and why each is data in the trigger rather than prose:**
- **A Reverse restore.** `apply_data_restore()` re-inserts a prior row state through `jsonb_populate_record` — a `DELETE` + `INSERT`, not an `UPDATE`, so a `BEFORE UPDATE` trigger never sees it. State this in the trigger comment; add no code for it. **Verify by reading the function body, not by assuming.**
- **Non-Selfbuild epics.** The P1–P10 board is outside the bar until the ladder widens it (`SES-122`); the trigger tests `epics.name ILIKE 'Selfbuild%'` through `epic_id`.
- **A ticket whose verdict predates its claim** is still a verdict: the check is existence of a row for the `backlog_id`, not recency. Recency is the ladder's concern (`SES-122`), not the gate's.
- **`removed`, `partial`, `delivered`** are not `done` and pass through untouched. A ticket that goes `delivered` and is later flipped `done` by a harvest is refused if it has no verdict — that is the correct direction: the harvest should not confer completion on an ungraded ship either.

### Task 1 — Migration `ses311_done_requires_verdict` (over the Supabase MCP; if unavailable, STOP and report the SQL)

```sql
CREATE OR REPLACE FUNCTION public.backlog_done_requires_verdict() RETURNS trigger LANGUAGE plpgsql AS $$
DECLARE v_selfbuild boolean; v_has_verdict boolean;
BEGIN
  IF NEW.status = 'done' AND COALESCE(OLD.status, '') <> 'done' THEN
    SELECT EXISTS (SELECT 1 FROM public.epics e WHERE e.id = NEW.epic_id AND e.name ILIKE 'Selfbuild%') INTO v_selfbuild;
    IF v_selfbuild THEN
      SELECT EXISTS (SELECT 1 FROM public.runner_verdicts v WHERE v.backlog_id = NEW.backlog_id) INTO v_has_verdict;
      IF NOT v_has_verdict THEN
        RAISE EXCEPTION USING ERRCODE = 'check_violation',
          MESSAGE = format('SES-311: %s cannot be written done — no runner_verdicts row exists for it. Run scripts/verifier.js --cycle-id=<supervised cycle> --ticket=%s first (docs/runbooks/session-setup.md step 3e).', NEW.backlog_id, NEW.backlog_id);
      END IF;
    END IF;
  END IF;
  RETURN NEW;
END $$;
CREATE TRIGGER backlog_done_requires_verdict BEFORE UPDATE OF status ON public.backlog_items
  FOR EACH ROW EXECUTE FUNCTION public.backlog_done_requires_verdict();
```
