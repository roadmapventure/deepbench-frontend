## The one that would have shipped wrong

**A straight `gist` → `title` swap.** It reads as the whole of part (a), it passes any check that
merely asks "does the Title column come from `title` now?", and it renders `` `Post-beta` `` as the
title of **44 tickets — two of them in §8's live top 12 right now.** For those rows it is strictly
*worse* than what the page does today.

The correct shape is therefore a **fallback, not a swap**: prefer the stored title; fall back to the
`gist` when the stored title is a marker rather than a title. And — the eighth precedent on this
platform (`SES-86` phase 3, `v7.0.146`, `SES-101`, `SES-111`, `SES-127`, `SES-128`, `SES-129`,
`SES-143`) — **that rule goes in SQL, not in a comment every future cycle re-derives.**

The rejected alternative is a length heuristic ("title under N characters is unusable"). It silently
reclassifies rows as titles are edited, and it is wrong on real data: `Landing screen` (14 chars) is
a terse title, not a marker. The shipped predicate matches the **closed, measured class** of retired
declaration vocabulary — the same `Beta-gate` / `Post-beta` vocabulary step 8c already sweeps as a
retired-premise signal — and nothing else.
