## 1. CONTEXT

**Two small, related chat-bubble fixes found live 2026-07-07 during John's own UX test of the Market Intelligence screen** (same test that also surfaced `AA-142`, deliberately *not* bundled here — that's a behavior/root-cause investigation, this is pure UI).

**MI-27 — Submitted Hypothesis card has zero attribution.** The `hyp_submitted` card (`MessageBubble`, `MarketIntelligenceScreen.jsx` ~line 452) renders the human's own hypothesis text (from `EvidenceColumn`'s "Use this hypothesis" action) with an intent badge (Theory/Forecast/Correct) but never says who submitted it. Every other card on this screen names an actor. **Resolved with John via a live HTML mock, Option A approved:** a small "You" byline row — a generic navy circle with a simple person silhouette (deliberately *not* an `AgentAvatar` — the human isn't an agent, no invented persona) + "Submitted by" + "You", same visual row shape as the existing "Formatted by [Agent]" byline already used on the `qa`/`hypothesis_test` cards.

**MI-28 — AI card header order inconsistent between the two AI-generated card types.** The Q&A card (`msg.kind === "qa"`, line 516) reads `Marcus Webb · Channel Intelligence` — actor first. The Hypothesis Test card (`msg.kind === "hypothesis_test"`, line 477) reads `AI - Hypothesis Test · Priya Nair` — label first, actor last. John's direct feedback: a chat header should read `<actor> <subject>`, name first, so it reads like a real chat participant. Fix: swap the hypothesis-test header string to match the Q&A card's existing order exactly.

**Why bundled together, not with `AA-142`:** both are isolated, single-file-region UI changes with no behavior/logic risk — fits comfortably inside the 3-file/4-task session limit. `AA-142` is an unscoped root-cause investigation into agent behavior (may touch Supabase Skill Profile text and/or `execute.js`) — bundling an open-ended investigation with a done-in-one-sitting UI fix would risk both blowing the task/file limit and mixing an uncertain-scope fix with a certain one, against Root Cause Analysis discipline (never bundle a diagnosis-in-progress with a scoped fix).

## 5. DESIGN RULES

- `UserAvatar` is a plain navy circle + simple person silhouette, never an illustrated `AgentAvatar` portrait — approved by John via live HTML mock (Option A), the deliberate point being instant visual distinction from every agent avatar, not a matching style.
- Attribution row shape/spacing/typography is a direct reuse of the existing "Formatted by [Agent]" byline row (same flex/gap/font-size/color values) — a consistency requirement per this screen's existing pattern, not a new visual language.
- Header order for both AI-generated card types (`qa`, `hypothesis_test`) is now locked as `<Agent Name> · <Capability/Label>` — actor first. Any future AI-card header on this screen should follow this order, not the old label-first shape.

**Style Guide update required at close-out:** add a short note to `STYLE-GUIDE.md` locking (a) the actor-first AI-card header order convention, and (b) `UserAvatar` as the canonical "human/non-agent attribution" component, distinct from `AgentAvatar` and outside Section 17's agent-only scope.
