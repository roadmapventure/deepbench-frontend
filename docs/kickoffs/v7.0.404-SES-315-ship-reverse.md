## 2. CONTEXT

**Measured by the M6 milestone gate review, both lenses.** A ship's close-out (`runner-cycle.md` step 7) writes `done` on an approve + eligible verdict and records **no decision**; 7b says a ship's Reverse "lives on the ship card" — and the card's tap is the surface `SES-285` retired. So a shipped change has no live Reverse. Since `reverse_decision()` is the only demote, **a bad ship can never demote the ladder**: the charter's safety measure ("a Reverse spike auto-narrows the ladder — autonomy is elastic, never ratcheted") has no live input for shipped work. `apply_ladder_decision()` still promotes on a ship-card Accept (step 2 and the step-9 tail still instruct the call; dormant since 2026-08-30, live). `apply_data_restore()` restores rows by DELETE + INSERT and raises `23503` on any `backlog_items` row another ticket is `blocked_by` (the ses-286a fixture found it). Four runbook passages still state withdrawn rules in live voice.

**Decided (M6-01):** the ship's close-out records a decision, and that decision is the ship's Reverse.
