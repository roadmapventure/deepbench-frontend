## 2. CONTEXT

John's decision (2026-07-28, design session, three explicit confirmations): **every counting surface on the AI Audit screen counts real model calls only.** A "countable call" is a log row that (a) names a model and (b) is not the duplicate `agent-turn` half of an AI-51 pair (one real call logged twice when a turn is terminal: `agent-turn` row + `request-receivable` capability-wrapper row).

Measured live 2026-07-28 (will have grown by coding time — do not hardcode these as assertions):
- `ai_activity_log` total: **24,819** rows
- No-model rows (deterministic ops, in the log by design per ARCHITECTURE.md §12): **4,247** (`librarian` 2,409, `agent-directory` 1,745, `librarian-write` 85, misc 8)
- `agent-turn` halves marked duplicate by the shipped AI-51 rule (same agent, wrapper `feature==='request-receivable'`, |Δt| < `PAIR_WINDOW_MS`=2000): **5,175** — of which **1,986 are classified in `ai_call_patterns`**, so today's By Pattern *classified* counts double-count those calls
- Countable model calls: **~15,400**

What stays intentionally unchanged (John's flags, approved):
- **By Service counts stay operations-based** (§12 LOCKED: deterministic services are productized usage) — `byService`, `servicesSorted`, `servicesActive`, `platformServices` untouched.
- **Total Cost** — already correct (AI-51 zeroes the duplicate half's cost at hydrate).
- **No tile label changes.** "Total Calls" keeps its exact label. No sub-labels added.
- The **2,571 model rows with empty `call_facts`** remain inside "not yet classified" — that number is John's backfill to-do list (`LOG-42`'s thread); never special-case them.

2. New exported predicate, defined once, directly below `pairedAgentTurnIds()`:
   ```js
   // FEATURE: LOG-81 -- the one definition of a countable call for every AI Audit count
   // (header Total Calls, By Agent, By LLM, By Pattern denominators). A countable call names a
   // model and is not the duplicate agent-turn half of an AI-51 pair. By Service deliberately
   ```

3. `byAgent[agentId].calls`: replace `d.calls` with a countable count. Before the `byAgent` construction loop:
   ```js
   // FEATURE: LOG-81 -- calls = countable model calls; cost/avgLatency semantics unchanged.
   // Counted here, NOT inside buildActivitySummary() (shared with useAgents.js / CHI drawer).
   const countableCallsByAgent = {};
   for (const e of log) {
     if (!e.agentId || !isCountableCall(e)) continue;
   ```

4. `modelsInUse` needs no edit (derives from gated `byLLM`).

### Task 3 — derive the By Pattern counts client-side (`src/hooks/useAIActivity.js`, `usePatternClassification(log)`)

Mirror the LOG-97 `costBySlug` mechanism (same hook, same fallback philosophy — per-source, never all-or-nothing):

1. Memo `countableIds`: `new Set(log.filter(isCountableCall).map(e => e.id))` (empty log → empty set).
2. Classified rows: derive each pattern's displayed `total` as `r.logIds.filter(id => countableIds.has(id)).length` **when** `log.length > 0 && r.logIds.length > 0`; otherwise fall back to the view's `call_count` (exactly today's number). Return this as the row's `total` so `AIActivityPanel.jsx` needs no count logic of its own.
3. `reclassificationCount`: when `log.length > 0`, derive as
   ```js
   countableTotal - distinctClassifiedCountable
   ```
   where `countableTotal = countableIds.size` and `distinctClassifiedCountable` = size of the Set union of all classified rows' `logIds` filtered to `countableIds` (a row can carry multiple patterns — union, never sum, or overlapping ids double-subtract). When the log is empty/not hydrated, fall back to the view's `reclassification_count`.
4. Invariant that must hold by construction and is asserted in QA: derived classified totals' distinct-id count + derived `reclassificationCount` = `totalCalls`.

```js
// test-log-81.mjs -- LOG-81 model-call counting (v6.3.203). Run from worktree root: node test-log-81.mjs
import { readFileSync } from 'node:fs';

let pass = 0, fail = 0;
const t = (name, cond) => { if (cond) { pass++; } else { fail++; console.error('FAIL: ' + name); } };

// --- B. predicate semantics (spec fixtures; real implementation asserted by wiring tests below)
const isCountableCall = e => !!e.model && !e.isPairedDup;
t('model call counts',            isCountableCall({ model: 'claude-haiku-4-5-20251001', isPairedDup: false }) === true);
t('live logAICall entry counts',  isCountableCall({ model: 'claude-haiku-4-5-20251001' }) === true);
t('null model excluded',          isCountableCall({ model: null,  isPairedDup: false }) === false);
t('empty model excluded',         isCountableCall({ model: '',    isPairedDup: false }) === false);
t('paired dup excluded',          isCountableCall({ model: 'claude-haiku-4-5-20251001', isPairedDup: true }) === false);

// --- B. By Pattern derivation semantics
const countable = new Set([1, 2, 3, 5]);
const deriveTotal = (logIds, callCount, logLen) =>
  (logLen > 0 && logIds.length > 0) ? logIds.filter(id => countable.has(id)).length : callCount;
t('classified total filters to countable', deriveTotal([1, 2, 9], 3, 10) === 2);
t('empty logIds falls back to view count', deriveTotal([], 7, 10) === 7);
t('empty log falls back to view count',    deriveTotal([1, 2], 7, 0) === 7);

const deriveReclass = (rows, countableIds, viewCount, logLen) => {
  if (logLen === 0) return viewCount;
  const union = new Set();
  for (const r of rows) for (const id of r.logIds) if (countableIds.has(id)) union.add(id);
  return countableIds.size - union.size;
};
t('reclass = countable minus distinct classified countable',
  deriveReclass([{ logIds: [1, 2] }, { logIds: [2, 3] }], countable, 99, 10) === 1); // union {1,2,3}, 4-3=1
t('multi-pattern ids never double-subtract',
  deriveReclass([{ logIds: [1] }, { logIds: [1] }], countable, 99, 10) === 3);
t('unhydrated log falls back to view count',
  deriveReclass([{ logIds: [1] }], countable, 99, 0) === 99);
t('invariant: classified-countable + reclass === countable total', (() => {
  const rows = [{ logIds: [1, 9] }, { logIds: [2, 1] }];
  const cls = new Set(); rows.forEach(r => r.logIds.forEach(id => { if (countable.has(id)) cls.add(id); }));
  return cls.size + deriveReclass(rows, countable, 0, 10) === countable.size;
})());

// --- M-lite. wiring: one definition, gated call sites (source-text assertions on the real files)
```
