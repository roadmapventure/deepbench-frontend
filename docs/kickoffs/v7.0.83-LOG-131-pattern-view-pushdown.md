## 2. CONTEXT

**Use case broken today:** opening the Agent Routing drawer on the CHI screen fires
`tracePatterns.js`'s query — `ai_call_patterns?ai_activity_log_id=in.(…11 ids…)` — and the view
recomputes §19k signature assembly + pattern matching for **all ~33,900 `ai_activity_log` rows**
before filtering to the 11 requested, because its CTEs are declared `AS MATERIALIZED` (a per-query
planner fence blocking predicate pushdown). Measured: 757 ms warm as admin; the browser runs as
`anon` (`statement_timeout=3s`), so under concurrent drawer fetches / cold cache it crosses 3 s →
Postgres 57014 → HTTP 500 → pattern lines silently vanish (John observed live 2026-08-10, two
500s in the console). Beta-gate (bucket 5): "Agent Routing drawer works well, accurate" + the
open-devtools-console bar.

**Fix (approved by John in the design walkthrough):** restructure the read path so an ID-filtered
query computes only the requested rows. Measured on the exact failing 11 IDs: **57 ms, identical
9 result rows.** Three parts, all Supabase DDL, **zero frontend changes**:

1. Factor the §19k signature-assembly expression into one shared SQL function
   `log_row_signature(ai_activity_log)` — single-sourced, used by every view below.
2. Redefine `ai_call_patterns` as a per-row LATERAL over `ai_activity_log` — the ID filter pushes
   down to the pkey index.
3. Redefine the two dependent rollup views (`ai_pattern_classification_rollup`,
   `ai_pattern_reclassification_count`) to carry the distinct-signature dedup **internally**
   (today they inherit it from `ai_call_patterns`). This preserves `LOG-99`-done's rollup fix:
   aggregates still match per **distinct** signature (~2.3k), never per row (~33.9k ×7 ≈ 5–6 s,
   which would blow the cap right back).

**Invariants that must hold (§19k / `.claude/rules/ai-pattern-signature.md`):** everything stays
**plain views** (never materialized — live, self-cleansing, criteria edits retroactive), one
generic matcher (`pattern_criteria_matches`, untouched), no per-pattern code, no stored names,
`LEFT-JOIN`-style honesty unchanged (unclassified rows simply match nothing).

**Secondary ID this session settles:** `LOG-101` (Observability) — its rollup-timeout symptom was
likely fixed by `LOG-99`-done; its proposed restructure ("build the signature once per row,
LATERAL") is what this session ships properly. Its closure gates are Manual QA items 6–7 below;
the parent design session archives it only if those pass.

**Deliberately out of scope:** `SES-44` (cardinality guard — this change doesn't alter signature
cardinality), doc sync of §19k / the rules file (parent design session does that at close-out).

### Task 1 — Migration part 1: the shared signature function

Apply via `apply_migration` (name: `log131_log_row_signature_fn`):

```sql
CREATE OR REPLACE FUNCTION public.log_row_signature(l public.ai_activity_log)
RETURNS jsonb
LANGUAGE sql
STABLE
AS $$
  SELECT ((((COALESCE(l.call_facts, '{}'::jsonb) || jsonb_build_object('model_modality',
      CASE
          WHEN l.model IS NULL THEN 'none'::text
          WHEN l.model LIKE 'text-embedding-%' THEN 'embedding'::text
          ELSE 'generative'::text
      END)) ||
      CASE
          WHEN l.feature ~ '^[^:]+:[^:]+:depth[0-9]+$'::text
          THEN jsonb_build_object('intent', split_part(l.feature, ':'::text, 2))
          ELSE '{}'::jsonb
      END) ||
      CASE
          WHEN l.parent_span_id IS NOT NULL
               OR (l.span_id IS NOT NULL AND EXISTS (
                     SELECT 1 FROM public.ai_activity_log c
                     WHERE c.parent_span_id = l.span_id))
          THEN jsonb_build_object('sub_calls_chained', true)
          ELSE '{}'::jsonb
      END) ||
      CASE
          WHEN l.span_id IS NOT NULL
          THEN jsonb_build_object('integration_followed', EXISTS (
                 SELECT 1 FROM public.ai_activity_log t
                 WHERE t.span_id = l.span_id
                   AND (t.created_at > l.created_at
                        OR (t.created_at = l.created_at AND t.id > l.id))
                   AND ((t.call_facts ->> 'input_references_other_deliverable')::boolean) IS TRUE))
          ELSE '{}'::jsonb
      END) ||
      CASE
          WHEN ((l.call_facts -> 'delegation_target') ->> 'agent_id') IS NOT NULL
           AND ((l.call_facts -> 'delegation_target') ->> 'capability_slug') IS NOT NULL
           AND ((l.call_facts -> 'task_provenance') ->> 'agent_id') IS NOT NULL
           AND ((l.call_facts -> 'task_provenance') ->> 'capability_slug') IS NOT NULL
          THEN jsonb_build_object('delegated_to_provenance',
               ((l.call_facts -> 'delegation_target') ->> 'agent_id')
                 = ((l.call_facts -> 'task_provenance') ->> 'agent_id')
               AND ((l.call_facts -> 'delegation_target') ->> 'capability_slug')
                 = ((l.call_facts -> 'task_provenance') ->> 'capability_slug'))
          ELSE '{}'::jsonb
      END
$$;

GRANT EXECUTE ON FUNCTION public.log_row_signature(public.ai_activity_log)
  TO anon, authenticated, service_role;
```

This expression is transcribed from `pg_get_viewdef('ai_call_patterns')` verbatim (the
`OR … AND` precedence in the `sub_calls_chained` branch is parenthesized to the identical
meaning — AND binds tighter). Do not "improve" it.

```sql
-- Probe A: per-row shape ≡ current view (pair-level, full log)
WITH new_shape AS (
  SELECT l.id AS ai_activity_log_id, pv.pattern_slug
  FROM public.ai_activity_log l
  JOIN public.pattern_vocabulary pv
    ON pv.criteria IS NOT NULL AND pv.superseded_by IS NULL
   AND public.pattern_criteria_matches(public.log_row_signature(l), pv.criteria)
)
SELECT
  (SELECT count(*) FROM (SELECT ai_activity_log_id, pattern_slug FROM new_shape
    EXCEPT SELECT ai_activity_log_id, pattern_slug FROM public.ai_call_patterns) x) AS new_not_old,
  (SELECT count(*) FROM (SELECT ai_activity_log_id, pattern_slug FROM public.ai_call_patterns
    EXCEPT SELECT ai_activity_log_id, pattern_slug FROM new_shape) y) AS old_not_new;
```

```sql
-- Probe B: rollup equality per pattern (call_count, cost_sum, sorted log_ids)
WITH sig AS MATERIALIZED (
  SELECT l.id, l.cost_usd, public.log_row_signature(l) AS signature
  FROM public.ai_activity_log l
), uniq AS MATERIALIZED (SELECT DISTINCT signature FROM sig),
matched AS MATERIALIZED (
  SELECT u.signature, pv.pattern_slug
  FROM uniq u JOIN public.pattern_vocabulary pv
    ON pv.criteria IS NOT NULL AND pv.superseded_by IS NULL
   AND public.pattern_criteria_matches(u.signature, pv.criteria)
), new_rollup AS (
  SELECT m.pattern_slug, count(*)::integer AS call_count,
         COALESCE(sum(s.cost_usd),0::numeric) AS cost_sum,
         (SELECT array_agg(x ORDER BY x) FROM unnest(array_agg(s.id)) x) AS log_ids_sorted
  FROM sig s JOIN matched m ON m.signature = s.signature
  GROUP BY m.pattern_slug
), old_rollup AS (
  SELECT pattern_slug, call_count, cost_sum,
         (SELECT array_agg(x ORDER BY x) FROM unnest(log_ids) x) AS log_ids_sorted
  FROM public.ai_pattern_classification_rollup
)
SELECT
  (SELECT count(*) FROM (SELECT * FROM new_rollup EXCEPT SELECT * FROM old_rollup) a) AS new_not_old,
  (SELECT count(*) FROM (SELECT * FROM old_rollup EXCEPT SELECT * FROM new_rollup) b) AS old_not_new;
```

```sql
-- Probe C: reclassification count equality
WITH sig AS MATERIALIZED (
  SELECT l.id, public.log_row_signature(l) AS signature FROM public.ai_activity_log l
), uniq AS MATERIALIZED (SELECT DISTINCT signature FROM sig),
unmatched AS MATERIALIZED (
  SELECT u.signature FROM uniq u
  WHERE NOT EXISTS (
    SELECT 1 FROM public.pattern_vocabulary pv
    WHERE pv.criteria IS NOT NULL AND pv.superseded_by IS NULL
      AND public.pattern_criteria_matches(u.signature, pv.criteria))
)
SELECT
  (SELECT count(*) FROM sig s JOIN unmatched um ON um.signature = s.signature) AS new_count,
  (SELECT reclassification_count FROM public.ai_pattern_reclassification_count) AS old_count;
```

### Task 3 — Migration part 2: the three view redefinitions (one migration)

Only after Task 2 passes. Apply via `apply_migration` (name: `log131_pattern_views_pushdown`).
Column lists/names/types/order are byte-identical to the current views — `CREATE OR REPLACE VIEW`
requires it and the dependent-view chain relies on it. Grants carry over on replace; do not
touch them.

```sql
-- Rollups first: they must stop depending on ai_call_patterns' deduped body
-- before ai_call_patterns goes per-row.
CREATE OR REPLACE VIEW public.ai_pattern_classification_rollup AS
WITH sig AS MATERIALIZED (
  SELECT l.id, l.cost_usd, public.log_row_signature(l) AS signature
  FROM public.ai_activity_log l
), uniq AS MATERIALIZED (
  SELECT DISTINCT signature FROM sig
), matched AS MATERIALIZED (
  SELECT u.signature, pv.pattern_slug, pv.name AS pattern_name,
         pv.description AS pattern_description
  FROM uniq u
  JOIN public.pattern_vocabulary pv
    ON pv.criteria IS NOT NULL AND pv.superseded_by IS NULL
   AND public.pattern_criteria_matches(u.signature, pv.criteria)
)
SELECT m.pattern_slug,
       m.pattern_name,
       m.pattern_description,
       count(*)::integer AS call_count,
       COALESCE(sum(s.cost_usd), 0::numeric) AS cost_sum,
       array_agg(s.id) AS log_ids
FROM sig s
JOIN matched m ON m.signature = s.signature
GROUP BY m.pattern_slug, m.pattern_name, m.pattern_description
ORDER BY (count(*)::integer) DESC;

CREATE OR REPLACE VIEW public.ai_pattern_reclassification_count AS
WITH sig AS MATERIALIZED (
  SELECT l.id, public.log_row_signature(l) AS signature
  FROM public.ai_activity_log l
), uniq AS MATERIALIZED (
  SELECT DISTINCT signature FROM sig
), unmatched AS MATERIALIZED (
  SELECT u.signature FROM uniq u
  WHERE NOT EXISTS (
    SELECT 1 FROM public.pattern_vocabulary pv
    WHERE pv.criteria IS NOT NULL AND pv.superseded_by IS NULL
      AND public.pattern_criteria_matches(u.signature, pv.criteria))
)
SELECT count(*)::integer AS reclassification_count
FROM sig s
JOIN unmatched um ON um.signature = s.signature;

-- The point-lookup view: per-row LATERAL, ID filter pushes to the pkey index.
CREATE OR REPLACE VIEW public.ai_call_patterns AS
SELECT l.id AS ai_activity_log_id,
       l.created_at,
       l.cost_usd,
       pv.pattern_slug,
       pv.name AS pattern_name,
       pv.description AS pattern_description
FROM public.ai_activity_log l
CROSS JOIN LATERAL (SELECT public.log_row_signature(l) AS signature) s
JOIN public.pattern_vocabulary pv
  ON pv.criteria IS NOT NULL AND pv.superseded_by IS NULL
 AND public.pattern_criteria_matches(s.signature, pv.criteria);
```

```js
// test-S-LOG-131.mjs — anon-parity timing + shape checks for the pattern read path.
// PASS bar: every request 200 within budget; trace query returns >0 pattern rows.
const URL_BASE = process.env.VITE_SUPABASE_URL;
const ANON = process.env.VITE_SUPABASE_ANON_KEY;
if (!URL_BASE || !ANON) { console.error('FAIL: missing VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY in .env.local'); process.exit(1); }
const H = { apikey: ANON, Authorization: `Bearer ${ANON}` };
let failures = 0;
const check = (name, ok, detail) => { console.log(`${ok ? 'PASS' : 'FAIL'}: ${name}${detail ? ' — ' + detail : ''}`); if (!ok) failures++; };

async function timedGet(name, path, budgetMs) {
  const t0 = Date.now();
  const res = await fetch(`${URL_BASE}/rest/v1/${path}`, { headers: H });
  const ms = Date.now() - t0;
  const body = res.ok ? await res.json() : await res.text();
  check(`${name} status 200`, res.status === 200, `got ${res.status}${res.ok ? '' : ' body: ' + String(body).slice(0, 200)}`);
  check(`${name} under ${budgetMs}ms`, ms < budgetMs, `${ms}ms`);
  return { body, ms };
}

// 1. Find a real recent trace with several rows (columns anon can read: id, span_id, trace_id).
const recent = await (await fetch(`${URL_BASE}/rest/v1/ai_activity_log?select=trace_id&trace_id=not.is.null&order=id.desc&limit=200`, { headers: H })).json();
const counts = new Map();
for (const r of recent) counts.set(r.trace_id, (counts.get(r.trace_id) || 0) + 1);
const traceId = [...counts.entries()].sort((a, b) => b[1] - a[1])[0]?.[0];
check('found a recent multi-row trace', !!traceId, traceId);

// 2. The exact tracePatterns.js two-step, timed. This is the query that 500'd on 2026-08-10.
const act = await timedGet('activity rows', `ai_activity_log?select=id,span_id&trace_id=eq.${traceId}`, 3000);
const ids = (act.body || []).map(r => r.id);
check('trace has rows', ids.length > 0, `${ids.length} ids`);
const pat = await timedGet('ai_call_patterns point lookup', `ai_call_patterns?select=ai_activity_log_id,pattern_name&ai_activity_log_id=in.(${ids.join(',')})`, 2000);
check('point lookup returns pattern rows', Array.isArray(pat.body) && pat.body.length > 0, `${(pat.body || []).length} rows`);
check('pattern rows carry names', (pat.body || []).every(r => typeof r.pattern_name === 'string' && r.pattern_name.length > 0));

// 3. Concurrency parity with the real screen: three simultaneous point lookups must all pass.
const trio = await Promise.all([1, 2, 3].map(i =>
  timedGet(`concurrent lookup ${i}`, `ai_call_patterns?select=ai_activity_log_id,pattern_name&ai_activity_log_id=in.(${ids.join(',')})`, 3000)));
check('all concurrent lookups returned rows', trio.every(t => Array.isArray(t.body) && t.body.length > 0));

// 4. The rollup pair (AI Audit / By Pattern path — LOG-101's closure evidence, anon role).
const roll = await timedGet('classification rollup', `ai_pattern_classification_rollup?select=pattern_slug,pattern_name,pattern_description,call_count,cost_sum,log_ids`, 3000);
check('rollup has patterns', Array.isArray(roll.body) && roll.body.length > 0, `${(roll.body || []).length} patterns`);
const recl = await timedGet('reclassification count', `ai_pattern_reclassification_count?select=reclassification_count`, 3000);
check('reclassification count is a number', Number.isInteger(recl.body?.[0]?.reclassification_count), String(recl.body?.[0]?.reclassification_count));

console.log(failures === 0 ? 'ALL TESTS PASS' : `${failures} FAILURES`);
process.exit(failures === 0 ? 0 : 1);
```
