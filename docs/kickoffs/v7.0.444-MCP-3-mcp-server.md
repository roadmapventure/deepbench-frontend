## 2. CONTEXT

Capabilities are rows (`public.capabilities`: slug, name, description, execution_type, default_intent_slug) with holders in `agent_capability_assignments` and a lane on the holder (`agents.lane`). An MCP tool per capability: name = slug, description = the row's description plus the holder's name and role, input schema = `{ task_context: object, intent_slug?: string }` (the Intent Skill's `traits.schema` is the OUTPUT contract, returned as the tool's structured content when the capability has one). Governance-lane capabilities are listed only when the caller presents the governance key (see §4); product-lane capabilities need the standard gate.
