## 2. CONTEXT — the question is now settled by live evidence

Across `ABT-1c`→`1e` the recount was moved onto the Vercel build and works: three of the four repo-fact tiles (lines of code, source files, governance docs) refresh on every push to `dev`.

The fourth, "Commits to dev", **cannot be computed in Vercel's build container**, and the last build log proves why:

```
platform-stats: deepened shallow clone for an accurate commit count
platform-stats: commit count looks truncated (computed 10 < stored 1536) — preserving stored value
```

`git fetch --unshallow` **exits 0 but does not actually deepen anything** in that environment — the count immediately afterward is still 10, Vercel's `--depth=10` clone depth. This also explains `ABT-1d`'s puzzle (the shallow flag staying `true` after an apparently-successful fetch): the fetch was a silent no-op, so nothing about the repository changed. The monotonic guard did its job and the tile kept its correct value.

**Two things are wrong with the current state, both small, neither affecting correctness of the data:**
1. The script logs `deepened shallow clone for an accurate commit count` when it demonstrably did not deepen. A log line that asserts something untrue is precisely the kind of detail that undermines credibility with the audience this whole screen is built for — and it will mislead the next person reading a build log.
2. The finding itself lives only in this kickoff and a build log. Without it recorded in the file, a future session will re-attempt the same fix.

**This session does not remove the deepen attempt.** It genuinely works outside Vercel (proven live from a local `file://` clone in `ABT-1d`), costs ~70 ms, and is already fully guarded. It just has to stop claiming success it can't verify.

## 8. NODE.JS TEST (save as `test-abt-1f.mjs`, run `node --env-file=.env.local test-abt-1f.mjs`, delete before committing)

**Ordering note (carried from `ABT-1d`/`1e`):** commit the script change before running this test — the shallow-clone case clones `file://$PWD`, which reads committed HEAD. Nothing is pushed until the test passes.

```js
// test-abt-1f.mjs — S-ABT-1f verification
import { execSync } from "node:child_process";
import { readFileSync, mkdtempSync } from "node:fs";
import { tmpdir } from "node:os";
import { join } from "node:path";
import assert from "node:assert";
let pass = 0;
const ok = (c, m) => { assert.ok(c, m); console.log("PASS:", m); pass++; };

const src = readFileSync("scripts/platform-stats.js", "utf8");
ok(/did not deepen/.test(src), "no-op deepen has its own honest message");
ok(/--unshallow/.test(src), "deepen attempt retained");
ok(/--soft/.test(src) && /VERCEL_GIT_COMMIT_REF/.test(src), "soft + preview guards retained");
ok(/looks truncated/.test(src), "monotonic guard retained");
ok(!/VERCEL_DEEP_CLONE\s*[^)]/.test(src.replace(/\/\/.*$/gm, "")), "no code depends on VERCEL_DEEP_CLONE");

const url = process.env.SUPABASE_URL || process.env.VITE_SUPABASE_URL;
const key = process.env.SUPABASE_ANON_KEY || process.env.VITE_SUPABASE_ANON_KEY;
const get = async () => (await (await fetch(`${url}/rest/v1/platform_stats?id=eq.1&select=*`,
  { headers: { apikey: key, Authorization: `Bearer ${key}` } })).json())[0];
const before = await get();

// Shallow clone with a reachable origin: the deepen really works here, so the
// success message must report real numbers, not a bare claim.
const dir = mkdtempSync(join(tmpdir(), "abt1f-"));
const clone = join(dir, "repo");
execSync(`git clone --depth 1 file://${process.cwd().replace(/\\/g, "/")} "${clone}"`, { stdio: "pipe" });
const out = execSync(`node "${join(clone, "scripts/platform-stats.js")}" --soft`,
  { cwd: clone, encoding: "utf8", env: { ...process.env, SUPABASE_URL: url, SUPABASE_ANON_KEY: key } });
console.log(out);
ok(/deepened shallow clone \(\d+ → \d+ commits\)/.test(out), "successful deepen reports before → after counts");

// Unreachable origin: fetch throws, existing catch message, still exit 0, value protected.
const clone2 = join(dir, "repo2");
execSync(`git clone --depth 1 file://${process.cwd().replace(/\\/g, "/")} "${clone2}"`, { stdio: "pipe" });
execSync(`git -C "${clone2}" remote set-url origin file:///nonexistent-abt1f`, { stdio: "pipe" });
let code = 0, out2 = "";
try {
  out2 = execSync(`node "${join(clone2, "scripts/platform-stats.js")}" --soft`,
    { cwd: clone2, encoding: "utf8", env: { ...process.env, SUPABASE_URL: url, SUPABASE_ANON_KEY: key } });
} catch (e) { code = e.status ?? 1; out2 = String(e.stdout || ""); }
ok(code === 0, "unreachable origin still exits 0 (deploy-safe)");
ok(/could not deepen/.test(out2), "throw path keeps its existing message");
const after = await get();
ok(after.commits_dev >= before.commits_dev, `commits_dev never regressed (${after.commits_dev})`);
ok(after.dev_toolchain_services === before.dev_toolchain_services, "toolchain preserved");

console.log(`ALL TESTS PASS (${pass})`);
```
