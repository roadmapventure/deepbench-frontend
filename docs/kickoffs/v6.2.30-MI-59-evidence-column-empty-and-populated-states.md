## 2. CONTEXT

John's direct live observation on the Channel Sales Intelligence default screen (Column 2, before any Theory/Forecast/Correct flow has started): the "Interact with the Data" box reads as if it's already interactive, when it's actually empty and waiting — the 4 tag pills below it (Sourced/Analysis/Source Simulation/Learned) are a static legend with no click handler and no tie to any flow or action (confirmed by reading `EvidenceColumn`'s `!hypFlow` branch — the pills are plain `<span>`s built from `describeDataType()`, not buttons).

Two things this session fixes, confirmed with John conversationally before this doc was written:
1. **Empty state** (`!hypFlow`) becomes purely informational: the box says "Once your chat has analysis data for you to interact with, it will appear here," and the 4 dummy pills are removed outright (not just hidden for this state — they don't represent a flow or action anywhere, so they're dead weight generally).
2. **Populated state** (`hypFlow` truthy, i.e. an active Theory/Forecast/Correct flow) currently renders a header that says `Theory Evidence` and has no descriptive sentence at all before its intent-toggle buttons. John wants the header to stay `Evidence` in both states (never switch to `Theory Evidence`), and a new sentence added above the intent buttons: the active intent's label prefixed onto "Data for you to interact with your chat..." — e.g. `Theory — Data for you to interact with your chat...`.

Both sentences are produced by one new pure helper, `getEvidencePanelSentence(hypFlow)`, so the empty/populated text can't drift apart from each other as separate hardcoded strings.

## 8. NODE.JS TEST

```js
// test-MI-59.mjs
let pass = 0, fail = 0;
function assert(desc, cond) {
  if (cond) { console.log(`  ✓ ${desc}`); pass++; }
  else       { console.error(`  ✗ ${desc}`); fail++; }
}

// Pure copy of getEvidencePanelSentence()'s logic — no app imports (Section 4 rule).
const INTENT_LABEL = { theory: "Theory", forecast: "Forecast", correct: "Correct" };
function getEvidencePanelSentence(hypFlow) {
  if (!hypFlow) return "Once your chat has analysis data for you to interact with, it will appear here";
  const label = INTENT_LABEL[hypFlow.intent] || hypFlow.intent;
  return `${label} — Data for you to interact with your chat...`;
}

// T1: empty state (no hypFlow / null / undefined)
assert("T1a: null hypFlow returns the onload sentence",
  getEvidencePanelSentence(null) === "Once your chat has analysis data for you to interact with, it will appear here");
assert("T1b: undefined hypFlow returns the onload sentence (never throws)",
  getEvidencePanelSentence(undefined) === "Once your chat has analysis data for you to interact with, it will appear here");

// T2: populated state, all 3 known intents
assert("T2a: theory intent prefixes 'Theory'",
  getEvidencePanelSentence({ intent: "theory" }) === "Theory — Data for you to interact with your chat...");
assert("T2b: forecast intent prefixes 'Forecast'",
  getEvidencePanelSentence({ intent: "forecast" }) === "Forecast — Data for you to interact with your chat...");
assert("T2c: correct intent prefixes 'Correct'",
  getEvidencePanelSentence({ intent: "correct" }) === "Correct — Data for you to interact with your chat...");

// T3: unknown/malformed intent falls back to the raw value instead of throwing or showing "undefined"
assert("T3: unrecognized intent string falls back to itself, not the literal word 'undefined'",
  getEvidencePanelSentence({ intent: "something_new" }) === "something_new — Data for you to interact with your chat...");

console.log(`\n${pass + fail} tests — ${pass} passed, ${fail} failed`);
if (fail > 0) process.exit(1);
else console.log("ALL TESTS PASS");
```
