## 2. CONTEXT

Every By Pattern row shows `<$0.01` while the real spend is ~$31. Root cause verified live 2026-07-28: `ai_pattern_classification_rollup` computes `cost_sum` as `sum(cost_usd)` over `ai_activity_log`, but **only 43 of 22,184 rows have a stored `cost_usd` at all, and zero of those belong to a classified pattern** — so the sum is genuinely `0`, not a rounding artifact. Cost on this platform is *derived at read time from tokens* by `computeCallCost()` (the `AA-181`/`AA-183` design — "single source of truth for call cost"); every other cost on the screen (Total Cost, By LLM, By Agent, By Service) already goes through it. The By Pattern section, added later by `LOG-38`, reads the SQL column instead and was never migrated onto that path. This session migrates it.

**Why the row-level join and not a cheaper token-sum aggregate (decided by measurement, not preference):** an aggregate of `sum(input_tokens)/sum(output_tokens)` per pattern would skip the `AI-51` pairing dedup that every other cost on this screen applies. Measured live: **1,731 of Request Routing's 2,629 classified rows (66%) are paired duplicates** (the `LOG-91` double-write). Aggregating tokens would report Request Routing at ~$26.24 while the header's Total Cost basis says ~$10.48 — reintroducing exactly the "numbers don't reconcile" class of bug `LOG-92` just fixed. Joining at row level inherits the dedup for free.

**Calls stay raw, cost is deduped — this is deliberate and matches the screen's existing behavior.** `computeByLLM()` already increments `calls` for every log row while summing an already-dedup-zeroed `cost`; By Agent does the same. So a By Pattern row's Calls reconciles with the header's Total Calls (raw rows, per `LOG-92`), and its Cost reconciles with Total Cost (deduped). Do not "fix" the call count in this session — the raw-row semantics are owned by `LOG-91`.

### Task 1 — `fetchPatternClassification()` also returns the row→pattern mapping (`src/hooks/useAIActivity.js`)

Page `ai_call_patterns` for the join keys alongside the existing two reads. Use the same `PAGE_SIZE`/`.range()` loop `hydrateFromSupabase()` already uses (~3,600 rows today = 4 requests):

```js
// FEATURE: LOG-97 -- the row->pattern mapping, so cost can be computed from the SAME per-row
// values every other cost on this screen uses (computeCallCost via the hydrated log), instead of
// the rollup view's sum(cost_usd) -- a column only 43 of 22k rows ever populate, and none of the
// classified ones. Row-level (not a token aggregate) specifically so the AI-51 pairing dedup is
// inherited: 66% of request-routing's rows are paired duplicates, so an aggregate would double it.
async function fetchPatternRowMap() {
  const bySlug = new Map();
  let from = 0;
  while (true) {
    const { data, error } = await supabase
      .from('ai_call_patterns')
      .select('ai_activity_log_id, pattern_slug')
      .range(from, from + PAGE_SIZE - 1);
    if (error) throw error;
    for (const r of (data || [])) {
      if (!bySlug.has(r.pattern_slug)) bySlug.set(r.pattern_slug, new Set());
      bySlug.get(r.pattern_slug).add(r.ai_activity_log_id);
    }
    if (!data || data.length < PAGE_SIZE) break;
    from += PAGE_SIZE;
  }
  return bySlug;
}
```

### Task 2 — `usePatternClassification(log)` computes cost from the log (`src/hooks/useAIActivity.js`)

Give the hook an optional `log` parameter and derive each pattern's cost from it:

```js
export function usePatternClassification(log = []) {
  const [state, setState] = useState({ classified: [], reclassificationCount: 0, rowIdsBySlug: new Map(), loaded: false });
  useEffect(() => {
    let alive = true;
    fetchPatternClassification().then(r => { if (alive) setState({ ...r, loaded: true }); });
    return () => { alive = false; };
  }, []);

  // FEATURE: LOG-97 -- cost per pattern = sum of the hydrated log entries' own cost values, which
  // computeCallCost() already derived from tokens at hydrate time AND which hydrateFromSupabase()
  // already zeroed for AI-51-paired duplicates. Falls back to the view's cost_sum only when the
  // mapping or the log is unavailable, so a fetch failure degrades to today's behavior, never to
  // a wrong number. Recomputes when either input changes (the log arrives after this fetch).
  const costBySlug = useMemo(() => {
    const costById = new Map(log.map(e => [e.id, e.cost || 0]));
    const out = new Map();
    for (const [slug, ids] of state.rowIdsBySlug) {
      let sum = 0;
      for (const id of ids) sum += costById.get(id) || 0;
      out.set(slug, sum);
    }
    return out;
  }, [log, state.rowIdsBySlug]);

  const classified = state.classified.map(p => ({
    ...p,
    cost: costBySlug.has(p.slug) && log.length > 0 ? costBySlug.get(p.slug) : p.cost,
  }));

  return { ...state, classified };
}
```

Import `useMemo` from React if not already imported in this file.

```js
// test-log-97.mjs — S-LOG-97 (v6.3.187) — By Pattern cost wiring
// Categories: B (cost aggregation logic), F (Supabase alignment — the join key and the real magnitudes)
import { createClient } from '@supabase/supabase-js';

const supabase = createClient(process.env.VITE_SUPABASE_URL, process.env.VITE_SUPABASE_ANON_KEY);
let pass = 0, fail = 0;
const ok = (name, cond, detail = '') => {
  if (cond) { pass++; console.log(`  PASS  ${name}`); }
  else { fail++; console.log(`  FAIL  ${name} ${detail}`); }
};
const PAGE_SIZE = 1000;
const pageAll = async (table, cols) => {
  const rows = []; let from = 0;
  while (true) {
    const { data, error } = await supabase.from(table).select(cols).range(from, from + PAGE_SIZE - 1);
    if (error) throw new Error(`${table}: ${error.message}`);
    rows.push(...(data || []));
    if (!data || data.length < PAGE_SIZE) break;
    from += PAGE_SIZE;
  }
  return rows;
};

// --- B. The pricing + aggregation logic, mirroring computeCallCost() exactly ---
const IN = { 'claude-haiku-4-5':0.001,'claude-haiku-4-5-20251001':0.001,'claude-sonnet-4-5':0.003,'claude-sonnet-4-6':0.003,'text-embedding-3-small':0.00002 };
const OUT = { 'claude-haiku-4-5':0.005,'claude-haiku-4-5-20251001':0.005,'claude-sonnet-4-5':0.015,'claude-sonnet-4-6':0.015,'text-embedding-3-small':0.00002 };
const NORM = { 'claude-haiku-4-5':'claude-haiku-4-5-20251001','claude-sonnet-4-5':'claude-sonnet-4-6' };
const cost = (model, i, o) => {
  const m = NORM[model] || model;
  const ir = IN[m] ?? IN[model], or = OUT[m] ?? OUT[model];
  if (ir == null && or == null) return null;
  return ((i||0)/1000)*(ir||0) + ((o||0)/1000)*(or||0);
};
ok('haiku 1M in + 100k out = $1.50', Math.abs(cost('claude-haiku-4-5-20251001', 1_000_000, 100_000) - 1.5) < 1e-9);
ok('sonnet 1M in + 100k out = $4.50', Math.abs(cost('claude-sonnet-4-6', 1_000_000, 100_000) - 4.5) < 1e-9);
ok('unknown model -> null (never 0)', cost('some-unknown-model', 5000, 5000) === null);
ok('null tokens -> 0, not NaN', cost('claude-haiku-4-5-20251001', null, null) === 0);

// --- F. The rollup's stored cost really is empty (the bug this fixes) ---
const { data: rollup, error: rErr } = await supabase.from('ai_pattern_classification_rollup').select('pattern_slug, call_count, cost_sum');
ok('rollup view readable', !rErr, rErr?.message);
ok('every rollup cost_sum is 0 (confirms the defect)', (rollup||[]).every(r => Number(r.cost_sum) === 0));

// --- F. Join key alignment + real per-pattern cost is materially > $0.01 ---
const map = await pageAll('ai_call_patterns', 'ai_activity_log_id, pattern_slug');
const logRows = await pageAll('ai_activity_log', 'id, model, input_tokens, output_tokens, ai_type, agent_id, feature, created_at');
const byId = new Map(logRows.map(r => [r.id, r]));
ok(`every mapped id resolves to a log row (${map.length} mappings)`, map.every(m => byId.has(m.ai_activity_log_id)));

// AI-51 pairing dedup, same rule as pairedAgentTurnIds()
const WRAPPERS = new Set(['channel-intelligence','hypothesis-evaluation','quality-gate','pipeline-triage','memory-consolidation','data-analysis','project-manager','screen-controls','html-display']);
const wrapperTimes = new Map();
for (const r of logRows) {
  if (WRAPPERS.has(r.ai_type) && r.feature === 'request-receivable') {
    if (!wrapperTimes.has(r.agent_id)) wrapperTimes.set(r.agent_id, []);
    wrapperTimes.get(r.agent_id).push(new Date(r.created_at).getTime());
  }
}
const paired = new Set();
for (const r of logRows) {
  if (r.ai_type !== 'agent-turn') continue;
  const t = new Date(r.created_at).getTime();
  if ((wrapperTimes.get(r.agent_id) || []).some(w => Math.abs(w - t) < 2000)) paired.add(r.id);
}

const costBySlug = new Map();
for (const m of map) {
  const row = byId.get(m.ai_activity_log_id);
  const c = paired.has(row.id) ? 0 : (cost(row.model, row.input_tokens, row.output_tokens) || 0);
  costBySlug.set(m.pattern_slug, (costBySlug.get(m.pattern_slug) || 0) + c);
}
for (const [slug, c] of costBySlug) {
  ok(`${slug} cost > $0.01 (got $${c.toFixed(2)})`, c > 0.01);
}
ok(`total classified cost is materially non-zero (got $${[...costBySlug.values()].reduce((a,b)=>a+b,0).toFixed(2)})`,
   [...costBySlug.values()].reduce((a,b)=>a+b,0) > 5);
ok('dedup actually removes cost (paired rows exist in the classified set)',
   map.some(m => paired.has(m.ai_activity_log_id)));

console.log(fail === 0 ? `\nALL TESTS PASS (${pass})` : `\n${fail} FAILURES (${pass} passed)`);
if (fail > 0) process.exit(1);
```
