Designer decisions, all reversible by `git revert` (JOHN-0925-DESIGNER-DECIDES):

- **D1 where:** the MCP-standard `_meta` on the `tools/call` result, one key, reverse-DNS prefixed as the spec recommends: `com.roadmapventure.deepbench/usage`. `content`, `structuredContent`, `isError` and every published `outputSchema` are untouched.
- **D2 shape:** `{ cost_usd, model, models?, model_calls, input_tokens, output_tokens, cache_creation_input_tokens, cache_read_input_tokens, trace_id }`. `cost_usd` is the SUM over every model row the call wrote (loop turns, delegated hops), each rounded to 6 places as the column stores it, so it equals `sum(cost_usd)` for the trace. `model` is the one model when all rows share it, else `null` with `models` listing them. Token fields are sums, `null` when no row reported that field.
- **D3 single source:** no second calculation. `logActivity()` appends the figure it is about to write to a per-call ledger carried on the request context (`usageLedger`, an array `runWithCallSource()`'s `extra` already lets a caller place); `mcp.js` only sums it.
- **D4 unknown is null, never 0:** a row whose model is unpriced makes `cost_usd` `null` (house rule, `shared/models.js`). A call that wrote no model row (a deterministic capability, a refusal before the model) gets NO usage key and no `_meta` at all.
- **D5 who:** keyed callers only (`callerKeyName` non-null: any `MCP_*` key). A keyless caller's result is byte-identical to today. Reason: token counts are a prompt-size signal nobody asked to publish to anonymous callers; the named use case is a keyed site.
- **D6 failures:** an `isError` result also carries the block when model rows were written before the failure (a billed failure costs the caller's cap too).
- **D7 cap:** three files hold `mcp.js`, `activity-log.js` and one new test; the ARCHITECTURE §19t amend line is residue, named in the report.
