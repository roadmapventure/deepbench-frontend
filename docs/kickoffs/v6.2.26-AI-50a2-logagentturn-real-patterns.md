## 1. CONTEXT

`AI-50a` (v6.2.23, shipped and live-verified) threaded each Intent Skill Profile's real `technical_services` through `db-assembly.js` → `ai-enrichment.js` → `request-receivable.js`'s `sendRequest()`, so `ai_activity_log.patterns_used` reflects real per-call pattern usage instead of a static per-service guess. Verified live against 3 different intents (`ci-answer-intent`, `hyp-generation-intent`, `agent-selection-intent` mid-delegation-chain) — all correct.

**Gap found live during `AI-50b`'s own verification (2026-07-14):** `execute.js`'s `logAgentTurn()` is a **second, independent write site** to `ai_activity_log` that `AI-50a` never touched. It fires on *every* turn in the delegation loop (not just terminal ones) and writes its own `patterns_used: is_delegate_call ? ['agent-delegation'] : []` — the old mechanical-only detection. For any intent whose real job **is** delegating (e.g. `ci-answer-display-intent`, `hyp-hypothesis-test-display-intent` — both just populated with real `technical_services` by `AI-50b`), the turn never reaches `sendRequest()` at all; it only ever logs through `logAgentTurn()`. Confirmed live: a real `hyp-hypothesis-test-display-intent` call logged `patterns_used: ["agent-delegation"]` only — its real `technical_services` (`["tool-use","agent-delegation"]`) never got read, because `logAgentTurn()` doesn't know about it.

**This session extends the exact same merge pattern to the second write site.** `logAgentTurn()`'s single call site already has `enriched` in scope (the same object `AI-50a` extended with `intent_technical_services`) — this is a same-file, same-shape fix, not a redesign.

## 7. NODE.JS TEST

Save as `test-AI-50a2.mjs` at the repo root, run with `node test-AI-50a2.mjs`, then delete the file. `logAgentTurn()` does a live `fetch()` on every call (fire-and-forget, no return value) so it can't be unit-tested directly without a real or mocked Supabase endpoint — this test instead verifies the exact merge/dedupe logic as a standalone pure function, mirroring `AI-50a`'s own test approach for `buildPatternsUsed()`'s merge.

```js
function mergeAgentTurnPatterns(isDelegateCall, intentTechnicalServices) {
  return Array.from(new Set([
    ...(isDelegateCall ? ['agent-delegation'] : []),
    ...intentTechnicalServices,
  ]));
}

let failures = 0;
function assertDeepEqual(actual, expected, label) {
  const a = JSON.stringify([...actual].sort());
  const e = JSON.stringify([...expected].sort());
  if (a !== e) {
    failures++;
    console.error(`FAIL: ${label} — expected ${e}, got ${a}`);
  } else {
    console.log(`PASS: ${label}`);
  }
}

assertDeepEqual(
  mergeAgentTurnPatterns(true, ['tool-use', 'agent-delegation']),
  ['tool-use', 'agent-delegation'],
  'delegating turn + real patterns already including agent-delegation -- deduped, not doubled'
);
assertDeepEqual(
  mergeAgentTurnPatterns(true, []),
  ['agent-delegation'],
  'delegating turn, no real technical_services populated -- falls back to mechanical-only detection (matches pre-fix behavior for any intent AI-50b hasn\'t reached yet)'
);
assertDeepEqual(
  mergeAgentTurnPatterns(false, ['rag', 'structured-output']),
  ['rag', 'structured-output'],
  'non-delegating turn -- real patterns present even though is_delegate_call is false'
);
assertDeepEqual(
  mergeAgentTurnPatterns(false, []),
  [],
  'non-delegating turn, nothing declared -- empty array, not null/undefined'
);

if (failures > 0) {
  console.error(`\n${failures} test(s) FAILED`);
  process.exit(1);
} else {
  console.log('\nALL TESTS PASS');
}
```
