## 1. CONTEXT

Direct follow-up to `S-AI-54-55` (same design session, same worktree): that session's own Category L live test found `input_tokens` came back `null` on 2/2 real `suggest-goal` calls against the dev endpoint, while `output_tokens`/`patterns_used` captured correctly. Root-caused by direct code read: the reader loop decodes and line-splits each `reader.read()` chunk in isolation —

```js
const chunk = decoder.decode(value);
const lines = chunk.split('\n').filter(l => l.trim());
```

— with no buffer carried over between reads. Any `data: {...}` line whose bytes are split across two separate `reader.read()` calls is silently corrupted on both halves (each half fails `JSON.parse` inside the existing `try {} catch {}`, so it's dropped with no error surfaced). `message_start` — the very first SSE event, carrying `input_tokens` — is the event most exposed to landing right at an early chunk boundary, consistent with the deterministic 2/2 reproduction. This is the standard missing-buffer bug in any hand-rolled SSE parser, not a transient network issue — the fix is the standard one: accumulate a running string buffer across reads, split on `\n`, and hold back the last (possibly incomplete) line for the next iteration instead of assuming every read ends on a line boundary.

**Scope, John's implicit continuation of the same session:** single-file, single-loop fix. No other behavior changes.

## 4. TASKS (max 4)

### Task 1 — `api/plan.js`: buffer SSE reads across chunk boundaries

Replace the reader loop (currently starting at `const reader = anthropicRes.body.getReader();` through the `for (const line of lines) { ... }` block's closing brace) with:

```js
      const reader = anthropicRes.body.getReader();
      const decoder = new TextDecoder();
      let buffer = '';

      while (true) {
        const { done, value } = await reader.read();
        if (done) break;
        buffer += decoder.decode(value, { stream: true });
        const lines = buffer.split('\n');
        buffer = lines.pop(); // last entry may be an incomplete line — hold it for the next read
        for (const line of lines) {
          if (!line.trim()) continue;
          if (line.startsWith('data: ')) {
            const data = line.slice(6);
            if (data === '[DONE]') continue;
            try {
              const parsed = JSON.parse(data);
              if (parsed.type === 'content_block_delta' && parsed.delta?.text) {
                res.write(`data: ${JSON.stringify({ text: parsed.delta.text })}\n\n`);
              } else if (parsed.type === 'message_start') {
                inputTokens = parsed.message?.usage?.input_tokens ?? null;
              } else if (parsed.type === 'message_delta') {
                outputTokens = parsed.usage?.output_tokens ?? outputTokens;
              }
            } catch {}
          }
        }
      }
```

Two changes from the current code: (1) `decoder.decode(value, { stream: true })` instead of `decoder.decode(value)` — required so a multi-byte UTF-8 character split across chunks decodes correctly instead of also being silently mangled; (2) `buffer`/`lines.pop()` carry-over — the actual fix for the reported bug. The `while(true)` loop structure, the `outputTokens ?? outputTokens` fallback, and everything after the loop (the `logActivity()` call, the trailing `res.write('data: [DONE]\n\n'); return res.end();`) are unchanged.

No other line in this file changes.

```js
// Simulates the exact bug: a `data: {...}` line whose bytes arrive across two
// separate `reader.read()` calls. Re-implements just the parsing loop (not a
// full HTTP mock) to verify the buffering logic in isolation.
let failures = 0;
function assert(cond, label) {
  if (!cond) { failures++; console.error(`FAIL: ${label}`); }
  else { console.log(`PASS: ${label}`); }
}

const fullLine = `data: ${JSON.stringify({ type: 'message_start', message: { usage: { input_tokens: 340, output_tokens: 1 } } })}\n`;
// Split mid-line, simulating a chunk boundary landing inside the JSON payload
const splitPoint = 40;
const chunks = [fullLine.slice(0, splitPoint), fullLine.slice(splitPoint)];

let buffer = '';
let inputTokens = null;
for (const rawChunk of chunks) {
  buffer += rawChunk; // decoder.decode(value, {stream:true}) already applied upstream in real code
  const lines = buffer.split('\n');
  buffer = lines.pop();
  for (const line of lines) {
    if (!line.trim()) continue;
    if (line.startsWith('data: ')) {
      const data = line.slice(6);
      try {
        const parsed = JSON.parse(data);
        if (parsed.type === 'message_start') inputTokens = parsed.message?.usage?.input_tokens ?? null;
      } catch {}
    }
  }
}
assert(inputTokens === 340, 'input_tokens recovered correctly even when the data line is split across two chunks');

if (failures > 0) {
  console.error(`\n${failures} test(s) FAILED`);
  process.exit(1);
} else {
  console.log('\nALL TESTS PASS');
}
```
