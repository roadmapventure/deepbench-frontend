## 1. CONTEXT

`AA-192` (found 2026-07-15 at `AA-190`'s close-out) lists several client-side `logAICall()` gaps. Investigating this session found the root cause is bigger than "missing tokens": `DashboardScreen.jsx` (3 call sites) and `PersonnelScreen.jsx`/`TeachScreen.jsx` (1 call site each) all funnel through one shared route, `api/brief.js`, which was never migrated onto the shared server-side `logActivity()` service the rest of the platform already uses (`ARCHITECTURE.md` §12/§13). Instead, each client call site logs its own guess client-side — and the guess is wrong in two ways, not one:

1. **Wrong tokens** (`AA-192`'s original finding) — `DashboardScreen.jsx` passes only `output_tokens` as `tokens`, silently never pricing the input side.
2. **Wrong model, found this session** — all of these calls carry an `agent_id` with no `system` override, so `api/brief.js` takes its AGENT PATH (line 93), which calls `callClaude(systemPrompt, messages, { max_tokens, model: "claude-sonnet-4-5" })` (`api/brief.js:110`) — **hardcoded to Sonnet 4.5, ignoring whatever `model` the client sent**. Every one of these call sites logs `model:"claude-haiku-4-5"` client-side — flatly wrong. Sonnet's rates (`COST_PER_1K_INPUT`/`OUTPUT` in `useAIActivity.js`) are ~3x Haiku's, so this is a bigger dollar-impact bug than the missing-tokens one.

**Root-cause fix, not a per-screen patch:** migrate `api/brief.js`'s AGENT PATH itself onto `logActivity()` — it already has the real Anthropic response (`result.usage`, the real model actually called) sitting right there. Each screen's own fix then collapses to deleting its now-redundant, wrong client-side guess — the same trivial cleanup already done twice this week (`CreateWorkOrderScreen.jsx`, `PersonnelScreen.jsx`'s own embedding call in `AA-190h`). This also means `AIReviewTab.jsx`/`TestTeamScreen.jsx` — two other real callers of this same route that currently log **nothing** client-side — start getting real logging for free, no code change needed in either file.

**Split into 3 sessions (John's explicit call, given the 3-file/session cap):** this is Session A. `TeachScreen.jsx` (Session B, depends on this session landing first) and `FetchContext.jsx`/`api/web-memory.js` (Session C, independent, a different route) are separate, not in this session's scope.

**Explicitly deferred, found while scoping, not fixed here (each logged with a real ID, not left as a bare note):**
- `LOG-05` — `SERVICE_CATALOG`'s `agent-routing`/`chat-response`/`document-extraction` entries all declare patterns (`Structured Output`, `Prompt Chaining`, `Streaming`) that don't match this route's real implementation (single non-streaming call, free-text JSON parsing, no schema enforcement). This session's `patternsUsed` will **not** claim `'structured-output'` for that reason — only `'rag'`, and only when it actually fired.
- `LOG-06` — `checkRouting()`/`generateMetadata()` both send `skipRag: true`, which `api/brief.js` never reads — RAG likely still runs on every one of these calls despite the caller's intent to skip it. Not this session's scope (logging accuracy, not retrieval behavior).
- `AIReviewTab.jsx`/`TestTeamScreen.jsx` — both call this same route with no `ai_type` today. This session's `logActivity()` call only fires when the caller passes one explicitly (see Task 1) — these two callers stay unlogged (same as before, not worse), rather than guessing a label for them.

## 4. TASKS (max 4)

### Task 1 — `api/brief.js`: log the AGENT PATH via shared `logActivity()`

**1a.** Add the import at the top of the file:
```js
import { logActivity } from "../lib/activity-log.js";
```

**1b.** Add a small local map right after the imports (module scope, not inside the handler):
```js
// FEATURE: AA-192a -- ai_type -> SERVICE_CATALOG feature slug for this route's callers.
// Only types explicitly declared by a caller get logged -- see Task 1c.
const BRIEF_AI_TYPE_FEATURE = {
  routing:    "agent-routing",
  chat:       "chat-response",
  extraction: "document-extraction",
};
```

**1c.** In the AGENT PATH (the block starting `// ── AGENT PATH — full pipeline via agent-run ──`), add a timer right before the existing `let result;` line:
```js
    const callStart = Date.now();
    let result;
```
Then, immediately after the existing `result._system = systemPrompt;` line and before `return res.status(200).json(result);`, add:
```js
    const feature = BRIEF_AI_TYPE_FEATURE[req.body.ai_type];
    if (feature) {
      logActivity({
        tenantId: tenant_id,
        agentId: agent_id,
        aiType: req.body.ai_type,
        feature,
        model: "claude-sonnet-4-5",
        inputTokens: result.usage?.input_tokens ?? null,
        outputTokens: result.usage?.output_tokens ?? null,
        latencyMs: Date.now() - callStart,
        patternsUsed: debugInfo.rag_retrieved ? ["rag"] : [],
      });
    }
```
`feature` only resolves when `req.body.ai_type` is one of the 3 keys in `BRIEF_AI_TYPE_FEATURE` — a caller that doesn't send `ai_type` (e.g. `AIReviewTab.jsx`, `TestTeamScreen.jsx`, both untouched by this session) logs nothing, same as before. Do **not** add logging to the LEGACY PATH or the `"pat"` branch above this — out of scope, neither is a caller this session investigated.

## 7. NODE.JS TEST

Save as `test-AA-192a.mjs` at the repo root, run with `node test-AA-192a.mjs`, then delete the file. Category A (data shape) — verifies `logActivity()` receives the real model/tokens and correctly conditional pattern tagging, and that an unrecognized `ai_type` logs nothing.

```js
import { logActivity } from './lib/activity-log.js';

let failures = 0;
function assert(cond, label) {
  if (!cond) { failures++; console.error(`FAIL: ${label}`); }
  else { console.log(`PASS: ${label}`); }
}

const BRIEF_AI_TYPE_FEATURE = { routing: "agent-routing", chat: "chat-response", extraction: "document-extraction" };

let capturedBody = null;
const realFetch = global.fetch;
global.fetch = async (url, opts) => { capturedBody = JSON.parse(opts.body); return { ok: true, json: async () => ({}) }; };
process.env.SUPABASE_URL = 'https://test.supabase.co';
process.env.SUPABASE_SERVICE_KEY = 'test-key';

// Case 1: chat call, RAG actually retrieved
logActivity({
  tenantId: 'global', agentId: 'chloe', aiType: 'chat', feature: BRIEF_AI_TYPE_FEATURE['chat'],
  model: 'claude-sonnet-4-5', inputTokens: 512, outputTokens: 180, latencyMs: 2200,
  patternsUsed: ['rag'],
});
await new Promise(r => setTimeout(r, 10));
assert(capturedBody.ai_type === 'chat', 'ai_type matches existing AI_TYPE_TO_SERVICE mapping (chat -> chat-response)');
assert(capturedBody.feature === 'chat-response', 'feature matches the real SERVICE_CATALOG slug');
assert(capturedBody.model === 'claude-sonnet-4-5', 'real model logged (Sonnet, not the previously-hardcoded wrong Haiku claim)');
assert(capturedBody.input_tokens === 512 && capturedBody.output_tokens === 180, 'real, separately-priced input/output tokens captured');
assert(JSON.stringify(capturedBody.patterns_used) === JSON.stringify(['rag']), 'rag tagged when it actually retrieved');

// Case 2: routing call, RAG did NOT retrieve (skipRag intent, even though api/brief.js itself ignores it -- LOG-06)
logActivity({
  tenantId: 'global', agentId: 'chloe', aiType: 'routing', feature: BRIEF_AI_TYPE_FEATURE['routing'],
  model: 'claude-sonnet-4-5', inputTokens: 210, outputTokens: 40, latencyMs: 900,
  patternsUsed: [],
});
await new Promise(r => setTimeout(r, 10));
assert(JSON.stringify(capturedBody.patterns_used) === JSON.stringify([]), 'no pattern claimed when RAG did not actually retrieve');
assert(capturedBody.feature === 'agent-routing', 'routing maps to the real agent-routing service slug');

// Case 3: BRIEF_AI_TYPE_FEATURE resolution for an unrecognized ai_type -- the route-level guard (Task 1c)
// mirrors this: feature would be undefined, so the real api/brief.js code skips logActivity() entirely.
assert(BRIEF_AI_TYPE_FEATURE['unknown_caller'] === undefined, 'unrecognized ai_type resolves to no feature -- route logs nothing rather than a guess');

global.fetch = realFetch;

if (failures > 0) {
  console.error(`\n${failures} test(s) FAILED`);
  process.exit(1);
} else {
  console.log('\nALL TESTS PASS');
}
```
