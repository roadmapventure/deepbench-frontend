## 1. SESSION

**AA-164** — deferred item from `AA-162`'s design session: when Marcus (`ci-answer-intent`) internally delegates to another agent mid-turn (e.g. Eleanor Voss for a catalog question, per `AA-162`) without `is_final: true` — i.e. the delegate's answer feeds back into Marcus's own next turn instead of terminating the loop — the Column 3 Agent Routing log shows nothing for that hop. Confirmed live via `ai_activity_log` during `AA-162`'s own QA: the real delegation chain (Marcus → Michelle's `agent-selection-intent` → Eleanor's `library-catalog-intent` → back to Marcus) genuinely executes, but the director sees no trace of it in the Pipeline Log — only Marcus's own final `qa_answer` entry.

**Root cause, confirmed live by reading the code (not guessed):** `runLoop()` already computes `lastHelpSelection` (line ~320, the exact same shape Michelle's Display-agent hand-off already surfaces via `display.selection`) on every `request_help` hop — but only threads it into the *checkpoint* persistence path (`patchDurableHopRow`, used only when a chain runs long enough to hit the durable-resume budget check) and the *resume* rehydration path. The normal, fast terminal success return (`finalResult = { ...result, display_agent_card, display_agent_id }`, line 281) never includes it — so for a fast chain like `AA-162`'s (Haiku-only, no checkpoint needed), the value is computed in memory and then silently dropped before it ever reaches the frontend.

**Why the existing `agent_selection` Pipeline Log case already works for this, unchanged.** The Display-agent hand-off's own `agent_selection` event (`MarketIntelligenceScreen.jsx` line ~356) already renders `evt.data.reasoning` via `describePipelineEvent()`'s existing case, fed by `display.selection` — which is exactly `lastHelpSelection`'s own shape, because it comes from the identical `request_help` code path in `execute.js`, just via a call site that happens to set `is_final: true`. This session doesn't invent a new rendering path; it closes the one place that shape isn't reaching the frontend.
