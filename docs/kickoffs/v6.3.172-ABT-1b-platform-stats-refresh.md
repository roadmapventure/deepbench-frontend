## 2. CONTEXT

`S-ABT-1a` made the About screen read repo facts (lines of code, governance docs, commits, dev toolchain services) from the `platform_stats` Supabase row (id=1), seeded manually with 2026-07-28 values. A browser can't recount repo facts, so this session adds the refresh path: on every push to `dev`, a GitHub Action recounts them from a full checkout and updates the row. `dev_toolchain_services` is **never recomputed** — it's a John-set value (6: GitHub · Vercel · Railway · Supabase · Anthropic · OpenAI); the script must preserve it.

The Action authenticates with the Supabase **anon key** — deliberate: it's the same public key already shipped in the app bundle, `platform_stats` has anon UPDATE granted (verified by the design session), consistent with the platform's current no-RLS posture. Store URL + key as GitHub Actions **repository variables** (`SUPABASE_URL`, `SUPABASE_ANON_KEY`) via `gh variable set`, not hardcoded in the workflow.

## 5. TASKS (3)

### Task 1 — `scripts/platform-stats.js` (new)

Plain Node (no deps beyond node:fs/child_process/fetch). Computes, from repo root:
- `lines_of_code` + `source_files`: all `*.js`/`*.jsx` files under `src/`, `api/`, `shared/` (recursive), counting newline-delimited lines.
- `governance_docs`: count of `CLAUDE*.md` at repo root + all `*.md` under `docs/` (recursive, kickoffs included).
- `commits_dev`: `git rev-list --count HEAD` (the workflow checks out `dev` at full depth).
Then PATCH `platform_stats` via Supabase REST:
`PATCH {SUPABASE_URL}/rest/v1/platform_stats?id=eq.1` with headers `apikey`/`Authorization: Bearer {SUPABASE_ANON_KEY}`, `Content-Type: application/json`, `Prefer: return=representation`, body `{lines_of_code, source_files, governance_docs, commits_dev, updated_at: new Date().toISOString(), updated_by: "platform-stats-action"}` — **`dev_toolchain_services` absent from the body** (preserved). Exit non-zero (fail the workflow run) if the response is not 200/204 or the returned row doesn't echo the new values; log the computed numbers either way. Env via `process.env.SUPABASE_URL`/`SUPABASE_ANON_KEY`, falling back to `VITE_SUPABASE_URL`/`VITE_SUPABASE_ANON_KEY` so the same script runs locally with `--env-file=.env.local`.

### Task 2 — `.github/workflows/platform-stats.yml` (new)

```yaml
name: platform-stats
on:
  push:
    branches: [dev]
jobs:
  refresh:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }
      - uses: actions/setup-node@v4
        with: { node-version: 20 }
      - run: node scripts/platform-stats.js
        env:
          SUPABASE_URL: ${{ vars.SUPABASE_URL }}
          SUPABASE_ANON_KEY: ${{ vars.SUPABASE_ANON_KEY }}
```

## 8. NODE.JS TEST (full code — save as `test-abt-1b.mjs`, run `node --env-file=.env.local test-abt-1b.mjs`, delete before committing)

```js
// test-abt-1b.mjs — S-ABT-1b verification (Categories B, F, L: live write path)
import { execSync } from "child_process";
import assert from "assert";
let pass = 0;
const ok = (c, m) => { assert.ok(c, m); console.log("PASS:", m); pass++; };

const url = process.env.SUPABASE_URL || process.env.VITE_SUPABASE_URL;
const key = process.env.SUPABASE_ANON_KEY || process.env.VITE_SUPABASE_ANON_KEY;
assert.ok(url && key, "Supabase env present");
const get = async () => (await (await fetch(`${url}/rest/v1/platform_stats?id=eq.1&select=*`, {
  headers: { apikey: key, Authorization: `Bearer ${key}` } })).json())[0];

const before = await get();
ok(before && Number.isInteger(before.dev_toolchain_services), `row readable; toolchain=${before.dev_toolchain_services}`);

// Live run of the real script (Category L — this IS the production write path)
const out = execSync("node scripts/platform-stats.js", { encoding: "utf8", env: { ...process.env, SUPABASE_URL: url, SUPABASE_ANON_KEY: key } });
console.log(out);

const after = await get();
ok(after.lines_of_code > 20000, `lines_of_code recounted plausibly (${after.lines_of_code})`);
ok(after.governance_docs > 300, `governance_docs recounted plausibly (${after.governance_docs})`);
ok(after.commits_dev >= before.commits_dev, `commits_dev monotonic (${before.commits_dev} → ${after.commits_dev})`);
ok(after.dev_toolchain_services === before.dev_toolchain_services, "dev_toolchain_services untouched by script");
ok(after.updated_by === "platform-stats-action", "updated_by stamped");
ok(new Date(after.updated_at) > new Date(before.updated_at), "updated_at bumped");
console.log(`ALL TESTS PASS (${pass})  [ABT-1B LIVE WRITE: PASS]`);
```
