## CONTEXT

Found 2026-07-21, investigation session `investigate-news-fetch-0721`, John's live re-test of Column 2 (News & Evidence). Confirmed live decision from the earlier design conversation (`CHI-55`'s original scoping): keep the existing multi-drawer-open behavior (`useDrawerStack`'s `manualOverride`, unchanged) — when John opens a second Evidence drawer while another is still expanded, both stay open. That's intentional (the "papers on a desk" persistence model `CHI-43`/`CHI-49` were built around). The actual problem, root-caused live by John re-testing and confirmed against the code:

**Column 2's `EvidenceColumn` wraps its entire drawer stack in one outer "card"** (`MarketIntelligenceScreen.jsx` ~L1855) that sets `background:T.cardAlt` + `border:1px solid ${T.lineSoft}`. Every individual `<Drawer>` inside it (`SharedUI.jsx:349`) *also* renders with `background:T.cardAlt` + the same border color. Two open drawers stacked inside a same-colored parent box read as one continuous block — not because the drawer-to-drawer gap is wrong (it's `gap:14`, identical to Column 3's), but because there's no contrast between "the drawer" and "the box holding the drawers."

**Column 3 (`AuditColumn`, ~L2496) has no such wrapper** — its outer container sets no background/border at all, so it sits directly on the app's real page background (`T.paperDeep`, set once in `AppShell.jsx:345`). Each individual `<Drawer>` inside it (same shared component, same `T.cardAlt` background) stands out clearly against that plain backdrop — confirmed live, this is exactly the separation John pointed at as the reference to match.

**The fix:** remove `background`/`border` from `EvidenceColumn`'s outer wrapper (~L1855) so Column 2 sits directly on `T.paperDeep`, identical to Column 3 — same shared `Drawer` component elsewhere, zero state/architecture change to `useDrawerStack`. `ScrollFadeHint`'s `bg` prop (~L2090) currently reads `T.cardAlt` to match this same wrapper's old background for its fade gradient — update it to `T.paperDeep` so the fade still blends with the real (new) background instead of the old one.

### Task 1 — `EvidenceColumn`'s outer wrapper: remove `background`/`border`

Current (`MarketIntelligenceScreen.jsx` ~L1855):
```jsx
<div style={{background:T.cardAlt,border:`1px solid ${T.lineSoft}`,display:"flex",flexDirection:"column",flex:1,minHeight:0,overflow:"hidden",gap:14}}>
```
becomes:
```jsx
{/* FEATURE: CHI-55 -- background/border removed so this column sits directly on the app's real
    page background (T.paperDeep, AppShell.jsx) instead of a same-colored T.cardAlt box that gave
    every individually-open Drawer inside it (also T.cardAlt) zero contrast against its own
    container -- matches AuditColumn (Column 3)'s equivalent wrapper, which has never set a
    background here. Layout properties (flex/minHeight/overflow/gap) are unchanged; this is a
    visual-only removal, confirmed live against Column 3 as the reference (John, 2026-07-21). */}
```

Do not touch any other property on this div. Do not touch the inner `position:"relative"` scroll-body wrapper directly beneath it (a separate div, unaffected).
