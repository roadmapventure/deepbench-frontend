## 1. CONTEXT

`AI-50a`/`AI-50a2`/`AI-50b` (all shipped, all live-verified) made `ai_activity_log.patterns_used` carry real, per-call pattern data end-to-end — both on the capability-level `sendRequest()`/`buildFinalDelegationResult()` write path and on `execute.js`'s `logAgentTurn()` write path. The data is now correct in the database and in every capability's own JSON response payload. **Nothing downstream reads it yet.**

Two frontend consumers still show the old, coarse, static picture:

1. **AI Audit's "By Pattern" view** (`useAIActivity.js`'s `byPattern`, computed inside `useAIActivity()`): rolls up cost by checking which `SERVICE_CATALOG` entries *statically declare* a pattern name (`svc.patterns.includes(pat.name)`), then sums the **full** cost of every call to that service into every one of that service's declared patterns. A `channel-intelligence` call tagged with 5 static patterns has its whole cost double/triple/quadruple/quintuple-counted. Confirmed live earlier this same day: By Pattern's bucket sum ran ~3x Total Cost (\$62.10 vs \$21.03). Worse: **the in-memory log entries don't even carry `patterns_used` today** — `logAICall()`'s entry object and `hydrateFromSupabase()`'s Supabase-row mapping both drop the field on the floor, so even after computing the wrong thing, there's no real per-row signal in scope to compute the right thing instead.

2. **MI screen's Agent Routing subline** (`SERVICE_LABEL[capability].patterns`, `MarketIntelligenceScreen.jsx` line ~148-155): a hardcoded static string per capability slug, shown under every routing-drawer row (`RoutingEventRow`). Traced the actual data flow this session: `describePipelineEvent()`'s own comment says event summaries are "driven entirely by actual call responses (`evt.data`)" — and confirmed both terminal write paths' response shapes (`request-receivable.js`'s `sendRequest()` return, ~line 470-477, and `execute.js`'s `buildFinalDelegationResult()`, ~line 208-216) already include `patterns_used` at the top level of the JSON payload the frontend receives. The real per-call value is sitting in `evt.data.patterns_used` today, unused.

**Two known catalog gaps, found during `AI-50a`, still open:** `PATTERN_CATALOG`'s `slug: 'reflection'` doesn't match the real `technical_services`/`patterns_used` value `'reflect'` (confirmed in `ARCHITECTURE.md`'s own REFLECT row and `api/plan.js`'s `s.type === 'reflect'` check) — so every real `'reflect'` pattern silently fails to match any catalog entry today. `'intelligent-synthesis'` (confirmed real value, `ARCHITECTURE.md`'s Intelligent Synthesis row) has no `PATTERN_CATALOG` entry at all — invisible in By Pattern forever without one.

**John's confirmed design for the reconciliation problem** (from the `AI-50a` scoping conversation): real multi-pattern attribution — not the static per-service over-count — with each call's cost split **evenly** across however many real patterns *that specific call* exercised. This makes bucket sums reconcile exactly to Total Cost while still reflecting genuine per-call behavior.

**2c.** Extract `byPattern`'s computation into a new exported, testable pure function — same "extract for testability" precedent `AI-50a` used for `buildSections()`/`buildPatternsUsed()`. Add it near `PATTERN_CATALOG` (top-level export, ~after line 142):

```js
// FEATURE: AI-50c — real per-call pattern attribution, replacing the old SERVICE_CATALOG static
// rollup (which summed a call's FULL cost into every one of that service's declared patterns,
// causing ~3x over-counting). Splits each call's cost EVENLY across however many real patterns
// that specific call exercised (patternsUsed), so bucket sums reconcile exactly to Total Cost —
// John's confirmed design. `total` (call count) is NOT split — a call legitimately counts once
// toward each pattern it used; only cost needs to reconcile to the whole. Entries with no
// patternsUsed (pre-AI-50a rows, or a slug not yet in PATTERN_CATALOG) contribute nothing to any
// bucket — invisible rather than mis-attributed, matching what real data is actually available.
export function computeByPattern(log) {
  const byPattern = {};
  for (const pat of PATTERN_CATALOG) {
    byPattern[pat.slug] = { ...pat, total: 0, cost: 0 };
  }
  for (const e of log) {
    const used = Array.isArray(e.patternsUsed) ? e.patternsUsed : [];
    if (used.length === 0) continue;
    const splitCost = (e.cost || 0) / used.length;
    for (const slug of used) {
      if (byPattern[slug]) {
        byPattern[slug].total += 1;
        byPattern[slug].cost += splitCost;
      }
    }
  }
  return byPattern;
}
```

```js
import { computeByPattern, PATTERN_CATALOG } from './src/hooks/useAIActivity.js';

let failures = 0;
function assert(cond, label) {
  if (!cond) { failures++; console.error(`FAIL: ${label}`); }
  else { console.log(`PASS: ${label}`); }
}

// Test 1: single entry, 2 patterns, cost splits evenly
const log1 = [{ cost: 10, patternsUsed: ['rag', 'structured-output'] }];
const bp1 = computeByPattern(log1);
assert(bp1['rag'].cost === 5 && bp1['rag'].total === 1, 'even split: rag gets half cost, 1 call');
assert(bp1['structured-output'].cost === 5 && bp1['structured-output'].total === 1, 'even split: structured-output gets half cost, 1 call');

// Test 2: entry with no patternsUsed contributes nothing
const log2 = [{ cost: 10, patternsUsed: [] }, { cost: 5 /* field absent entirely */ }];
const bp2 = computeByPattern(log2);
const totalCost2 = Object.values(bp2).reduce((s, p) => s + p.cost, 0);
assert(totalCost2 === 0, 'entries with no patternsUsed contribute zero to every bucket');

// Test 3: reconciliation invariant — sum of bucket costs equals sum of contributing entries' cost
const log3 = [
  { cost: 9,  patternsUsed: ['rag', 'tool-use', 'agent-delegation'] },
  { cost: 6,  patternsUsed: ['structured-output'] },
  { cost: 100, patternsUsed: [] }, // excluded — no real pattern data
];
const bp3 = computeByPattern(log3);
const sumBuckets3 = Object.values(bp3).reduce((s, p) => s + p.cost, 0);
assert(Math.abs(sumBuckets3 - 15) < 1e-9, 'reconciliation: bucket sum equals sum of entries WITH real pattern data (9+6=15), excludes the $100 unattributed entry');

// Test 4: the 2 catalog gap fixes are actually present
assert(PATTERN_CATALOG.some(p => p.slug === 'reflect'), "PATTERN_CATALOG has 'reflect' slug (renamed from 'reflection')");
assert(!PATTERN_CATALOG.some(p => p.slug === 'reflection'), "PATTERN_CATALOG no longer has the old 'reflection' slug");
assert(PATTERN_CATALOG.some(p => p.slug === 'intelligent-synthesis'), "PATTERN_CATALOG has 'intelligent-synthesis' entry");

// Test 5: real values now match (regression guard for the exact gap AI-50a found)
const log5 = [{ cost: 4, patternsUsed: ['reflect', 'intelligent-synthesis'] }];
const bp5 = computeByPattern(log5);
assert(bp5['reflect'].total === 1 && bp5['intelligent-synthesis'].total === 1, "real 'reflect'/'intelligent-synthesis' values now match a catalog entry (previously silently dropped)");

if (failures > 0) {
  console.error(`\n${failures} test(s) FAILED`);
  process.exit(1);
} else {
  console.log('\nALL TESTS PASS');
}
```
