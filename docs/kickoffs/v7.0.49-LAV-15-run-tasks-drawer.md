## CONTEXT

The Agent Console (LAV screen, `/`) shows THAT agents collaborate (network animation, meters,
routing/trace console) but not WHY each hop earned its place. Settled design (John,
2026-08-01/02, `design-scaling-arch-0731` — provenance concept, mock approved with revisions):
per completed hop, a "run task" entry with three lines — **Asked** (the delegation contract),
**Did** (the hop's concrete artifact, typed by hop kind), **Content**
(created / changed / unchanged-with-reason). Terminology validated: a "run" is the standard
industry term for one end-to-end agentic execution (OpenAI Assistants `Run` object, LangSmith
runs/traces); the drawer name **"Run Tasks"** is John's canonical choice — use it verbatim.

Worked example the copy should match in tone (real logged run, upgrade-cycles):
- Router: "Pulled 4 candidate agent profiles; selected Marcus Webb — GEO CSO Expert because the
  question needs channel performance analysis with sourced Q&A." Content: unchanged — routing only.
- Drafter: "Drafted the 26-vs-46-month cycle spread with 4 Library citations." Content: created.
- Gate: "Scored the draft 5/5 on all criteria; verdict pass → displayed." Content: unchanged —
  approved as drafted.

**John's placement + format spec (his own layout calls, revised 2026-08-02):**
- Own Drawer titled **`Run Tasks`**, directly UNDER the "Answer" drawer, **open by default**,
  expanding down to the TOP of the harness trace console, with a **gradient and scroll**.
- **Most recent entry on top**, each entry **numbered** (ascending — newest = highest number).
- **Asked / Did / Content each on its OWN line** within an entry (not run together).
- Each entry carries a **time signature**: "arrived M:SS into the run · took Ns".
- Entries NEVER auto-dismiss; the feed persists after run completion, scrollable; a new run resets it.
- **NO summary/rollup entry** — the feed is only the per-hop entries (John removed the summary
  card from the approved mock).
- **Visual formatting beyond the above is the coding session's judgment, explicitly delegated by
  John — but sourced from the platform's style guide:** read `docs/STYLE-GUIDE.md` and
  `src/tokens.js` and use their tokens/typography/spacing idioms; match the console's existing
  look (trace console, Answer drawer). No new palette inventions.
