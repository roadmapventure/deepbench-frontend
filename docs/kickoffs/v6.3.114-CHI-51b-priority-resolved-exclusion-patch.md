## CONTEXT

**Patch to `S-CHI-51` (`v6.3.111`, shipped `bdcfc79`), found via this design session's own live Manual QA verification — a real bug, root-caused, not a coding-session deviation.** `S-CHI-51`'s own kickoff doc (`v6.3.111-CHI-51-drawer-persistence-resolution.md`) specified the `useDrawerStack()` priority list incorrectly; the coding session implemented it exactly as written. This is a design-session mistake, being corrected the way `STANDARDS.md`'s "no bug fails QA twice" rule requires — full root cause first, then a patch, not a blind retry.

**The bug, reproduced live:** drove a real theory flow (Vietnam/Thailand-Indonesia readiness question) to "Info Only" resolution — confirmed correct: Candidates/Result both persisted, collapsed, footer empty, nothing auto-open (matches `CHI-51`'s spec exactly). Then asked a **new, unrelated question** ("Apple Authorized Reseller requirements") — the new answer landed correctly in `qaEvidence`, but **`THEORY RESULT` re-opened instead of the new `ANALYSIS & NARRATIVE` drawer.** The exact edge case `CHI-51`'s own Architect Review flagged as the reason `useDrawerStack()` needed a `freshDeps`-driven suppression-lift mechanism in the first place — and it still fails, just one step later than expected.

**Root cause:** `useDrawerStack()`'s temporary `suppressed` state correctly blocks auto-open the instant resolution happens, and correctly clears the instant `freshDeps` (`[qaEvidence, newsCards]`) next changes. But the `priorityChecks` array itself — `["hyp-draft", isHypAwaitingConfirmation(hypFlow)]` / `["hyp-result", isHypInResultPhase(hypFlow)]` / `["hyp-candidates", !!hypFlow]` — was never told about resolution. `isHypInResultPhase(hypFlow)` stays `true` forever after resolving (by design — Task 2 deliberately keeps `hypFlow.stage`/`hypothesisTest`/`confirmation` populated so the drawers keep *rendering*, collapsed, reopenable). Once `suppressed` clears, the priority computation runs fresh — and `hyp-result` still evaluates `true`, so it wins again over the brand-new `qa`, even though the theory cycle is long since resolved. **The render-gate functions (`isHypInResultPhase`/`isHypAwaitingConfirmation`) are correctly reused for "does this drawer exist" (Task 2's whole point) — the bug is reusing those exact same booleans for "should this drawer win the auto-open race," which is a different question once resolved.**

**The fix:** the 3 hyp-related `priorityChecks` entries each gain an `&& !isHypResolved(hypFlow)` clause — for priority-selection purposes only. The drawers' own render gates (the `{isHypInResultPhase(hypFlow) && (...)}`/`{isHypAwaitingConfirmation(hypFlow) && (...)}`/`{hypFlow && (...)}` JSX conditions) are untouched — they still render post-resolution, exactly as `CHI-51` Task 2 intended. Only the hook's priority *ranking* changes.

### Task 1 — Exclude resolved hyp from priority ranking (not from rendering)

Change (find `const { isOpen: isDrawerOpen, toggle: handleDrawerToggle } = useDrawerStack(`):
```jsx
  const { isOpen: isDrawerOpen, toggle: handleDrawerToggle } = useDrawerStack(
    [
      ["hyp-draft", isHypAwaitingConfirmation(hypFlow)],
      ["hyp-result", isHypInResultPhase(hypFlow)],
      ["hyp-candidates", !!hypFlow],
      ["qa", !!qaEvidence],

    evidenceScrollRef,
    [hypFlow?.stage, newsCards],

```
to:
```jsx
  // FEATURE: CHI-51b — patch: the 3 hyp-related priority checks now also require
  // !isHypResolved(hypFlow). Without this, useDrawerStack()'s suppression correctly blocks
  // auto-open at the instant of resolution, but the moment it lifts (a genuinely new question
  // arriving), the priority list still ranked hyp-result/hyp-draft/hyp-candidates above qa —
  // isHypInResultPhase()/isHypAwaitingConfirmation() stay true forever post-resolution (Task 2's
  // deliberate design, so the drawers keep rendering/reopenable) but that same truth must not
  // also keep winning the auto-open race once the cycle is resolved. Render gates below (the

    [
      ["hyp-draft", isHypAwaitingConfirmation(hypFlow) && !isHypResolved(hypFlow)],
      ["hyp-result", isHypInResultPhase(hypFlow) && !isHypResolved(hypFlow)],
      ["hyp-candidates", !!hypFlow && !isHypResolved(hypFlow)],
      ["qa", !!qaEvidence],
      ["news", newsCards !== undefined],
    ],
    evidenceScrollRef,
    [hypFlow?.stage, newsCards],
    isHypResolved(hypFlow),
    [qaEvidence, newsCards]
  );
```

```js
// test-chi-51b.mjs — pure Node, no app imports.

let pass = 0, fail = 0;
function assert(cond, label) {
  if (cond) { pass++; console.log(`PASS: ${label}`); }
  else { fail++; console.log(`FAIL: ${label}`); }
}

function isHypInResultPhase(hypFlow) {
  return !!(hypFlow && (hypFlow.stage === "testing" || hypFlow.stage === "result" || hypFlow.stage === "committing" || hypFlow.confirmation));
}
function isHypAwaitingConfirmation(hypFlow) {
  return !!(hypFlow && hypFlow.confirmation);
}
function isHypResolved(hypFlow) {
  return !!(hypFlow && hypFlow.resolution);
}
function pickAutoCurrent(priorityChecks) {
  return priorityChecks.find(([, active]) => active)?.[0] ?? null;
}
// Mirror of Task 1's patched priorityChecks
function buildPriority(qaEvidence, hypFlow, newsCards) {
  return [
    ["hyp-draft", isHypAwaitingConfirmation(hypFlow) && !isHypResolved(hypFlow)],
    ["hyp-result", isHypInResultPhase(hypFlow) && !isHypResolved(hypFlow)],
    ["hyp-candidates", !!hypFlow && !isHypResolved(hypFlow)],
    ["qa", !!qaEvidence],
    ["news", newsCards !== undefined],
  ];
}

// --- Category A: unresolved flows rank exactly as before (regression guard) ---
{
  assert(pickAutoCurrent(buildPriority(null, null, [])) === "news", "nothing active: news (unchanged)");
  assert(pickAutoCurrent(buildPriority({ text: "a" }, null, [])) === "qa", "qaEvidence only: qa (unchanged)");
  assert(pickAutoCurrent(buildPriority({ text: "a" }, { stage: "choosing" }, [])) === "hyp-candidates", "choosing, unresolved: hyp-candidates (unchanged)");
  assert(pickAutoCurrent(buildPriority({ text: "a" }, { stage: "result", chosenText: "x", hypothesisTest: {} }, [])) === "hyp-result", "result, unresolved: hyp-result (unchanged)");
  assert(pickAutoCurrent(buildPriority({ text: "a" }, { stage: "result", confirmation: { proposed_action: {} } }, [])) === "hyp-draft", "confirmation, unresolved: hyp-draft (unchanged)");
}

// --- Category B: THE BUG, reproduced and confirmed fixed ---
{
  const resolvedResult = { stage: "result", chosenText: "x", hypothesisTest: {}, resolution: "info_only" };
  const newQaEvidence = { text: "a brand new answer" };
  assert(pickAutoCurrent(buildPriority(newQaEvidence, resolvedResult, [])) === "qa",
    "THE BUG: resolved hyp-result + fresh qaEvidence must rank qa first, not hyp-result — this is what failed live before the patch");

  const resolvedDraft = { stage: "result", confirmation: { proposed_action: {} }, resolution: "stored" };
  assert(pickAutoCurrent(buildPriority(newQaEvidence, resolvedDraft, [])) === "qa",
    "same bug, Accept path: resolved hyp-draft + fresh qaEvidence must rank qa first");

  const resolvedCandidates = { stage: "generating", resolution: "info_only" };
  assert(pickAutoCurrent(buildPriority(newQaEvidence, resolvedCandidates, [])) === "qa",
    "same bug, defensive case: resolved hyp-candidates + fresh qaEvidence must rank qa first");
}

// --- Category C: render gates (separate functions, NOT part of this patch) still return true
//     post-resolution — confirms Task 2's persistence is unaffected by this priority-only fix ---
{
  const resolvedResult = { stage: "result", chosenText: "x", hypothesisTest: {}, resolution: "info_only" };
  assert(isHypInResultPhase(resolvedResult) === true, "render gate still true post-resolve — drawer still exists (Task 2 unaffected)");
  const resolvedDraft = { stage: "result", confirmation: { proposed_action: {} }, resolution: "stored" };
  assert(isHypAwaitingConfirmation(resolvedDraft) === true, "render gate still true post-resolve — Draft Forecast still exists (Task 2 unaffected)");
}

console.log(`\n${pass} PASS, ${fail} FAIL`);
if (fail > 0) { console.log("ALL TESTS PASS: NO — fix before committing"); process.exit(1); }
console.log("ALL TESTS PASS");
```
