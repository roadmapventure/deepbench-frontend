## 2. CONTEXT
S-HAR-02b made the assembled prompt stable-first and delivered it to `callModel` as `system_prompt_stable` + `system_prompt_volatile`. This session turns caching on: the stable run goes into the real Anthropic `system` field as a content block carrying a `cache_control` breakpoint, and multi-hop loops get a second breakpoint on the conversation so each hop rereads the prior hops from cache. Decisions locked by John in the design session: (1) unconditional marking, no per-capability opt-in data — below-minimum prefixes (Haiku 4.5 floor: 4096 tokens) silently no-op at zero cost; (2) 5-minute TTL (`{type: "ephemeral"}`, the default); (3) two breakpoints total (limit is 4).

**Anthropic mechanics you must honor** (from the current API reference, verified this design session):
- Prefix match is over `tools` → `system` → `messages` in that order. Same capability+intent ⇒ same tools ⇒ same prefix; different intents are simply different cache entries. Nothing to do — just don't reorder tools.
- `cache_control: {type: "ephemeral"}` goes on a **content block**, so `system` must become a block array: `[{ type: 'text', text: stable, cache_control: { type: 'ephemeral' } }]`.
- Max 4 breakpoints per request — we use 2. A breakpoint's cache lookback is 20 content blocks; loop hops add ~2 blocks each, comfortably inside.

## 5. TASKS (3)

**Task 1 — `buildCallBody()`: stable run into cached `system` blocks.**
New optional params `systemPromptStable`, `systemPromptVolatile` (both strings; when absent, fall back to current single-`systemPrompt` behavior byte-identically — every non-loop caller that predates b's plumbing keeps working).
**The fallback is a live path, not just legacy:** S-HAR-02b confirmed `durable_hops` persists only the concatenated `system_prompt`, and `resumeCapability()` rebuilds from it — so every checkpoint-resumed hop legitimately arrives split-less. It must take the fallback (no `system` field restructure, no breakpoints, hop runs uncached) — safe degradation, deliberately accepted; do NOT attempt to re-derive or persist the split.
When the split is present:
- Both branches (tools and no-tools) set `system: [{ type: 'text', text: systemPromptStable, cache_control: { type: 'ephemeral' } }]`.
- The **volatile** text becomes the first user message content (where the whole `systemPrompt` string goes today): no-tools branch's message default, and the tools branch's `messages` when `conversation_history` is empty.
- Empty stable half (degenerate assembly): omit the `system` field entirely rather than sending an empty block (Anthropic rejects empty text blocks).

**Task 2 — conversation breakpoint, stamped at send time, never persisted.**
When `conversation_history` is non-empty:
- Build the request `messages` from a **copy** of the history; normalize the *final* message's `content` to block-array form if it's a plain string (`[{ type: 'text', text }]`), and stamp `cache_control: { type: 'ephemeral' }` on its **last** content block.
- **Never mutate `conversation_history` itself** — it is persisted to `durable_hops` (`execute.js` ~line 529) and replayed across checkpoint/resume; a persisted marker would accumulate one breakpoint per hop and blow the 4-breakpoint limit. Defensively strip any `cache_control` keys found on earlier messages of the incoming history (belt-and-suspenders against a marker that leaked into a checkpoint before this rule).
- `tool_result` blocks accept `cache_control` directly — stamp the block as-is, do not wrap it.

**Task 3 — `callModel()` plumbing.**
Thread `systemPromptStable`/`systemPromptVolatile` (already arriving from `execute.js` per S-HAR-02b) into `buildCallBody()` at every internal call site, including the parse-retry and guardrails-inline paths — grep every `buildCallBody(` occurrence in the file and account for each in your report. The retry path re-sending an identical body is exactly what makes the cache pay; do not vary the stable block between retries.

## 8. NODE.JS TEST (full code — save as `test-har-02c.mjs`, delete before committing)
```js
// test-har-02c.mjs — S-HAR-02c (v7.0.17). Categories B, G + live L below.
import assert from 'node:assert';
import { buildCallBody } from './api/prompt/request-receivable.js';

const fc = { output_type: 'json', skill_profile_slug: 'sp-x', schema: { type: 'object', properties: {} }, handler: 'store', guardrails: { must: [], must_not: [] } };
const base = { format_contract: fc, model: 'claude-haiku-4-5-20251001', max_tokens: 400 };

// 1) split present, no history: system is a cached block array; volatile is the user message
let b = buildCallBody({ ...base, systemPrompt: 'S+V', systemPromptStable: 'STABLE', systemPromptVolatile: 'VOLATILE', conversation_history: [] });
assert.ok(Array.isArray(b.system) && b.system.length === 1, 'system must be a 1-block array');
assert.equal(b.system[0].text, 'STABLE');
assert.deepEqual(b.system[0].cache_control, { type: 'ephemeral' });
assert.ok(JSON.stringify(b.messages).includes('VOLATILE'));
assert.ok(!JSON.stringify(b.messages).includes('STABLE'), 'stable text must not leak into messages');

// 2) legacy caller (no split): byte-compatible fallback, no cache_control anywhere
b = buildCallBody({ ...base, systemPrompt: 'WHOLE', conversation_history: [] });
assert.ok(!JSON.stringify(b).includes('cache_control'), 'no marker without the split');

// 3) history present: exactly 2 breakpoints total; final message's last block stamped; input history unmutated
const history = [
  { role: 'user', content: 'VOLATILE-TURN-1' },
  { role: 'assistant', content: [{ type: 'tool_use', id: 't1', name: 'x', input: {} }] },
  { role: 'user', content: [{ type: 'tool_result', tool_use_id: 't1', content: 'r1' }] },
];
const frozen = JSON.stringify(history);
b = buildCallBody({ ...base, systemPrompt: 'S+V', systemPromptStable: 'STABLE', systemPromptVolatile: 'VOLATILE', canRequestHelp: true, conversation_history: history });
assert.equal(JSON.stringify(history), frozen, 'conversation_history must not be mutated');
const markers = JSON.stringify(b).match(/cache_control/g) || [];
assert.equal(markers.length, 2, `expected exactly 2 breakpoints, got ${markers.length}`);
const lastMsg = b.messages[b.messages.length - 1];
const lastBlock = lastMsg.content[lastMsg.content.length - 1];
assert.deepEqual(lastBlock.cache_control, { type: 'ephemeral' });

// 4) stray persisted markers on earlier turns are stripped (never >4 breakpoints as hops grow)
const dirty = [
  { role: 'user', content: [{ type: 'text', text: 'h1', cache_control: { type: 'ephemeral' } }] },
  { role: 'assistant', content: [{ type: 'text', text: 'a1', cache_control: { type: 'ephemeral' } }] },
  { role: 'user', content: [{ type: 'text', text: 'h2' }] },
];
b = buildCallBody({ ...base, systemPromptStable: 'STABLE', systemPromptVolatile: 'V', canRequestHelp: true, conversation_history: dirty });
assert.equal((JSON.stringify(b).match(/cache_control/g) || []).length, 2, 'stray markers must be stripped');

// 5) string-content final message gets normalized to a block array
b = buildCallBody({ ...base, systemPromptStable: 'STABLE', systemPromptVolatile: 'V', canRequestHelp: true, conversation_history: [{ role: 'user', content: 'plain string turn' }] });
const lm = b.messages[b.messages.length - 1];
assert.ok(Array.isArray(lm.content) && lm.content[lm.content.length - 1].cache_control, 'string content must be normalized and stamped');

console.log('ALL TESTS PASS');
```
