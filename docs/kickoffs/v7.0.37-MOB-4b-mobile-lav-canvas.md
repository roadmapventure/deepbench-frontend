## 2. CONTEXT
The desktop canvas is a 1200×640 viewBox with 132px fixed-pixel node cards positioned as percentages of a box locked to that aspect ratio. It cannot reflow to 402px — eleven cards at 132px do not fit. This session gives `AgentNetwork` a mobile branch with **two user-picked views of the same real data**.

John's rules, from the design walkthrough (`design-lav-mobile-0801`, 2026-08-01):
- **Bench is the default view.** It shows **only the agents this run actually called** — an uncalled agent's slot stays empty, and that gap is the information.
- **Every agent occupies the same position on every run**, so the user learns where to look. This is the opposite of desktop, where `computeTargets()` deliberately moves the lead agent to a fixed `LEAD` anchor and arcs the engaged around it. **That divergence is intentional; do not "fix" mobile to match desktop's moving layout.**
- **Active** is the second view: the current hand-off at full card size.
- **There is no auto-switch.** An earlier design pass had the view widen automatically on the first `delegation_return`; John's Bench-as-default supersedes it. The toggle is the only thing that moves the view.

### Task 2 — Bench view: permanent slots derived from roster index, called agents only
Add this exported helper. It mirrors `homeLayout()`'s standing rule (L281: *"computed from roster order — there is no hand-authored position table and no hand-listed agent id"*):
```js
// FEATURE: MOB-4b -- mobile Bench slots. Returns PERCENTAGES of the mobile stage box, the same
// units the desktop node cards already position in. index is the agent's index in the roster
// array, never its position in the engaged list -- that is the whole point: an agent occupies the
// same slot on every run, so the user learns where to look. roster[0] takes the hub; the rest ring
// around it. Nothing here names an agent, so a 12th agent joining the mi bench group claims the
// next slot with no code change, exactly as homeLayout() behaves today.
export function mobileSlot(index, total) {
  if (index === 0) return { x: 50, y: 52 };
  const n = Math.max(1, total - 1);
  const ang = (-90 + (index - 1) * (360 / n)) * Math.PI / 180;
  return { x: 50 + 38 * Math.cos(ang), y: 52 + 35 * Math.sin(ang) };
}
```
Render, when `mobileView === "bench"`:
- **Only called agents.** Iterate the `roster` prop with its index; skip any agent not in the run's engaged set. Use the engaged set the component **already derives** (`deriveNetwork`'s result — grep for `net.engaged`); do not compute a second one.
- Each rendered agent is a compact node at `left:${slot.x}%`, `top:${slot.y}%`, `transform:translate(-50%,-50%)`, width 56px: a 38px `<AgentAvatar/>`, then `a.code` (mono 7px, weight 700, `T.muted`, uppercase), then the agent's **first name only** (`body` 8px, weight 600, `T.navy`). No role, no model tag, no pattern pill at this size.
- Keep the existing state classes' meaning: the orchestrator/active/assembly/done/recovering distinctions still apply, expressed here as the avatar's own glow (`filter:drop-shadow`) rather than a card border, since there is no card.
- **Edges are the real observed ones, not hub spokes.** Reuse `sessionEdges(hops, runHops, running)` and render each edge between its two endpoints' `mobileSlot` positions, through the existing `ePath`/`isLitEdge` path and the existing meaning colours. An edge whose endpoint agent is not rendered is skipped. Do **not** invent a star topology.
- The SVG edge layer is a **direct child** of the mobile stage. Scope its CSS rule to `.lav-stage > svg` (or an explicit class) — a bare descendant selector also matches the avatar SVGs inside the nodes and will stretch them to the container width. *(Found live in the design mock: `width:100%` on a descendant `svg` rule blew every 44px avatar up to 126px and collapsed the cards.)*

### Task 3 — Active view: the current hand-off at full size
When `mobileView === "active"`:
- Render the two agents of the most recent lit delegation edge — the component already tracks it (grep `litEdge`) — as **full-size cards** (the existing `.lav-card` treatment with avatar, code, name, role, model tag and pattern pill, all legible), the dispatcher at `top:24%` and the recipient at `top:76%`, both `left:50%`.
- Between them, a vertical connector in the edge's own meaning colour with that edge's own word from `EDGE_MEANING_LABEL` beside it. - Speech bubbles behave as they do on desktop.

## 8. NODE.JS TEST (full code — save as `test-mob-4b.mjs`, delete before commit)
```js
// S-MOB-4b inline test: mobileSlot's stability and geometry contract. Pure Node -- the .jsx module
// can't be imported here, so the helper is mirrored from the kickoff spec; the committed
// implementation must match verbatim.
function mobileSlot(index, total) {
  if (index === 0) return { x: 50, y: 52 };
  const n = Math.max(1, total - 1);
  const ang = (-90 + (index - 1) * (360 / n)) * Math.PI / 180;
  return { x: 50 + 38 * Math.cos(ang), y: 52 + 35 * Math.sin(ang) };
}
let pass = true;
const check = (name, cond, extra = "") => {
  if (!cond) { pass = false; console.error(`FAIL ${name} ${extra}`); } else console.log(`ok ${name}`);
};
const N = 11;
const all = Array.from({ length: N }, (_, i) => mobileSlot(i, N));

check("hub is centre", all[0].x === 50 && all[0].y === 52);
check("slot 1 is top-centre", Math.abs(all[1].x - 50) < 0.001 && all[1].y < 52);

// THE contract: an agent's slot depends only on its roster index, never on which agents ran.
// Simulate two runs calling different subsets and assert the shared agents did not move.
const runA = [0, 4, 6, 3];        // michelle, marcus, nadia, eleanor
const runB = [0, 6, 9, 3, 10];    // michelle, nadia, elena, eleanor, jordan
for (const i of runA.filter(i => runB.includes(i))) {
  const a = mobileSlot(i, N), b = mobileSlot(i, N);
  check(`index ${i} identical across runs`, a.x === b.x && a.y === b.y);
}
check("distinct indices get distinct slots",
  new Set(all.map(s => `${s.x.toFixed(4)},${s.y.toFixed(4)}`)).size === N);

// Every slot must sit inside the stage with room for a 56x60 node box (~7% x, ~6.5% y half-extent).
for (let i = 0; i < N; i++) {
  const s = all[i];
  check(`slot ${i} inside x bounds`, s.x >= 7 && s.x <= 93, `x=${s.x.toFixed(1)}`);
  check(`slot ${i} inside y bounds`, s.y >= 7 && s.y <= 93, `y=${s.y.toFixed(1)}`);
}
// No two ring slots may overlap a 56px-wide (13.9% of 402) x 60px-tall (13.4% of 447) box.
for (let i = 1; i < N; i++) for (let j = i + 1; j < N; j++) {
  const a = all[i], b = all[j];
  check(`ring ${i}/${j} no overlap`,
    Math.abs(a.x - b.x) >= 13.9 || Math.abs(a.y - b.y) >= 13.4,
    `dx=${Math.abs(a.x - b.x).toFixed(1)} dy=${Math.abs(a.y - b.y).toFixed(1)}`);
}
// Growth: adding a 12th agent must not throw and must keep the hub put.
check("12th agent keeps hub at centre", mobileSlot(0, 12).x === 50 && mobileSlot(0, 12).y === 52);
check("single-agent roster degrades safely", mobileSlot(0, 1).x === 50);
console.log(pass ? "ALL TESTS PASS" : "TESTS FAILED");
if (!pass) process.exit(1);
```
