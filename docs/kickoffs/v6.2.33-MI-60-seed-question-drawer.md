## 2. CONTEXT

`InteractColumn`'s empty state (shown only before the first message, `messages.length === 0`) currently offers 3 static example-question buttons (`EXAMPLE_QUESTIONS`). This session adds a 4th box beneath them: a collapsed `Drawer` (the same accordion component already used in Column 3 for Agents/Data Sources/Analysis) labeled "Browse 20 more example questions" with a `(20)` count badge. Expanding it reveals the 20 realistic VP-of-Channel-Sales questions drafted and pipeline-tested by the 2026-07-08/09 overnight session (`AA-172`/`AA-173`, `docs/FEATURES.md`), letting a user pick one instead of typing.

Design session walkthrough with John (2026-07-14) confirmed both open questions before this kickoff was written:
- **Click behavior:** clicking any of the 20 auto-sends immediately — identical to the existing 3 buttons, not populate-then-review.
- **Visibility:** the whole box disappears once the first message is sent, identical to the existing 3 — no persistent/mid-conversation access.

Because `InteractColumn` is locked (`MI-45`) as reused *unmodified* on mobile (no mobile branch), this ships identically on both desktop and mobile by construction — the `Drawer`'s own `maxHeight`+internal-scroll keeps the 20-item list from growing the card past its cap, which stays compatible with `MobileBody`'s "no page-level scroll" rule with zero mobile-specific code.
