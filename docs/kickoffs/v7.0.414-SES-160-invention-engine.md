### Task 1 — Migration `ses160_invention_engine`

1. `runner_settings`: `invention_floor_days int NOT NULL DEFAULT 7`, `invention_per_rung_per_day int NOT NULL DEFAULT 1`, `invention_requires_epic boolean NOT NULL DEFAULT true`. Add the three to the reversal allowlist the same way `cap_relax_rung` is (read `reverse_decision()`'s allowlist).
2. `public.invention_due()` → `(due boolean, allowed integer, reason text)`: reads the `invention` rung, the settings, `enhancement_week_spent_pct()` vs `enhancement_cap_pct`, and the newest `runner_decisions` row of kind `invention` (not reversed): at rung 0, due iff none in the last `invention_floor_days` days; at rung n, due iff fewer than `n × invention_per_rung_per_day` today (CST). `allowed` = how many now. 3. `public.file_invention_proposal(p_cycle uuid, p_session text, p jsonb)` → `backlog_id`: one transaction — claims the next `SES` id from `feature_id_counter` (the 3b shape, never hand-counted), `record_decision(kind 'invention', summary = the title, reasoning = p->>'rationale')`, the canonical 3c INSERT with `scope_origin 'enhancement'`, `priority_class` = `p->>'class'` (must be P1–P4, else raise), `scope_rationale`, `enhancement_claim` (must pass `outcome_claim_is_valid()`), `predicted_cycles`, `size_stamp`, `epic_id` = the standing drain's epic when `invention_requires_epic`, `milestone` = that epic's M-code, `milestone_required false`, `description` = `p->>'description'` which **must** contain at least one `VC-` claim ref and one `docs/research/` path (raise otherwise — a proposal with no evidence is a feature mill, §19d), a NULL-`row_data` before-image under the decision (the `SES-312` filed-row shape), `recompute_backlog_queue()`. Returns the id.

Idempotent per decision.
