## 5. TASKS

### Task 1 — Rewrite the pick predicate (migration `ses281_m5_pick_enforcement`)

`CREATE OR REPLACE` **both** `drain_epic_next(uuid)` and `prime_directive_queue()`. They must stay in agreement — `prime_directive_queue`'s own header says the page and the gate "cannot disagree about whether the Prime Directive stands," and that property must survive this change.

- **`M5-01` structural fence:** the pick joins `epics` and requires `e.name ILIKE 'Selfbuild%'`, so a mis-scoped `runner_drain_scope` row cannot surface non-Selfbuild work.
- **`M5-02` filing lane, replacing bare queue order.** New ordering, in this precedence:
  1. `b.filed_at < DATE '2026-08-21'` first (the priority lane), post-8/21 second (the review bucket).
  2. then `b.queue` ascending.
  3. then **`M5-07`**: `b.predicted_cycles` ascending nulls last.
  **`filed_at`, never `created_at`** — `SES-295` fixed `ticket_matrix` for exactly this reason; `created_at` is the board-migration bulk-load stamp and misdates most of the board by up to 68 days.
- **`M5-09` gate check:** a member is unpickable while its epic's own design-gate ticket is unresolved. Identify the gate as the epic's member whose `scope_origin = 'original'` and whose title matches `'M% design gate%'`; unresolved means `status <> 'done'`. **A gate ticket must never block itself** — the predicate excludes the gate row from its own test, or M5 deadlocks permanently.
- **`c_flagged` becomes `ARRAY['needs-desktop']`** in both functions. Drop `needs-john` (retired) and `john-paced` (converted in Task 2).

### Task 3 — Test `tests/regression/ses-281-m5-pick-enforcement.test.mjs`

Discriminating assertions — each must fail if the change did nothing:

1. **Lane precedence:** given a post-8/21 ticket at a *lower* queue number than a pre-8/21 ticket, the pre-8/21 one is returned first. (Fails today: bare `ORDER BY queue` returns the post-8/21 row.)

6. **Zero open tickets carry `john-paced`.**
7. **Agreement:** `drain_epic_next` and `prime_directive_queue` return the same next ticket for the standing drain.
