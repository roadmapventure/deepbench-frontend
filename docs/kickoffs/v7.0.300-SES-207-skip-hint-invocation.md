## Scope constraint, named rather than worked around

`CLAUDE.md`: **max 3 files**. Seven sites plus the guard is eight files. Correcting the strings
by hand cannot be done in one cycle under the cap, and doing it across three cycles would still
leave the propagation mechanism intact.

## The fix — one home, two files

Every one of those seven strings reaches a human through exactly one function:
`renderNotRun()` in `tests/regression/_lib/self-run.js`, called by `run-all.js` after every module
and by `selfRun()` on a direct run. That is the seam.

1. **`tests/regression/_lib/self-run.js`** — `repairInvocation()`, a pure literal one-token swap
   (`--env-file=` → `--env-file-if-exists=`), applied to every declaration's reason at render time;
   plus one repair notice naming `STANDARDS.md Section 2 rule 5`, emitted **only when a repair
   actually happened**.
2. **`tests/regression/SES-61-suite-invocation.js`** — extend the existing guard (never a second
   guard file) with clauses for the new behaviour, each with its own negative control, in the idiom
   that file already uses.

**Why a swap and not a stored copy of the command.** The module holds the *token*, never the
invocation, so this does not become the ninth hand-maintained copy of
`node … tests/regression/run-all.js` — which is the trap the ticket names. The corrected text is
derived from whatever the test wrote.

**Why the swap is safe.** `--env-file-if-exists=` does not contain the substring `--env-file=`
(after `--env-file` comes `-`, not `=`), so the replacement is **idempotent** — a reason that is
already correct comes back byte-identical. Asserted, not assumed.

**Why the repair is announced rather than silent.** Silently rewriting a test's own message would
be hiding the defect. The notice says the hint was repaired and why, so the source rot stays
visible while no reader is ever handed the hard-erroring command.

## What this does NOT do — declared remainder

The seven **source** strings still read `--env-file=`. They are inert (nothing prints them
unrepaired) but they remain copyable. The ticket's suggested guard shape — *"no `--env-file=`
outside `--env-file-if-exists=` remains under `tests/regression/`"* — is a **source-level**
assertion this ship does not satisfy, and that is a named deviation, not an oversight: shipping it
today would paint the suite red over seven files the cap forbids touching. Filed as a follow-up
rather than left to be found.
