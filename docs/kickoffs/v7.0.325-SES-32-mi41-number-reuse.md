## QA

`tests/regression/SES-32-mi41-number-reuse.js`, seven parts:

- **Four clauses read out of the shipped kickoff, never restated in the test**, each with its own
  negative control: `names-the-reuse` (a bare *"related to"* must fail), `forbids-the-close`,
  `cites-the-existing-record` (without the archive citation the correction reads as invented at
  correction time), `carries-the-live-measurement`.
- **The `SES-158` vacuity meta-check**, because a control that changes nothing proves nothing.
- **A file-level negative control**: the pre-change file is reconstructed in-process by stripping
  the added sub-bullet, and **4 of 4 clauses fail on it, 4 of 4 pass on the shipped one**. It
  asserts the reconstruction *keeps* the original fold sentence, so the control cannot pass for the
  wrong reason. Reconstructed rather than read from `origin/dev` **deliberately** — `SES-240` is the
  open finding that asserting against that moving ref fails for reasons unrelated to the subject.
- **The discriminating semantic check.** `resolveFold()` compares the *subject* of a fold against
  the subject of the row still carrying the id. The negative control **is the retired reading** —
  the naive *"folds in means closed"* rule applied to the same fixture and asserted to reach the
  **opposite** verdict. Two more arms stop the fix over-firing: a genuine fold (subjects match) and
  a fold whose secondary id has no surviving row — the original `MI-41` — both still resolve
  `discharged`.
- **`MI-41`'s premise, measured from the real source, both directions.** `AuditColumn`'s wrapper
  must still lack the chain (or the *"do NOT close"* clause is guarding a dead ticket and the test
  says so in those words), **and** `InteractColumn`'s must still have it — otherwise the first
  assertion passed because the detector is broken, which is
  `.claude/rules/supabase-column-grants.md`'s both-directions rule applied to a source grep.

Would any of it still pass if the change did nothing? No: the file-level control is exactly that
experiment, run rather than argued.
