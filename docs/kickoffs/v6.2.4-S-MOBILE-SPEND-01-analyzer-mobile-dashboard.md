## 2. CONTEXT

Follow-on to `S-MOBILE-NAV-01` (v6.2.0, mobile hamburger drawer), which routes the drawer's "Spend Analysis" item to `/work/1/analyze` (`taskId === "1"`) — the same task id that already triggers the existing Austin FY2025 demo auto-load (`AZ-18`, in `DataSourceScreen`'s mount effect). So a mobile user tapping "Spend Analysis" today already lands on real, auto-loaded data almost immediately — the screen just isn't laid out for a phone viewport at all: a fixed 200px sidebar with 12 tabs across 4 groups, a KPI strip, and side-by-side charts.

Design was scoped down live with John across several rounds, narrowing from "the whole 12-tab screen" to a much smaller, concrete slice:

**Locked decisions (all confirmed by John, do not re-litigate):**
1. **Scope is 2 mobile "pages", not the full 12-tab screen.** Page 1 = a combined landing-and-dashboard view (header/description/workflow-strip + KPI grid + the two Dashboard-tab charts). Page 2 = column mapping. The other 11 tabs (Categories, Treemap, Vendors, Timeline, Departments, Concerns, Local Spend, Vendor Diversity, AI Review, Cleanup, Full Table) are **out of scope** — still reachable only via desktop, not mobile-optimized this session, no mobile tab-picker is being built for them.
2. **Page 1 combines what were two separate stage-gated screens** (`DataSourceScreen`'s intro/workflow-strip, `AnalyzerView`'s Dashboard-tab KPI+charts) **into one mobile view**, shown for both the `stage==="overview"` (no data yet) and `stage==="analyze"` (data loaded) states — not two separate mobile screens. Before data loads: header + workflow strip + "Load your data" button only. Once data loads (which, via `AZ-18`, happens almost immediately for the `/work/1/analyze` route): the same view also shows a **"Now analyzing: `<fileName>`"** label (porting the desktop sidebar's existing "Now Analyzing" info into the mobile body, since mobile drops the sidebar entirely) plus the KPI grid and both charts.
3. **No fake/sample-data preview state.** If `data` is null (rare in practice given `AZ-18`'s near-instant auto-load), Page 1 shows only the header/workflow-strip/button — no placeholder numbers.
4. **"Load your data" is upload-only for this session — explicitly not touching Demo/Fetch.** John: "just load data for now — don't want to mess with the others til later." The button opens the file picker directly (no intermediate 3-card chooser on mobile). Demo dataset and Fetch State Data remain desktop-only conveniences, untouched by this session.
5. **Column mapping (Page 2) stacks each field row** (currently `label | select` side-by-side) to label-above-select. Functionally unchanged — same fields, same `runAnalysis` call.
6. **The "← Column Mapping" back control moves into the screen's own body on mobile**, per the already-locked `STYLE-GUIDE.md` §24 rule: *"`rightContent`/`onBack` are not rendered on mobile at all... the fix belongs in the calling screen."* Do not add a mobile exception back into `AppShell.jsx` — this is Analyzer's own retrofit, closing its specific instance of `SH-20`.
7. **Desktop is completely untouched.** Every change in this session is gated by `useIsMobile()`; the existing 12-tab sidebar flow, `DataSourceScreen`'s 3-card chooser, and `MappingScreen`'s side-by-side field rows all render exactly as they do today at ≥768px.

### Task 1 — New `MobileAnalyzerHome` component (Page 1: combined landing + dashboard)

Add a new function component in `AnalyzerScreen.jsx`, alongside `DataSourceScreen`/`MappingScreen`/`AnalyzerView`. It owns the mobile-only auto-load effect (ported from `DataSourceScreen` — that component no longer mounts on mobile, so its copy of the effect never runs there) and the mobile Dashboard-tab layout.

```jsx
function MobileAnalyzerHome({ taskId }) {
  const {
    autoLoaded, setAutoLoaded, processFile, setError, error,
    data, fileName, stage, setStage, setActiveTab, highFlags,
  } = useAnalyzer();
  const hiddenRef = useRef();

  // Ported from DataSourceScreen's mount effect (AZ-18) — DataSourceScreen doesn't
  // mount on mobile, so this session needs its own copy of the auto-load logic.
  useEffect(() => {
    if (autoLoaded) return;
    if (!taskId) return;
    setAutoLoaded(true);
    if (taskId === "1") {
      (async () => {
        try {
          const res = await fetch("/Austin_2025Data_.csv");
          if (!res.ok) throw new Error("Could not load demo file");
          const blob = await res.blob();
          processFile(new File([blob], "Austin_2025Data_.csv", { type: "text/csv" }), null, true);
        } catch (e) { setError("Demo failed: " + e.message); }
      })();
    }
    // Non-demo taskId (Storage-loaded return visit) is out of scope for this session —
    // desktop's DataSourceScreen still handles that path; mobile's first shipped
    // destination is exclusively the /work/1/analyze demo route (S-MOBILE-NAV-01).
  }, [taskId]);

  const top15C = useMemo(() => data?.classArr.slice(0,15) || [], [data]);
  const pieData = useMemo(() => {
    if (!data) return [];
    const top = data.classArr.slice(0,9);
    const other = data.classArr.slice(9).reduce((s,x)=>s+x.total,0);
    const r = top.map(x=>({name:x.displayLabel, value:x.total}));
    if (other>0) r.push({name:"All Other", value:other});
    return r;
  }, [data]);
  const kpis = data ? [
    {label:"Total Spend",  value:fmtFull(data.totalSpend)},
    {label:"Transactions", value:data.txCount.toLocaleString()},
    {label:"Health Flags", value:data.flags.length, flagged:highFlags>0},
    ...(data.hasVendor && data.vendorConc ? [{label:"Vendor HHI", value:data.vendorConc.hhi.toFixed(0), flagged:data.vendorConc.hhi>2500}] : []),
  ] : [];

  const loadYourData = () => hiddenRef.current.click();

  return (
    <div style={{flex:1,overflowY:"auto",background:T.paperDeep,padding:"18px 16px 40px"}}>
      <div style={{fontFamily:mono,fontSize:9,letterSpacing:2,textTransform:"uppercase",color:T.brass,marginBottom:8}}>Roadmap Venture · Procurement Intelligence</div>
      <div style={{fontFamily:display,fontSize:22,fontWeight:700,color:T.navy,marginBottom:8,letterSpacing:"-.5px"}}>Government Spend Analyzer</div>
      <p style={{fontSize:12.5,color:T.muted,lineHeight:1.6,marginBottom:16}}>Load procurement data from a demo dataset, a live state portal, or your own file.</p>

      {/* Workflow strip — horizontal scroll instead of the desktop 5-col grid */}
      <div style={{display:"flex",overflowX:"auto",gap:6,marginBottom:18,paddingBottom:4}}>
        {[
          {n:"01",label:"Load Data",   active:!data},
          {n:"02",label:"Map Fields",  active:false},
          {n:"03",label:"Analyze",     active:!!data},
          {n:"04",label:"Act",         active:false},
        ].map((s,i)=>(
          <div key={i} style={{flex:"0 0 auto",background:s.active?T.navy:T.card,color:s.active?T.brass:T.navy,border:s.active?"none":`1px solid ${T.line}`,padding:"8px 10px",fontSize:9,fontWeight:600,whiteSpace:"nowrap"}}>{s.n} {s.label}</div>
        ))}
      </div>

      {data && (
        <div style={{marginBottom:14,paddingBottom:10,borderBottom:`1px solid ${T.line}`}}>
          <div style={{fontSize:8.5,color:T.brassDeep,textTransform:"uppercase",letterSpacing:1.6,fontWeight:600,marginBottom:3,fontFamily:mono}}>Now Analyzing</div>
          <div style={{fontFamily:display,fontSize:13.5,fontWeight:600,color:T.navy}}>{fileName.replace(/\.csv$/i,"")}</div>
          <div style={{fontSize:10,color:T.muted,marginTop:2,fontFamily:mono}}>{data.txCount.toLocaleString()} rows</div>
        </div>
      )}

      {data && (
        <>
          <div style={{display:"grid",gridTemplateColumns:"1fr 1fr",gap:8,marginBottom:16}}>
            {kpis.map(k=>(
              <div key={k.label} style={{background:T.card,border:`1px solid ${T.line}`,padding:"10px 12px"}}>
                <div style={{fontSize:8,color:T.muted,textTransform:"uppercase",letterSpacing:1.2,marginBottom:4,fontFamily:mono}}>{k.label}</div>
                <div style={{fontFamily:display,fontSize:15,color:k.flagged?T.flag:T.navy,fontVariantNumeric:"tabular-nums"}}>{k.value}</div>
              </div>
            ))}
          </div>

          <Card title="Categories by Spend">
            <ResponsiveContainer width="100%" height={260}>
              <BarChart data={top15C.slice(0,6).map(x=>({...x,label:x.displayLabel}))} layout="vertical" margin={{left:10,right:50,top:5,bottom:5}}>
                <XAxis type="number" tickFormatter={fmt} tick={{fill:T.muted,fontSize:9,fontFamily:mono}} axisLine={false} tickLine={false}/>
                <YAxis type="category" dataKey="label" width={90} tick={{fill:T.mutedDeep,fontSize:9,fontFamily:body}} axisLine={false} tickLine={false}/>
                <Tooltip content={<Tip total={data.totalSpend}/>}/>
                <Bar dataKey="total" radius={[0,3,3,0]}>
                  {top15C.slice(0,6).map((_,i)=><Cell key={i} fill={PALETTE[i%PALETTE.length]} fillOpacity={0.9}/>)}
                </Bar>
              </BarChart>
            </ResponsiveContainer>
          </Card>

          <div style={{height:12}}/>

          <Card title="Spend Distribution" subtitle="Share of total by category">
            <div style={{width:"100%",height:260,position:"relative"}}>
              <ResponsiveContainer width="100%" height="100%">
                <PieChart margin={{top:10,right:10,bottom:0,left:10}}>
                  <Pie data={pieData} cx="50%" cy="42%" outerRadius={80} dataKey="value" nameKey="name" label={({percent})=>percent>0.08?`${(percent*100).toFixed(0)}%`:""}>
                    {pieData.map((_,i)=><Cell key={i} fill={PALETTE[i%PALETTE.length]} stroke={T.paperDeep} strokeWidth={2}/>)}
                  </Pie>
                  <Tooltip content={<Tip/>}/>
                </PieChart>
              </ResponsiveContainer>
            </div>
          </Card>

          <div style={{height:16}}/>
        </>
      )}

      <div onClick={loadYourData} style={{padding:"12px 0",background:T.brass,color:T.navy,textAlign:"center",fontWeight:700,fontSize:13,fontFamily:display,cursor:"pointer"}}>Load your data →</div>
      <input ref={hiddenRef} type="file" accept=".csv" style={{display:"none"}} onChange={e=>{ if(e.target.files[0]) processFile(e.target.files[0], taskId); }}/>

      {error && <div style={{marginTop:14,background:`${T.flag}10`,border:`1px solid ${T.flag}44`,padding:"12px 16px",color:T.flag,fontSize:13}}>⚠ {error}</div>}
      <FeatureBadge id="AZ-19"/>
    </div>
  );
}
```

- Mobile "← Back" control on `MappingScreen`: same button styling already used elsewhere for secondary actions (card border, `T.card` background, `T.navy` text) — not a new visual pattern

```js
let pass = 0, fail = 0;

assert("T1a: stage 'overview' (no data yet) resolves to combined home page", resolveMobilePage("overview") === "home");
```
