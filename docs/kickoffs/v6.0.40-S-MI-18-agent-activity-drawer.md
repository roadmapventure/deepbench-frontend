## 2. CONTEXT

John asked to design "the 3rd column, agent list drawer." `docs/FEATURES.md` already had two overlapping, never-reconciled entries for this: `MI-06` (local AI Audit drawer — per-agent pattern/cost/latency counts, all 6 v5 agents, originally gated on `AI-38`'s taxonomy field) and `MI-18` (Available Agents drawer — roster cards with bio/patterns/usage, carried from the v4 mock's "Available Agents" drawer). `MI-18`'s own FEATURES.md text already flagged this explicitly: "significant content duplication with `MI-06`... whichever session designs this must resolve the overlap... before speccing it." This session resolves it by merging both into one drawer — one card per agent, showing identity (avatar/name/role/specialty) and live usage (calls/latency/cost) together, which is what both entries wanted separately.

**Design revision, confirmed with John this session:** rather than gating the drawer on `AI-38` (generalizing the unused `isAppleChannel` boolean into a `section` field on `agents.js`, so the roster carries a page-affinity tag), the drawer is a **portable, dynamic mechanism**: any screen that renders it supplies its own hardcoded `proposedAgentIds` list (page-scoped, lives in the page's own file — not on the agent record, so `agents.js` stays platform-wide and page-agnostic). Whether an agent renders **Active** (full color) or **Potential** (muted, `opacity: 0.38`) is derived live from whether `ai_activity_log` has any row for that `agent_id` — never a stored flag, so it "self-populates" the moment an agent's first real call lands and never reverts.

**Real constraint found and designed around:** the existing `useAIActivity()` hook's `byAgent` aggregation is backed by an in-memory log capped at 500 rows (`hydrateFromSupabase()`'s `.limit(500)`) — a rolling window, not full history. An agent used only occasionally could scroll out of that window and get wrongly demoted back to "Potential." This session's new hook queries Supabase directly and independently of that capped log — see Task 1.

`isAppleChannel` becomes fully dead once nothing reads it (confirmed via grep this design session — zero UI consumers today). Removed in Task 3, approved explicitly by John.

**Not in this session, left open:** `AI-38`'s other half — the *global* AI Audit screen's "By Agent" section grouping (unrelated code path, `src/components/AIActivityPanel.jsx`, confirmed untouched by this session) — stays unscheduled. `docs/FEATURES.md`'s `AI-38` row is narrowed at close-out to reflect that its local-drawer prerequisite no longer applies.

### Task 1 — `src/hooks/useAgents.js`: add `useAgentActivitySummary(agentIds)`

Add below `useAgentUsageCounts()`. **Not a modification of `useAgentUsageCounts()`** — that hook's flat `{agentId: number}` shape is consumed directly as a number by `RosterScreen.jsx:163-165`'s sort comparator (`usageCounts[a.id] || 0`); changing its return shape would silently break that sort. This is a separate hook with a richer per-agent shape and an `agentIds` filter (so callers only query the agents they care about, not an unfiltered full-table scan every mount):

```js
// FEATURE: MI-18 — per-agent all-time usage summary (calls/avgLatency/avgCost) for a given set of
// agent IDs. Distinct from useAgentUsageCounts() above (RO-09): deliberately not reused/modified,
// see Task 1 note in the kickoff doc — that hook's flat number shape is a direct sort-comparator
// input in RosterScreen.jsx, changing it would silently break that sort. Also distinct from
// useAIActivity()'s byAgent (src/hooks/useAIActivity.js): that aggregation is backed by an
// in-memory log capped at 500 rows (hydrateFromSupabase()'s .limit(500)) — a rolling window, not
// full history, so an occasionally-used agent could scroll out of it and be wrongly reported as
// unused. This hook queries Supabase directly, independent of that cap, so an agent's "used at
// least once, ever" status is never lost.
export function useAgentActivitySummary(agentIds) {
  const [summary, setSummary] = useState({});

  useEffect(() => {
    if (!agentIds || agentIds.length === 0) { setSummary({}); return; }
    supabase
      .from('ai_activity_log')
      .select('agent_id,latency_ms,cost_usd')
      .eq('tenant_id', 'global')
      .in('agent_id', agentIds)
      .then(({ data, error }) => {
        if (error || !data) return;
        const map = {};
        for (const row of data) {
          if (!row.agent_id) continue;
          if (!map[row.agent_id]) map[row.agent_id] = { calls: 0, totalLatency: 0, latencyCount: 0, totalCost: 0 };
          const d = map[row.agent_id];
          d.calls++;
          if (row.latency_ms) { d.totalLatency += row.latency_ms; d.latencyCount++; }
          if (row.cost_usd) { d.totalCost += parseFloat(row.cost_usd); }
        }
        Object.values(map).forEach(d => {
          d.avgLatency = d.latencyCount ? Math.round(d.totalLatency / d.latencyCount) : null;
          d.avgCost = d.calls ? d.totalCost / d.calls : null;
        });
        setSummary(map);
      });
  }, []); // agentIds is a stable, page-defined constant — same no-deps precedent as useLearnedContext() above

  return summary;
}
```
