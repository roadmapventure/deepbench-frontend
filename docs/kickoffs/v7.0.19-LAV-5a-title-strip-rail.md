### Task 3 — Prompt box: 4-line preview, skip the leading OUTPUT FORMAT block
In `LiveAgentViewScreen.jsx` (`PromptBox`):
- `WebkitLineClamp: 2` → `4`.
- Add and use this exported helper (export it for the test + future reuse):
```js
// The assembled prompt is `=== LABEL ===` blocks joined by "\n\n---\n\n" (api/prompt/ai-enrichment.js
// renderSection/assembleSystemPrompt; HAR-02b orders the format section first, deliberately, for
// prompt caching). The PREVIEW starts after a leading OUTPUT FORMAT block; the popover keeps the
// full untouched text — the record is never altered, only where the preview window starts.
export function promptPreviewText(text) {
  if (typeof text !== "string" || !text) return text;
  const blocks = text.split("\n\n---\n\n");
  if (blocks.length > 1 && /^===\s*OUTPUT FORMAT\s*===/.test(blocks[0])) {
    return blocks.slice(1).join("\n\n---\n\n");
  }
  return text;
}
```
- The 2-line (now 4-line) clamped preview renders `promptPreviewText(text)`; the click-open popover and the `countLabel` (tokens/chars) render exactly as today, from the full text.
