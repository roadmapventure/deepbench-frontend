## 4. STUB DEFINITIONS

Both pure and exported from `scripts/regrade-cohort.js`:

- `ownCommitRange({ log, version, backlogId })` → `{ ship, base, own, intruders }`. `log` is `[{sha, parent, subject}]`, newest first. `intruders` = shas in `base..ship` that are not own. Empty `version`, or no own commit → all-null/empty, never a guess; never throws.
- `cohortRow({ verdict, range })` → `{ backlog_id, version, graded_sha, verdict_id, base_sha, ship_sha, status, reason, graded_sha_in_history }`. `status` is `resolved` only when `base` and `ship` are set and `intruders` is empty; else `refused`, `reason` naming the class — `no-version`, `no-own-commit`, `interleaved: <shas>`. An unresolvable ship is refused, never approximated.
