## 1. CONTEXT

`LOG-08`'s coding session shipped `scripts/check-ai-logging-coverage.js` and verified it against all 8 required findings — legitimately good work, it also caught and fixed one real gap in its own logic before finishing (missing an `embedContent(` marker). This design session then independently re-ran the tool itself (rather than accepting the coding report alone) and found a second, real bug the coding session missed: **the tool flags `src/hooks/useAIActivity.js` — the file that *defines* `logAICall` — as `CRITICAL: calls logAICall (1x) with no import — undefined-reference crash risk`.**

This is a genuine false positive, not a nitpick: `checkClientFile()`'s `logAICall(` count matches the literal substring anywhere in the file, including inside the `export function logAICall({...` declaration itself and two `//` comments that happen to mention it. A file that defines a function obviously doesn't import it from elsewhere — the check's premise (call-without-import means undefined-reference) doesn't apply to the file that IS the reference. Left unfixed, this is a guaranteed, permanent false CRITICAL on every single future run — exactly the kind of thing that erodes trust in a tool meant to become a standing check (`STANDARDS.md`'s Category M references it starting today).

### Task 1 — `scripts/check-ai-logging-coverage.js`: strip comments and the definition line before counting

Replace `checkClientFile()`'s current body:
```js
function checkClientFile(filePath) {
  const text = fs.readFileSync(filePath, "utf8");
  const importsLogAICall = /import\s*\{[^}]*logAICall[^}]*\}\s*from/.test(text);
  const logCallCount = countOccurrences(text, "logAICall(");
```
with:
```js
function checkClientFile(filePath) {
  const rawText = fs.readFileSync(filePath, "utf8");
  // Strip // line comments and the function's own definition signature before counting --
  // a file that defines logAICall (or only mentions it in a comment) isn't "calling it
  // with no import," and would otherwise self-flag as a permanent false positive
  // (found live 2026-07-16 on src/hooks/useAIActivity.js, the file that defines it).
  const text = rawText
    .split("\n")
    .filter(line => !line.trim().startsWith("//"))
    .join("\n")
    .replace(/export\s+function\s+logAICall\s*\(/g, "");
  const importsLogAICall = /import\s*\{[^}]*logAICall[^}]*\}\s*from/.test(text);
  const logCallCount = countOccurrences(text, "logAICall(");
```
No other line in this function, or anywhere else in the file, changes.
