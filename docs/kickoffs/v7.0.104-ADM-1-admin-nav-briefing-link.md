## Hostname gate

Code constant, defined once at the top of `AppShell.jsx` (also read by `AdminScreen.jsx`'s
safety redirect):

```js
export const IS_ADMIN_HOST =
  typeof window !== "undefined" &&
  (window.location.hostname === "localhost" ||
   window.location.hostname === "127.0.0.1" ||
   /-git-dev-.*\.vercel\.app$/.test(window.location.hostname));
```

Production custom domain `deepbench.roadmapventure.com` is excluded by construction; PR previews
(`*.vercel.app` without `-git-dev-`) also excluded. This is the code-constant gate the standing
rule normally forbids — the waiver on record permits it for this v1. A follow-up cycle that
lands HAR-41's data-row flag mechanism can retire this constant without moving the surface.

**Defense in depth:** when the gate is false, both (a) the nav entries are not rendered, and (b)
the `/admin` route's screen redirects the browser to `/` on mount. A direct URL visit to `/admin`
from production therefore neither renders the Admin screen nor exposes its DOM.
