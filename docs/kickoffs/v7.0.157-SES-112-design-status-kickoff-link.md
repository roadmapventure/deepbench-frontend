## 6. DESIGN RULES

- **Append LAST, never insert.** `check-session-docs.js` addresses cells by index
  (`cells[1..9]`); any position but the end silently re-points every one of them. Same rule
  `SES-110` wrote for the `Epic` column, applied twice more.
- **`NULL` ≠ `'auto'`.** An untriaged ticket stays `NULL` and is counted as untriaged. Coercing it
  to `auto` would tell the runner it may build 541 tickets nobody has read.
- **`designed` cannot exist without its artifact** — the pairing CHECK is the enforcement, so the
  column cannot drift into a claim the repo does not back.
- **Empty cell means SQL NULL** in the snapshot encoding; a stored empty string is `\e`. Both new
  columns inherit that convention unchanged.
- **Shipping does not clear it:** `done` rows keep `design_status` as history (John, 2026-08-22).
