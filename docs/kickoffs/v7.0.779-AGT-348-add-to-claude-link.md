## 2. CONTEXT

The Claude pill's step 1 is eight numbered items (`ConnectAgentPopup.jsx` `CONNECT_TOOLS[0].step1`). claude.ai has a deep link that opens its **Add custom connector** dialog directly: `https://claude.ai/customize/connectors?modal=add-custom-connector`. Public reports say extra query params pre-fill the dialog's Name and URL fields, but they disagree on the names (`connectorName`/`connectorUrl` vs `mcpName`/`mcpServerUrl`) and Anthropic does not document either. The link therefore carries **both pairs**: unknown params are ignored, so whichever pair claude.ai reads fills the form, and if neither does the user still lands on the right dialog with the copy box beside the link. Agent addresses need no sign-in, so pre-fill + **Add** is the whole setup: 8 steps → 2 (click link, click Add).

1. **New file `src/lib/connectLinks.js`** (plain JS so the Node test can import it — Node cannot import `.jsx`), imported by the popup as `import { claudeAddLink } from "../lib/connectLinks.js";`:

```js
// FEATURE: AGT-348 -- claude.ai's Add custom connector dialog, pre-filled. Both param pairs ride
// along because public reports disagree on the names and Anthropic documents neither; unknown params
// are ignored, and with neither read the link still opens the right dialog.
export const CLAUDE_ADD_CONNECTOR = "https://claude.ai/customize/connectors";
export function claudeAddLink(name, url) {
  const q = new URLSearchParams({
    modal: "add-custom-connector",
    connectorName: name, connectorUrl: url,
    mcpName: name, mcpServerUrl: url,
  });
  return `${CLAUDE_ADD_CONNECTOR}?${q.toString()}`;
}
```
