## 2. CONTEXT

Found live 2026-07-21, immediately after `SES-011` (v6.3.105) shipped, during this design session's own Manual QA self-verification (`CLAUDE-DESIGN.md` Step 5b) — a real QA FAIL, not a hypothetical.

**Root cause, confirmed directly (not assumed):** `freshDevDirEntries()` (`scripts/check-session-docs.js`) runs `git ls-tree --name-only origin/dev -- .claude/inflight` with no `-r` flag. Verified live: `git -C C:/Projects/deepbench-frontend ls-tree --name-only origin/dev -- .claude/inflight` returns exactly one line, `.claude/inflight` (the directory's own tree entry) — not the files inside it. Adding `-r` returns the real 11 file paths (`.claude/inflight/design-0720.md`, etc.) correctly. Non-recursive `ls-tree` given a directory pathspec lists that directory's own entry only; it does not descend into it without `-r`.

**Consequence:** every call to `extractInFlightBullets()`/`freshDevDirEntries()` silently returns an empty array, regardless of how many real `.claude/inflight/*.md` files exist on `origin/dev`. This session migrated 11 real files (the pre-existing "In flight now" bullets) and pushed them — `check-session-docs.js` still reported every one of those sessions' worktrees as "no bullet" (check 5), because `path.basename(".claude/inflight")` resolves to `"inflight"`, `freshDevText` then tries to fetch a nonexistent `.claude/inflight/inflight.md` blob, fails, and the entry is dropped by the existing `.filter(e => e.text !== null)` — silently, with no error surfaced anywhere.

**Why the Node test didn't catch this:** `SES-011`'s own test (`test-SES-011.mjs`, deleted per protocol after running) only exercised T5 — running the real script against a worktree with **no** `.claude/inflight/` directory at all (the pre-migration state at the time the coding session ran). An empty/missing directory and a non-recursive listing of a populated directory both currently produce the same outward result (zero entries), so that test could pass while this bug was already present. The gap: no test exercised the script against a directory that actually **has** files in it.

## 5. TASKS

### Task 1 — `scripts/check-session-docs.js`: add `-r` to the `ls-tree` call in `freshDevDirEntries()`

```js
// before:
    const out = execFileSync("git", ["-C", SHARED_CHECKOUT, "ls-tree", "--name-only", "origin/dev", "--", relDirPath], { encoding: "utf8" });
// after:

```
