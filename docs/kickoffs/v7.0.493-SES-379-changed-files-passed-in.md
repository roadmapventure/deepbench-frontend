## STUB DEFINITIONS
- New pure exported function in `scripts/verifier.js`, beside `changedFilesFor()`:
  `export function resolveDeliveryFiles({ explicit, gitList }) // -> string[] | null`.
  `explicit` an array → empty resolves to **null**; non-empty to the deduped union of `explicit`
  and `gitList ?? []` (extra paths only move toward refusal). No `explicit` → `gitList`,
  except that **both `null` and `[]` resolve to `null`**.
- New flag, exact string `--changed-files=<path>`: a file holding a JSON array of repo-relative
  paths, or one path per line. Unreadable or unparseable resolves to **null** (block), never to the
  git fallback — a caller who passed the flag and got nothing is not silently downgraded.
- Suffix appended to `auto_done_reason`:
  ` (changed-file source: builder list, N paths | git diff vs <base>, N paths | UNREADABLE)`.
