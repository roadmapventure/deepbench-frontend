## 1. CONTEXT

John raised a platform-rules concern mid-session: `ai_activity_log.patterns_used` is not honest per-call data for several patterns. Verified live, not assumed: `request-receivable.js`'s `sendRequest()` (line 440-443) spreads `intent_technical_services` — a static list declared once on an Intent Skill Profile in Supabase — into **every single call** of that intent, unconditionally, regardless of whether that specific call actually exercised the pattern. This is separate from and deeper than `LOG-12`/`13`/`14` (which fixed *display* misattribution) — this is a **write-side** honesty problem: a pattern can be logged as used when it wasn't, and a pattern that genuinely was used can never be logged if nobody pre-declared it on that Intent Skill Profile.

**Quantified live (Supabase query, this session):** 11,226 total rows. 659 rows carry a pattern sourced from this exact unverified path (`rag`/`llm-as-judge`/`streaming`/`reflect`/`intelligent-synthesis` on any `ai_type` other than `librarian`/`librarian-write`). `rag` dominates (2,559 raw occurrences), but 1,999 of those are the Librarian (`lib/librarian.js`), whose `patternsUsed: ['rag', 'embeddings']` is a **hardcoded literal sitting immediately after a real vector search call succeeds** (confirmed by direct code read, lines 192-207) — genuinely honest regardless of declaration, not part of the at-risk population.

**The good news, found this session:** `ai-enrichment.js`'s `enrichPrompt()` already computes real, per-call booleans that solve this — `debug.rag_retrieved` (line 311: `Object.keys(ragChunksBySection).length > 0`, a genuine check that real chunks came back), `debug.reflect_ran`, `debug.synthesis_ran`. They're sitting in the return value today, unused for pattern logging. This session is almost entirely wiring, not new detection logic.

**Design principle established with John this session (governs Phase 1 and all future pattern work):** a pattern is logged based on a real, checkable fact about *this specific call* — never a pre-declared allowlist. Four legitimate sources: (1) mechanical — computed from the call's own real shape/response, (2) declared-and-triggers-behavior — legitimate only where declaring it is what *causes* the behavior to run (REFLECT, Prompt Compression), (3) self-reported by the model's own structured output, (4) deterministically inferred/verified by the harness from actual data (call graph, retrieved-content cross-check). `intent_technical_services`'s blanket-spread role fits none of these — it's removed. Its role as REFLECT's *trigger* (`db-assembly.js`'s `technical_services.includes("reflect")` gate) is legitimate bucket-2 usage and is **not** touched by this session.

**Historical data — per John's explicit rule ("if it can't be verified, don't show it; if it can, show it"):** pre-fix rows cannot be retroactively confirmed — nothing recorded whether a declared pattern genuinely fired on that specific call. This session adds a display-time trust boundary so the AI Audit "By Pattern" view stops counting exactly the population that can't be verified, without touching the underlying rows.

Add directly above `computeByPattern()`'s existing `// FEATURE: AI-50c` comment block:

```js
// FEATURE: LOG-16 -- historical pattern-display trust boundary. Before this session,
// rag/streaming/reflect/intelligent-synthesis on any ai_type other than librarian/librarian-write
// were spread from a declared Intent Skill Profile field onto every call of that intent, regardless
// of whether that specific call actually exercised it -- confirmed live 2026-07-16, 659 real rows
// carry this risk (see kickoff CONTEXT). This session's request-receivable.js fix makes these
// patterns genuinely per-call real going forward, but a pre-fix row's declared-but-unverified
// pattern can never be retroactively confirmed. Per John's explicit rule: if it can't be verified,
// don't show it; if it can, show it. PATTERN_VERIFICATION_CUTOFF must be set to this fix's real
// production deploy timestamp before the final push (Section 9/Manual QA) -- not an approximate or
// pre-emptive value, since any row before the real fix is actually live could still carry the old
// unverified spread.
const UNVERIFIED_BEFORE_CUTOFF = new Set(['rag', 'streaming', 'reflect', 'intelligent-synthesis']);
const ALWAYS_TRUSTED_AI_TYPES = new Set(['librarian', 'librarian-write']);
export const PATTERN_VERIFICATION_CUTOFF = '2026-07-16T23:59:00Z'; // SET TO REAL DEPLOY TIME BEFORE FINAL PUSH -- see Section 9

function isPatternTrusted(slug, aiType, ts) {
  if (!UNVERIFIED_BEFORE_CUTOFF.has(slug)) return true; // mechanical/always-real patterns
  if (ALWAYS_TRUSTED_AI_TYPES.has(aiType)) return true; // hardcoded-at-real-occurrence, any age
  return new Date(ts).getTime() >= new Date(PATTERN_VERIFICATION_CUTOFF).getTime();
}
```

## 7. NODE.JS TEST

Add `test-log-16.js` at repo root (delete after verification):

```js
import { buildPatternsUsed } from './api/prompt/request-receivable.js';
import { computeByPattern, PATTERN_VERIFICATION_CUTOFF } from './src/hooks/useAIActivity.js';

let pass = 0, fail = 0;
function check(label, actual, expected) {
  const ok = JSON.stringify(actual) === JSON.stringify(expected);
  console.log(`${ok ? 'PASS' : 'FAIL'}: ${label}${ok ? '' : ` (got ${JSON.stringify(actual)}, want ${JSON.stringify(expected)})`}`);
  ok ? pass++ : fail++;
}

// Task 1: buildPatternsUsed's new ragRetrieved param
check('ragRetrieved=false adds nothing', buildPatternsUsed(true, false, false, false), ['structured-output', 'tool-use']);
check('ragRetrieved=true adds rag', buildPatternsUsed(true, false, false, true), ['structured-output', 'tool-use', 'rag']);
check('no isJson, ragRetrieved=true still adds rag alone', buildPatternsUsed(false, false, false, true), ['rag']);

// Task 2: computeByPattern's historical trust boundary
const beforeCutoff = new Date(new Date(PATTERN_VERIFICATION_CUTOFF).getTime() - 60000).toISOString();
const afterCutoff = new Date(new Date(PATTERN_VERIFICATION_CUTOFF).getTime() + 60000).toISOString();

const preFixNonLibrarian = [{ type: 'channel-intelligence', location: 'request-receivable', cost: 0.03, patternsUsed: ['structured-output', 'rag'], ts: beforeCutoff }];
const preFixResult = computeByPattern(preFixNonLibrarian);
check('pre-cutoff non-librarian: rag stripped', preFixResult['rag'].total, 0);
check('pre-cutoff non-librarian: structured-output kept, gets full cost', preFixResult['structured-output'].total, 1);
check('pre-cutoff non-librarian: structured-output absorbs the stripped rag cost share', preFixResult['structured-output'].cost, 0.03);

const postFixNonLibrarian = [{ type: 'channel-intelligence', location: 'request-receivable', cost: 0.03, patternsUsed: ['structured-output', 'rag'], ts: afterCutoff }];
const postFixResult = computeByPattern(postFixNonLibrarian);
check('post-cutoff non-librarian: rag trusted', postFixResult['rag'].total, 1);
check('post-cutoff non-librarian: cost split evenly across both', postFixResult['rag'].cost, 0.015);

const preFixLibrarian = [{ type: 'librarian', location: 'librarian', cost: 0.001, patternsUsed: ['rag', 'embeddings'], ts: beforeCutoff }];
const librarianResult = computeByPattern(preFixLibrarian);
check('pre-cutoff librarian: rag still trusted (hardcoded-at-real-occurrence)', librarianResult['rag'].total, 1);

console.log(`\n${pass} passed, ${fail} failed`);
if (fail > 0) process.exit(1);
```
