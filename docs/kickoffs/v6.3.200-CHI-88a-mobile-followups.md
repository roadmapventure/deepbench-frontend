## Task 1 — `AgentWorkingIndicator` gets a `compact` one-line variant (`MarketIntelligenceScreen.jsx` ~710–739)

Add a `compact` prop, default false. When false: byte-identical rendering to today (desktop + any other caller untouched). When true:
- Outer div: `{display:"flex",flexDirection:"column",gap:4,position:"relative",alignItems:"stretch",maxWidth:"100%",marginBottom:0}` (drops the CHI-56 chat-pane `alignItems:"flex-end"`/`maxWidth:"85%"`/`marginBottom:12`).
- Row: `flexWrap:"nowrap"`, `overflow:"hidden"`, `justifyContent:"flex-start"`.
- Render order in compact (matches John's approved mock): `AIDiamond` → activity message span → elapsed/expect span. The message span additionally gets `{overflow:"hidden",textOverflow:"ellipsis",whiteSpace:"nowrap",minWidth:0,flexShrink:1}`; the elapsed/expect span gets `flexShrink:0`. The per-agent time span (`formatElapsed(now - startedAt)`) is **omitted in compact only** — the feed's hop rows already carry per-agent durations. The elapsed/expect span keeps its exact current text (`elapsed X | <expectation>`) — §19o requires the expectation (and its recovery extensions) to stay visible in this line.

The mobile status wrapper (the block v6.3.198 moved below the input row) passes `compact`. Desktop `InteractColumn` call: no prop, unchanged.
