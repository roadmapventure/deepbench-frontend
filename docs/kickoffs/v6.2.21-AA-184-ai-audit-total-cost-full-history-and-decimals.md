## 1. CONTEXT

Follow-up to `AA-181`/`AI-49` (tracked as `AA-183`, v6.2.19) — that session fixed *how* cost is computed (derive from tokens when `cost_usd` is null) but not *how many rows* the AI Audit screen reads. John noticed the Total Cost figure read ~$3 despite ~$60 of real spend, and asked whether history was miscaptured.

Root-caused live against Supabase this session: it wasn't a capture problem, it was a **scope** problem. `hydrateFromSupabase()` in `useAIActivity.js` has a bare `.limit(500)` (pre-existing, unrelated to `AA-183`) — it only ever loads the 500 most recent `ai_activity_log` rows, and every rollup the AI Audit screen shows (`totalCost`, `byService`, `byPattern`, `byLLM`) derives from that same capped `_log` array. Confirmed via direct query:

| Scope | Derived cost |
|---|---|
| Most recent 500 rows | **$3.56** (matches what John saw) |
| All 9,311 rows | **$42.18** |

The remaining gap between $42.18 and John's ~$60 estimate is a third, separate, **unrecoverable** issue: 1,549 rows have a real `model` logged but no `input_tokens`/`output_tokens`/`cost_usd` at all (calls made before token logging existed everywhere, earliest row 2026-06-08) — no data exists to derive cost from for those. Not in scope for this session; nothing to fix, the data is gone.

**Fix, this session:** page through the *entire* result set instead of capping at 500, using the exact `PAGE_SIZE=1000` + `.range()` loop `useAgents.js`'s `fetchAll()` already uses for its own per-agent cost rollup (same proven pattern, not a new one). Also: switch the AI Audit panel's dollar formatter from 3 decimals to 2 (John's explicit request), keeping the existing `<$0.01` guard so genuinely tiny non-zero amounts don't misleadingly round to `$0.00`.

## 4. TASKS (max 4)

### Task 1 — `src/hooks/useAIActivity.js`: paginate the full `ai_activity_log` result set

Replace `hydrateFromSupabase()` (currently a single `.select('*')...limit(500)` call) with a paging loop. Add a module-level `PAGE_SIZE` constant near the top of the file (next to the existing `MODEL_ID_NORMALIZE`/`COST_PER_1K_INPUT` constants is fine) and rewrite the function body:

```js
// FEATURE: AA-184 -- page through the full result set instead of capping at 500, so
// Total Cost and every by-type/by-service/by-pattern/by-LLM rollup reflect true history
// instead of just the most recent 500 rows. AA-183 fixed HOW cost is computed per row;
// this fixes HOW MANY rows are read -- confirmed live the two are independent bugs
// (last-500-rows total was $3.56 vs $42.18 across the real ~9,300-row history). Same
// PAGE_SIZE/.range() loop already proven in useAgents.js's fetchAll() -- not a new pattern.
const PAGE_SIZE = 1000;

export async function hydrateFromSupabase(tenantId = 'global') {
  const rows = [];
  let from = 0;
  while (true) {
    const { data, error } = await supabase
      .from('ai_activity_log')
      .select('*')
      .eq('tenant_id', tenantId)
      .order('created_at', { ascending: false })
      .range(from, from + PAGE_SIZE - 1);

    if (error) {
      console.warn('[AI log] Hydration failed:', error.message);
      return;
    }
    rows.push(...(data || []));
    if (!data || data.length < PAGE_SIZE) break;
    from += PAGE_SIZE;
  }

  // Replace store entirely with DB state — DB is authoritative on every panel open
  _log = rows.map(row => ({
    id:        row.id,
    type:      row.ai_type,
    model:     row.model || 'claude-haiku-4-5',
    tokens:    row.input_tokens || 0,
    latencyMs: row.latency_ms || 0,
    tier:      row.knowledge_tier || null,
    location:  row.feature || '—',
    agentId:   row.agent_id || null,
    cost:      row.cost_usd != null
      ? parseFloat(row.cost_usd)
      : computeCallCost(row.model, row.input_tokens, row.output_tokens),
    ts:        row.created_at,
    _fromDB:   true,
  }));
  notify();
}
```

The row-mapping block (the `_log = rows.map(...)` body) is byte-identical to the current one — only the fetch above it changes from one capped call to a paging loop, and the source array changes from `data` to the accumulated `rows`. `order('created_at', {ascending:false})` combined with sequential `.range()` pages preserves the existing newest-first ordering of `_log` (page 0 = newest 1000 rows, page 1 = next-older 1000, etc., concatenated in fetch order) — no downstream consumer needs to change.

Do not touch `logAICall()`'s own separate `_log = [entry, ..._log].slice(0, 500)` cap (client-side in-memory cap for calls made during the current session) — that's a different, intentional cap on live-added entries, not the DB hydration path.

### Task 2 — `src/components/AIActivityPanel.jsx`: 2-decimal cost formatting

Change the `fmt$` formatter (currently ~line 34):

```js
const fmt$ = n => n < 0.01 ? `<$0.01` : `$${n.toFixed(3)}`;
```

to:

```js
const fmt$ = n => n < 0.01 ? `<$0.01` : `$${n.toFixed(2)}`;
```

One-line change. The `<$0.01` guard stays — without it, any real but tiny amount (e.g. $0.006) would round to `$0.00` under 2-decimal formatting, misleadingly reading as exactly zero. No other file needs this change — `MarketIntelligenceScreen.jsx`'s own cost display (`StatCell val={... stats.avgCost.toFixed(2)}`, Agents drawer) already uses 2 decimals.

## 7. NODE.JS TEST

Save as `test-AA-184.mjs` at the repo root, run with `node test-AA-184.mjs`, then delete the file. This test verifies the paging loop's *shape* using a fake Supabase client (no live network call) — it must exercise at least 3 pages (so the `< PAGE_SIZE` break condition is genuinely tested, not just the trivial 1-page case) and confirm the final `_log` length and ordering.

```js
// Minimal fake Supabase client: 3 pages of 1000, 1000, 250 rows (2250 total),
// confirming hydrateFromSupabase() pages until a short page ends the loop.
let callCount = 0;
const TOTAL_ROWS = 2250;
const fakeRows = Array.from({ length: TOTAL_ROWS }, (_, i) => ({
  id: TOTAL_ROWS - i, // descending IDs so index 0 is "newest"
  ai_type: 'agent-turn',
  model: 'claude-haiku-4-5-20251001',
  input_tokens: 100,
  output_tokens: 50,
  latency_ms: 500,
  knowledge_tier: null,
  feature: 'test',
  agent_id: 'marcus',
  cost_usd: null,
  created_at: new Date(2026, 6, 14, 0, 0, TOTAL_ROWS - i).toISOString(),
}));

const fakeSupabase = {
  from(table) {
    if (table !== 'ai_activity_log') throw new Error(`unexpected table ${table}`);
    let tenantFilter = null;
    return {
      select() { return this; },
      eq(col, val) { if (col === 'tenant_id') tenantFilter = val; return this; },
      order() { return this; },
      range(from, to) {
        callCount++;
        if (tenantFilter !== 'global') return Promise.resolve({ data: [], error: null });
        const slice = fakeRows.slice(from, to + 1);
        return Promise.resolve({ data: slice, error: null });
      },
    };
  },
};

// Inline re-implementation of the paging loop being tested (mirrors the shipped
// hydrateFromSupabase() body exactly) -- avoids needing to mock the real
// '../lib/supabase.js' module import for this standalone test.
const PAGE_SIZE = 1000;
async function hydrateFromFakeSupabase(tenantId = 'global') {
  const rows = [];
  let from = 0;
  while (true) {
    const { data, error } = await fakeSupabase
      .from('ai_activity_log')
      .select('*')
      .eq('tenant_id', tenantId)
      .order('created_at', { ascending: false })
      .range(from, from + PAGE_SIZE - 1);
    if (error) return null;
    rows.push(...(data || []));
    if (!data || data.length < PAGE_SIZE) break;
    from += PAGE_SIZE;
  }
  return rows;
}

let failures = 0;
function assertEqual(actual, expected, label) {
  if (actual !== expected) {
    failures++;
    console.error(`FAIL: ${label} — expected ${expected}, got ${actual}`);
  } else {
    console.log(`PASS: ${label}`);
  }
}

const result = await hydrateFromFakeSupabase('global');
assertEqual(result.length, TOTAL_ROWS, 'all 2250 rows across 3 pages returned');
assertEqual(callCount, 3, 'exactly 3 range() calls made (1000 + 1000 + 250)');
assertEqual(result[0].id, TOTAL_ROWS, 'first row is the newest (highest id, page 0)');
assertEqual(result[TOTAL_ROWS - 1].id, 1, 'last row is the oldest (lowest id, final page)');

const emptyTenantResult = await hydrateFromFakeSupabase('other-tenant');
assertEqual(emptyTenantResult.length, 0, 'a non-matching tenant_id returns zero rows (single call, no infinite loop)');

if (failures > 0) {
  console.error(`\n${failures} test(s) FAILED`);
  process.exit(1);
} else {
  console.log('\nALL TESTS PASS');
}
```
