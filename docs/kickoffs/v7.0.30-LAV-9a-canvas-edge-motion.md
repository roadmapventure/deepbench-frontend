## 2. CONTEXT

The Live Agent View canvas (`AgentNetwork.jsx`) draws the agent-to-agent communication lines for a run. Round 2 (`LAV-7`) added a travelling arrow for a delegation that's genuinely still open, and kept the LAV-5b behavior where exactly one edge — the most recently pulsed — shows a solid line + word label. John's round-3 UX pass found four problems in this area, all in the same rendering block:

1. The Answer drawer (top-left) has no height cap, so a long answer just grows past the canvas.
2. A delegation left genuinely unresolved at the run's end gets stuck permanently in the "open" blue+arrow look — nothing ever fires again to release it, so a run that's long done can still show a moving arrow.
3. Only one line ever gets the travelling arrow (the genuinely-open one, hardcoded blue) — every other edge that carried real traffic this run sits static.
4. Only one line at a time ever shows its word label — the moment a new pulse lands elsewhere, the previous edge's label vanishes, even though it really happened.

John's resolution, confirmed live in the design session: while a run is going, **every edge that has carried real traffic this run stays solid and arrow-animated simultaneously, each in its own real meaning color** (Delegate/Report back/Hand-off/Re-dispatch) — so a busy run visibly shows N agents talking at once, not a spotlight hopping between them. Labels are scarcer than lines: only the **2 most-recently-active edges show a full-opacity label; the 3rd-most-recent shows a fading (dimmed) label; anything older shows none.** The moment the run ends, genuinely-still-open edges settle immediately into their real terminal look (existing `sessionEdges` Hand-off coloring) instead of staying stuck, and the arrow motion stops everywhere (motion means "happening right now," and nothing is, once the run is over).

### Task 2 — Settle genuinely-open edges the instant the run ends

File: `src/components/AgentNetwork.jsx`, the `visuallyOpenKeys` floor effect (currently ~lines 687-708).

Root cause: the effect only re-runs when `openEdgeKeys` changes reference, which is derived from `runHops` via `deriveNetwork`. Once the run's last hop lands and `running` flips to `false`, `runHops` stops changing — so if a delegation was genuinely still open at that moment, the effect never fires again to release it, and it stays rendered as an in-flight blue+arrow edge forever.

Fix: add `running` to the effect's dependency array, and when `!running`, treat every currently-tracked key as due for immediate settlement (no floor) instead of only the ones the ledger says have actually closed.

```js
// FEATURE: LAV-9a -- every edge's own last-known meaning color and how recently it last carried a
// pulse, folded once over this run's hops. No new imperative pulse-tracking state: the existing
// pulsesForHop() already knows exactly which hops are real pulses and what color each one is: this
// just keeps the LAST one per edge instead of only the single most-recent one across all edges.
// `order` is the fold index of that edge's last pulse -- ranking by it (descending) is the entire
// "most recent N" rule below, with no separate timer-based bookkeeping duplicating the ledger.
export function edgeActivity(runHops) {
  const colors = new Map();   // key -> meaning color
  const order = new Map();    // key -> fold index of its last pulse
  runHops.forEach((h, i) => {
    for (const p of pulsesForHop(h, i, runHops.slice(0, i))) {
      const k = edgeKey(p.from, p.to);
      colors.set(k, p.color);
      order.set(k, i);
    }
  });
  return { colors, order };
}

// FEATURE: LAV-9a -- the last-N-labels-visible rule, as a pure rank lookup: the 2 most-recently-
// active edges get a full-opacity label, the 3rd gets a fading one, anything older gets none. A
// single named export so the render loop and the Node test both read the exact same tiers.
export const LABEL_FULL_COUNT = 2;
export const LABEL_FADE_COUNT = 3;
export function labelOpacityForRank(rank) {
  if (rank < 0) return 0;
  if (rank < LABEL_FULL_COUNT) return 1;
  if (rank < LABEL_FADE_COUNT) return 0.45;
  return 0;
}
```

```js
// test-lav-9a.mjs -- LAV-9a Category B logic tests (pure, no app imports)
function edgeKey(from, to) { return `${from}>${to}`; }

// Mirrors AgentNetwork.jsx's edgeActivity(): last pulse per edge wins for color, fold index wins for order.
function edgeActivity(pulseLog) {
  const colors = new Map(), order = new Map();
  pulseLog.forEach(({ from, to, color }, i) => {
    const k = edgeKey(from, to);
    colors.set(k, color);
    order.set(k, i);
  });
  return { colors, order };
}

const LABEL_FULL_COUNT = 2, LABEL_FADE_COUNT = 3;
function labelOpacityForRank(rank) {
  if (rank < 0) return 0;
  if (rank < LABEL_FULL_COUNT) return 1;
  if (rank < LABEL_FADE_COUNT) return 0.45;
  return 0;
}

let pass = 0, fail = 0;
function assertEq(actual, expected, msg) {
  const ok = JSON.stringify(actual) === JSON.stringify(expected);
  if (ok) { pass++; } else { fail++; console.error(`FAIL: ${msg} -- got ${JSON.stringify(actual)}, expected ${JSON.stringify(expected)}`); }
}

// A: last pulse per edge wins its color, even if an earlier pulse on the same edge had a different one
const log = [
  { from: "A", to: "B", color: "blue" },
  { from: "B", to: "C", color: "green" },
  { from: "A", to: "B", color: "red" },   // re-dispatch on the same pair
  { from: "C", to: "D", color: "tan" },
];
const { colors, order } = edgeActivity(log);
assertEq(colors.get(edgeKey("A", "B")), "red", "A: last color wins on repeated edge");
assertEq(colors.get(edgeKey("B", "C")), "green", "A: single-pulse edge keeps its color");
assertEq(order.get(edgeKey("A", "B")), 2, "A: order is the LAST fold index, not the first");

// B: ranking by order descending gives most-recent-first, which is what recentOrder does in-component
const ranked = [...order.entries()].sort((a, b) => b[1] - a[1]).map(([k]) => k);
assertEq(ranked, [edgeKey("C", "D"), edgeKey("A", "B"), edgeKey("B", "C")], "B: most-recent-first ranking");

// C: label opacity tiers -- top 2 full, 3rd faded, rest none, and "not in the window" (-1) is none
assertEq(labelOpacityForRank(0), 1, "C: rank 0 full opacity");
assertEq(labelOpacityForRank(1), 1, "C: rank 1 full opacity");
assertEq(labelOpacityForRank(2), 0.45, "C: rank 2 faded");
assertEq(labelOpacityForRank(3), 0, "C: rank 3 no label");
assertEq(labelOpacityForRank(-1), 0, "C: not-in-window no label");

// D: settle-on-terminal formula (Task 2) -- while running, an edge the ledger still calls open has
// nothing scheduled; once !running, remaining is always 0 (immediate settle), never the 900ms floor
const LOOP_LAP_MS = 900;
function remainingFor(running, since, now) { return running ? LOOP_LAP_MS - (now - since) : 0; }
assertEq(remainingFor(true, 1000, 1200), 700, "D: still running -- floor applies");
assertEq(remainingFor(false, 1000, 1200), 0, "D: run over -- settles immediately regardless of floor");

console.log(fail === 0 ? "ALL TESTS PASS" : `${fail} FAILED, ${pass} PASSED`);
if (fail > 0) process.exit(1);
```
