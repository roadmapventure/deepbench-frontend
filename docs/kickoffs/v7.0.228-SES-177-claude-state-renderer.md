## The distinction the build must not collapse

The **version lines** skip cycles that claimed no version; the **session bullets** do not. Taking
`cycles[0]` for "Version in dev" renders `(no version claimed)` as the current version *of dev* —
the wrong question answered, not a gap surfaced honestly. Asserted on a fixture whose newest shipped
cycle is version-less.
