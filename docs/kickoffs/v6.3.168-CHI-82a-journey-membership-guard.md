## 2. CONTEXT
QA on v6.3.162 confirmed the defect its own coding session flagged: the step-arrival effect keys on drawer-content **presence**, but `qaEvidence`/`hypFlow` persist across journeys (`CHI-51` persistence). After `resetJourney()`, the moment any effect dep changes (e.g. a new question's `qaEvidence` lands), the still-present **previous** journey's `hypFlow` gets re-numbered into the new journey — old resolved Theories/Result/Draft drawers wear fresh numbers 2/3/4 and sort above ambient News, misrepresenting them as steps of the current journey. Root cause: presence ≠ journey membership. Fix: stamp `hypFlow` with the journey sequence it was created in; the effect numbers only current-journey content. (Verified live 2026-07-28: right after a new-question submit, old drawers correctly show unnumbered/order-90 — only because no effect dep had changed yet; the mechanism fires on the next dep change.) Second item: the mobile heads-up pointer still reads "Click News above for current headlines" — it points at the tab `CHI-82` renamed to "Steps & Evidence".

## 5. TASKS (2)

### T1 — Journey-membership guard
1. **Sentinel block (`CHI-82-PURE-BEGIN/END`):** extend journey state with a sequence: `EMPTY_JOURNEY = () => ({ order: {}, next: 1, seq: 0 })`, and add:
```js
function nextJourney(prev) {
  return { order: {}, next: 1, seq: (prev?.seq ?? 0) + 1 };
}
```
`assignStep` unchanged (it spreads `order`/`next`; ensure it preserves `seq` — change its return to `{ ...journey, order: {...}, next: n + 1 }` so `seq` carries through).
2. **`resetJourney()`** now sets `journeyRef.current = nextJourney(journeyRef.current)` (keeps the version-bump behavior).
3. **Stamp `hypFlow` at creation:** at every site that creates a **fresh** `hypFlow` object from scratch (the `enterHypothesisFlow` entry and any other `setHypFlow({...})`-from-scratch site — NOT stage-advance updates that spread the existing object), add `journeySeq: journeyRef.current.seq`. The Review/escalation entry path gets the same stamp — no reset happened there, so it naturally carries the current (continuing) journey's seq.
4. **Guard the arrival effect:** the three hyp checks become conditional on membership: `const hypCurrent = hypFlow && hypFlow.journeySeq === journeyRef.current.seq;` then `if (hypCurrent) ensureStep("hyp-candidates")` etc. The `qa` check stays unguarded (`qaEvidence` is a single overwritten slot — the new journey's answer replaces it under the same key, so a pre-arrival stale assignment self-corrects; do not add a stamp to `qaEvidence`).
5. **Defensive default:** a `hypFlow` with `journeySeq === undefined` (shouldn't exist, but e.g. hot-reload state) counts as NOT current — it stays unnumbered ambient rather than stealing a step number.

```js
import { readFileSync } from "fs";
const src = readFileSync("src/screens/MarketIntelligenceScreen.jsx", "utf8");
const m = src.match(/\/\/ CHI-82-PURE-BEGIN([\s\S]*?)\/\/ CHI-82-PURE-END/);
if (!m) { console.error("FAIL: sentinel block missing"); process.exit(1); }
const { EMPTY_JOURNEY, assignStep, nextJourney } = new Function(
  `${m[1]}; return { EMPTY_JOURNEY, assignStep, nextJourney };`
)();
let pass = 0, fail = 0;
const eq = (name, got, want) => {
  if (JSON.stringify(got) === JSON.stringify(want)) { pass++; }
  else { fail++; console.error(`FAIL ${name}: got ${JSON.stringify(got)}, want ${JSON.stringify(want)}`); }
};
// journey 0: run a full flow
let j = EMPTY_JOURNEY(), n;
eq("seq.initial", j.seq, 0);
[j, n] = assignStep(j, "hyp-candidates"); eq("j0.theories", n, 1);
eq("seq.preserved-by-assign", j.seq, 0);
// reset -> journey 1: numbering restarts, seq increments
j = nextJourney(j);
eq("seq.incremented", j.seq, 1);
eq("order.cleared", Object.keys(j.order).length, 0);
[j, n] = assignStep(j, "qa"); eq("j1.qa", n, 1);
// membership semantics: a hypFlow stamped with seq 0 is NOT current in journey 1
const staleHyp = { journeySeq: 0 };
eq("stale.not-current", staleHyp.journeySeq === j.seq, false);
const freshHyp = { journeySeq: j.seq };
eq("fresh.current", freshHyp.journeySeq === j.seq, true);
// undefined stamp counts as not current
eq("undef.not-current", ({}).journeySeq === j.seq, false);
console.log(`${pass}/${pass + fail} passed`);
process.exit(fail ? 1 : 0);
```
