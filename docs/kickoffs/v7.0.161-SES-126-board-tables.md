## The four traps this ticket has to get right

Each was measured against the live board/log this cycle, not reasoned about.

- **`· FLAGGED` splits a class in two (§11).** Grouping the now tier by the raw
  `priority_class` string returns **seven** rows for six classes — `P9 - Bug Fixes` (120) and
  `P9 - Bug Fixes · FLAGGED` (27) land as separate lines, so John reads "120 bug fixes" when the
  true figure is **147**. §11 groups on the extracted **digit**, exactly as
  `recompute_backlog_queue()` does. Same family as the runbook's lexical-vs-numeric trap.
- **`title` is not a title (§8).** For imported tickets `backlog_items.title` holds the class
  string (`'P9 - Bug Fixes.'`). §8's Title column uses the `gist` extract — the first clause of
  `description` with the bolded class prefix stripped — which is what the runbook already
  requires of anything that *displays* the queue, and stays true until `SES-91` repairs the
  column.
- **Production ≠ dev (§14).** `request_host = 'deepbench.roadmapventure.com'` is the only
  production host in `ai_activity_log`; the dev URL is John himself (the standing dev-URL=John
  attribution rule) and `request_host IS NULL` covers 12,212 pre-`LOG-134` rows with no host at
  all. Filtering on anything looser puts John's own runner traffic in a table headed "who used
  DeepBench".
- **A "use" is a run, not a row.** `LOG-81`'s standing rule is that "AI calls" means real model
  calls, never raw log rows. §14 groups by `trace_id` (one run) and counts only rows with a
  `model`, so a five-call run reads as one use.

## Honest limits, stated rather than discovered later

- **`cost_usd` is NULL on every production row** in `ai_activity_log` today, so §14's Cost column
  renders `—`. That is the truthful value; it is not a zero and must never be rendered as `$0.00`.
- **§14's most recent production use is 2026-08-18** — the table is a "last 5", not a "today",
  and its heading says so.
- **`ip_org_cache.user_label` is sometimes a provenance paragraph**, not a name (one live row
  carries 130 characters of explanation). §14 prefers `visitor_labels.user_label`, then the first
  clause of the cache label, then `org` — so the Name column stays a name.
- **No ladder row exists for `P6 - Agent Enhancement`** (`runner_ladder` holds six work classes;
  P6 is not one). §13 says so in a note rather than rendering a blank row, and points at
  `SES-122`.
