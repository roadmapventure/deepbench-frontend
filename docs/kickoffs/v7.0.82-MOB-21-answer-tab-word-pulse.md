## Task 1 — extend `MOB_TAB_CUE_CSS`

Change the export exactly from:

```js
export const MOB_TAB_CUE_CSS = `
.lav-mtab-alert{animation:borderPulse 2s ease-in-out infinite}
@media (prefers-reduced-motion:reduce){.lav-mtab-alert{animation:none;border-bottom-color:${T.brass}}}
`;
```

to:

```js
export const MOB_TAB_CUE_CSS = `
.lav-mtab-alert{animation:borderPulse 2s ease-in-out infinite,inkTanPulse 2s ease-in-out infinite}
@media (prefers-reduced-motion:reduce){.lav-mtab-alert{animation:none;border-bottom-color:${T.brass}}}
`;
```

Why this works with no other change: the armed button's label is the button's own text, so animating `color` on `.lav-mtab-alert` pulses the word; CSS animations override the inline `color: alert ? T.navy : …` while running, and reduced-motion's `animation:none` hands color back to that inline navy — solid brass tab with static navy label, exactly today's reduced-motion state. `inkTanPulse` is defined once in `tokens.js` `GLOBAL_CSS` (S-LAV-38) — do NOT redefine it here. Both animations share the 2s rhythm so border and word breathe together, in sync with the desktop drawer.
