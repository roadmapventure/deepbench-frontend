## CONTEXT

`onDelegationProgress` always appends a brand-new pending placeholder row for every live delegation event (`logEvent(evt, { replaces })`, unconditionally) — it never checks whether the event it just received actually *resolves* a placeholder it created moments earlier. So a *returning* hand-off's "X is routing to Y…" line never gets claimed by its own later completion. Live-reproduced 2026-07-20: Owen — The Proofreader's internal retry-via-Marcus — GEO CSO Expert (`qg-review-intent`'s non-final `delegate_to_agent` retry) leaves a permanently-stuck "Owen is routing this to Marcus…" line in the Agent Routing drawer, because the harness's own `delegation_return` event (which correctly names Marcus as done and Owen as receiving control back) is never consumed to resolve it.

This session fixes the actual matching bug, and — now that `S-LOO-009` makes it redundant — removes the dynamically-resolved (**Shape 2**) `hopEvents` declarations (`agent_selection`/`display_format`) from the 3 Q&A call sites, since the harness now announces those completions live instead of the client having to declare them in advance.

**Explicitly out of scope:** Shape 1 (`qa_answer`/`proofreader`/`news_fetch` — crediting the agent originally called, independent of any delegation) is deferred to `LOO-010`, a separate, not-yet-scoped session, because safely removing it requires verifying a reliable direct-answer-vs-delegated signal that hasn't been confirmed to exist cleanly for every call shape.

Per John's explicit rule, confirmed live 2026-07-20: **every real agent call is its own hop, always** — whether it's a live orchestration event (Orchestrator-Workers pattern, `shared/ai-patterns.js` slug `agent-delegation`) or a routing decision, no exceptions, no folding into a parent hop's summary text. This governs the expected outcome below: Marcus's retry becomes its own correctly-attributed hop once the pairing fix lands, not text folded into Owen's card.

```js
// test-loo-009b.mjs
import assert from 'node:assert/strict';

function makePendingStore() { return new Map(); }

function logEvent(state, evt, { replaces } = {}) {
  const pending = state.pendingRef.get(evt.agentId);
  let next;
  if (pending) {
    state.pendingRef.delete(evt.agentId);
    next = state.events.map(e => (e.id === pending.id ? { ...evt, id: pending.id } : e));
  } else if (replaces) {
    const id = state.events.length;
    state.pendingRef.set(replaces.awaitingAgentId, { id, key: replaces.key });
    next = [...state.events, { ...evt, id }];
  } else {
    next = [...state.events, { ...evt, id: state.events.length }];
  }
  state.events = next;
  return next;
}

// Test 1: delegation -> delegation_return resolves to ONE row, not two.
{
  const state = { events: [], pendingRef: makePendingStore() };
  logEvent(state, { type: 'delegation', agentId: 'owen' }, { replaces: { key: 'owen:marcus:', awaitingAgentId: 'marcus' } });
  logEvent(state, { type: 'delegation_return', agentId: 'marcus' });
  assert.equal(state.events.length, 1, 'delegation + delegation_return must collapse to 1 row');
  assert.equal(state.events[0].type, 'delegation_return');
  assert.equal(state.events[0].agentId, 'marcus');
}

// Test 2: delegation -> delegation_complete resolves the same way (final-hand-off shape).
{
  const state = { events: [], pendingRef: makePendingStore() };
  logEvent(state, { type: 'delegation', agentId: 'marcus' }, { replaces: { key: 'marcus:alex:', awaitingAgentId: 'alex' } });
  logEvent(state, { type: 'delegation_complete', agentId: 'alex' });
  assert.equal(state.events.length, 1, 'delegation + delegation_complete must collapse to 1 row');
  assert.equal(state.events[0].agentId, 'alex');
}

// Test 3: regression -- two ordinary same-agent plain events (no pending involved) still both persist.
{
  const state = { events: [], pendingRef: makePendingStore() };
  logEvent(state, { type: 'qa_answer', agentId: 'marcus' });
  logEvent(state, { type: 'agent_selection', agentId: 'marcus' });
  assert.equal(state.events.length, 2, 'unrelated same-agent events must NOT be merged by the pairing fix');
}

console.log('LOO-009b Node test: ALL TESTS PASS');
```
