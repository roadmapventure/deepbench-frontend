- **It does not implement pins.** `B23`'s "Accept re-enters at queue #1" still has nowhere to

  later word than a standing build order) — written into the migration header so it travels.

  back to back" collides with the `runner_lease` (`B31`), the single-runner control built *after*
  two cycles built `ADM-1` v1 simultaneously on 2026-08-20. A cycle does not dismantle a safety

  carrying exactly what would be built, per `B27` outcome 3 and `B24` (the card never ends the
  cycle).
