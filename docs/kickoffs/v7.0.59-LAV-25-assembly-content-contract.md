Exclude prompt-assembly briefing fetches from Assembly entirely: an `assembly_work_complete`
with `work === "fetch"` and `source` of `roster`/`knowledge` builds no section and no sub-entry

capability. Library sources (`the_library`, `the_library_catalog`) are untouched.

**T2 — Honest terminal cap (`AssemblyView.jsx`).**
Replace the single `ASSEMBLY_TERMINAL_TEXT` with three John-locked strings keyed on the run's
real end state, passed from the screen's existing result/error state (extend `buildAssemblyStages`
opts or the component props — smallest honest plumbing wins):
- answered: `"Build complete — answer delivered"`
- blocked (gate guardrail/`block` verdict on the terminal result): `"Build stopped — the reviewer blocked the draft"`
- error: `"Build stopped — the run hit an error"`
Verbatim, never re-worded without John.

**T3 — Revision nesting (`AssemblyView.jsx`).**
A delegation start whose `toIntentSlug` maps to a stage that already has a **filled** section
(the revision case: gate re-delegates `ci-answer-intent` after Draft filled) nests as a sub-entry
under that filled section instead of opening a second ghost section. Its `asked`/task words (when
present) render on the sub-entry; unresolved at terminal, the sub-entry stays (it names real
work) with no invented completion line.

**T4 — Narration render-if-present (`AssemblyView.jsx` + `useHarnessStream.js`).**
`useHarnessStream.js`: carry `task` (delegation start build — field verified absent from start
frames today, so this is forward-carry: `task: evt.task ?? null` joins the named list) and
`account` on the delegation start/completion/`delegation_return` and assembly payloads, same
`?? null` verbatim posture as `candidates_considered` (LAV-19).
`AssemblyView.jsx`: when a frame carries `account`, the stage/sub-entry renders it as the
content line **instead of** the derived template sentence; when absent, today's template line
renders unchanged (the §19s degrade). Ghost `asked` already renders — extend only so a start's
`task` feeds it when present (replacing the slug fallback, not the mechanism).
