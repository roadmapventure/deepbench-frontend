## The rule

`STANDARDS.md` Section 4 now opens with it: **a test must assert against the real implementation;
logic recreated inside the test file is not a test, it is a second implementation agreeing with
itself.** Attributed to the incident, not left as taste: `LOG-91`'s Section 8 test rebuilt the merge
rules as plain JS and went green while the shipped `logAgentTurn()` did something different — the
`SES-44` defect, caught by diff review rather than by the suite.

**The tension it had to resolve, rather than ignore.** Section 4 already opened with *"Pure Node.js
only — no app imports"*, which reads as the opposite. It is not: that line governs the **throwaway
session test**, and it has never licensed recreating the subject. Without saying so, the next reader
deletes whichever half they met second — so the guard pins that sentence specifically.

**Three sanctioned shapes when you cannot import**, because a rule that only forbids sends the
reader straight back to a copy: import it (default), read the shipped file, or a labelled seam
proof. Plus: **a `NOT RUN` declaration beats a recreation** — an honest gap is information, a
recreation is a false green.

## This file obeys its own rule

asserts the shipped text (5 clauses, each with a negative control), **and** it reads two of tonight's

If either were rewritten into a recreation, this notices.
