**Background the coding session needs:** each pair of agents shares ONE physical line, wearing
the colour of the last thing that crossed it (`sessionEdges()` / `edgeActivity()` /
`pulsesForHop()`, `AgentNetwork.jsx:388-455`). Current post-run behavior — lines stay solid in
their last meaning colour forever, and only the 2 most-recently-active lines keep a visible
name (`labelOpacityForRank`, `:460-467`) — is `LAV-9`-done's deliberate design, which John has
now reversed. The dashed tan "Link" style (`LINK_COLOR = T.line`) has been effectively dead
since `LAV-12`-done made edges run-scoped: a line now only exists because a delegation crossed
it this run, so it is born wearing a meaning colour and the at-rest style has nothing to attach
to. John's trace decision gives that style its job back.

**John's decisions, verbatim intent:**
1. Legend shows exactly three entries: **Delegate** (blue), **Result** (green, renamed from
   "Report back"), **Iterate** (red, renamed from "Re-dispatch"). Link, Hand-off, and Assembly
   work leave the legend — but their canvas behaviors stay (the tan trace, the assembly ring on
   cards).
2. During the run, **every solid line carries its legend name** — in-flight blue included, no
   2-3-name visibility cap.
3. Once the run is done, **all lines settle to the original dashed tan Link format** — a trace,
   so the user sees how much communication was carried. No colours kept, no words, no
   exceptions (John explicitly declined keeping the brass never-returned state solid; its
   becoming unreachable was flagged to him twice and accepted).
4. **Mobile Bench view: the active agent must pulse like desktop** — today it gets only a
   static drop-shadow glow, which reads as a dead screen (John, live on his phone).
