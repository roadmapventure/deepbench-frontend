## CONTEXT

Found live 2026-07-16 (John's screenshot walkthrough of the Chat/Agent Routing panels, design session `continuity-ux-0716`): the "Full Agent Routing & Answer Given in Xm Ys" elapsed-time caption is missing after several `HopBadge`s in the Chat panel, and some Agent Routing drawer lines (Michelle's `agent_selection`, Owen's `delegation`) never show a duration even after expanding "Read more."

Root-caused as structural, not a render bug: `logEvent()` has 21 independent call sites (13 in the component body, 8 inside the module-scope `runQaWithQualityGate`/`runHypothesisTest` functions), each hand-computing its own `durationMs` or hand-passing `null` with its own justifying comment. `setMessages()` has 17 independent call sites building message objects inline; only 1 (the `qa` bubble) ever sets `totalElapsedMs`, even though 7 more ack-bubble sites already carry `hopStart`/`hopEnd` (and could carry elapsed time too). No single helper exists for either. A stray bug was also found in this sweep: `failure_triage` (L992) logs a literal `durationMs: 0` — every sibling non-measurable event uses `null`; this one should too (confirmed: it shares Owen's `proofreader` round trip, same as the `agent_selection` event logged one line above it — no separate measurable call).

This session consolidates both into two small, local (component-file-scoped) helpers so the decision of "which events/messages get a duration" lives in exactly one place each, not scattered across a dozen comments — the fix John asked for after the first two symptom-level candidates ("just fix the display" / "instrument new timing") were both correctly identified as papering over the same missing central service.

**This is the first of 5 sessions on this same UX sweep, in order: `CHI-07` (this one, foundational) → `CHI-08` → `CHI-12` → `CHI-09` → `CHI-10`.** `CHI-08`/`CHI-09` both depend on this session's helpers for guaranteed elapsed-time data on the lines they touch.

**Visible behavior change (expected, not a regression):** once every `hopStart`-bearing message and event routes through the new helpers, several ack bubbles that never showed elapsed time before (submission ack, info-only ack, resolution ack) will start showing "Full Agent Routing & Answer Given in Xs" — this is the intended fix, not a side effect to suppress.

// event object. Resolves durationMs once: a caller-supplied real value passes through unchanged;

### Task 2 — Central `buildMessage()` helper, guaranteeing `totalElapsedMs` travels with `hopStart`/`hopEnd`

Add next to `buildHopEvent` (Task 1):

```js
// FEATURE: CHI-07 — every setMessages(...) push routes through this instead of a hand-written
// object literal. Whenever hopStart is present, totalElapsedMs is a required companion, not a
// field a caller can silently omit — 7 of this file's 17 setMessages call sites carried
// hopStart/hopEnd but never totalElapsedMs before this fix (submission/info-only/resolution ack
// bubbles). Sites that never carried hop data before this session still don't — this helper
// enforces the pairing, it does not invent hop data for messages that never had it.
function buildMessage({ role = "assistant", kind, text, hopStart, hopEnd, totalElapsedMs, needsReview, reviewReason }) {
  const msg = { role, text };
  if (kind != null) msg.kind = kind;
  if (hopStart != null) {
    if (totalElapsedMs == null) {
      console.error(`FEATURE: CHI-07 — message (role="${role}", kind="${kind}") has hopStart/hopEnd but no totalElapsedMs; caller must pass Date.now()-turnStart.`);
    }
    msg.hopStart = hopStart;
    msg.hopEnd = hopEnd;
    msg.totalElapsedMs = totalElapsedMs ?? null;
  }
  if (needsReview) {
    msg.needs_review = true;
    msg.review_reason = reviewReason || "flagged for review";
  }
  return msg;
}
```
