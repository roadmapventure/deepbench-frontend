## 2. CONTEXT

Originally flagged 2026-07-17 (`S-CHI-21-design`'s live UI test-run screenshot): Evidence column's pinned CTA footer sat directly against the scrollable narrative content above it, with no visual break — conflicting with `STYLE-GUIDE.md` Section 37 (LOCKED, `S-CHI-13-design`), which specifies the footer's border-top-only spacing to match `InteractColumn`'s own footer row exactly, for cross-column parity.

This design session resolved it live against the real running app — not a static mock. John reviewed the actual rendered page through several rounds (a local dev server was stood up in this worktree at port 5223, with a temporary `?mockqa=1` query-param seed since `/api` isn't reachable from a local Vite dev server) and gave explicit, itemized approval on the final state. Two things were confirmed as **hard invariants**, not just preferences:

1. **The footer stays locked to the bottom of the card, always** — its position must not depend on how much narrative content there is. This matches (and does not override) Section 37's core parity claim: the footer's own padding/border (`padding:"10px 14px", borderTop`) is completely unchanged, still matches `InteractColumn`'s footer exactly.
2. **The narrative content box stretches to fill the available space above the footer**, leaving a real, fixed ~14px gap to the footer — the same `gap:14` value already used for `AuditColumn`'s (Column 3) drawer stack — instead of either (a) hugging just its own text and leaving a large disconnected dead zone, or (b) letting a large accidental blank gap sit between short content and the footer.

**What was tried and rejected, for the record (so a future session doesn't re-attempt these):**
- Shrinking the CTA card's own bottom padding to force pixel-alignment with `InteractColumn`'s Send button — rejected; the CTA card needs its own real bottom padding around its button (not flush against its border), and exact alignment with Chat's Send button was never actually the goal once John clarified the footer just needs to be *locked*, not pixel-matched to a different column's unrelated control.
- Making the whole Evidence card content-sized (`alignSelf:"start"`, no `flex:1`) so it stops matching Chat's column height — rejected; this broke the 3-column visual rhythm (Evidence's outer card border no longer extended down to match Chat/Audit), leaving a bare, unbordered dead zone below a short floating card. The outer card's `flex:1` (matching Chat's height) stays exactly as it was originally.
- Making the scroll body itself content-sized (`flex:"0 1 auto"`) so the footer would sit right after short content — rejected for the same reason (footer must stay locked to the bottom, not follow content).

**The actual fix (verified live, 3 style-value changes, no logic/structural changes):**

| # | Element | Line (current) | Before | After |
|---|---|---|---|---|
| 1 | `QaEvidenceCard` root `<div>` | `MarketIntelligenceScreen.jsx:1395` | `{background:T.card,border:`1px solid ${T.line}`,borderLeft:`4px solid ${T.navy}`,borderRadius:0,position:"relative"}` | same, **+ `flex:1`** |
| 2 | `EvidenceColumn`'s outer bordered card `<div>` | `MarketIntelligenceScreen.jsx:1542` | `{background:T.cardAlt,border:`1px solid ${T.lineSoft}`,display:"flex",flexDirection:"column",flex:1,minHeight:0,overflow:"hidden"}` | same, **+ `gap:14`** |
| 3 | Scroll-body inner `<div>` (inside #2) | `MarketIntelligenceScreen.jsx:1543` | `{padding:16,display:"flex",flexDirection:"column",gap:14,overflowY:"auto",flex:1,minHeight:0}` | `padding` → **`"16px 16px 0"`** (top/sides unchanged, bottom dropped — the trailing padding would otherwise stack on top of the new structural 14px gap, producing 30px instead of 14px) |

**Why this combination works (mechanism, verified live via `getBoundingClientRect()`/`getComputedStyle()` on the real running page, not asserted from memory):**
- The outer card (#2) keeps `flex:1` — unchanged, still matches `InteractColumn`'s card height exactly (both measured top/bottom pixel-identical). This is what keeps the footer "locked": the footer is the last child of a flex column whose overall height is fixed to the grid row, so the footer's position relative to the card's own bottom edge never moves.
- The scroll body keeps `flex:1,minHeight:0,overflowY:"auto"` — unchanged. It still grows to fill all space between the top of the card and the footer, and still shrinks (and scrolls) when content is long enough to need it — confirmed live by temporarily forcing a 2000px-tall narrative: the scroll body became genuinely scrollable (`scrollHeight` 2016 vs `clientHeight` 452) while the footer stayed pinned within 1px of the card's bottom edge. `MI-54`'s original intent (a very long analysis scrolls internally, never grows the whole page) is fully preserved.
- `QaEvidenceCard` (#1) is the scroll body's only child in the plain qa-review case and now has `flex:1` itself — it stretches to fill the scroll body's available height (its own background/border extend with it), instead of shrink-wrapping just its text. Combined with the scroll body's own `gap:14` (unchanged, already existed at the scroll-body level) and its new zero bottom padding (#3), the measured gap between the narrative card's bottom edge and the footer's top edge is exactly 14px, matching `AuditColumn`'s drawer-gap value structurally (same `gap:14` property, not a coincidence).

**Desktop/mobile parity:** N/A — `EvidenceColumn` (and the `QaEvidenceCard`/scroll-body structure inside it) is a single shared component. `MobileBody` calls the identical `EvidenceColumn` (`MarketIntelligenceScreen.jsx:2430`) that the desktop 3-column layout calls (`MarketIntelligenceScreen.jsx:3006`) — confirmed by reading both call sites this session. The fix applies to both automatically; no separate mobile task.

**Architect Review — duplicate-functionality check:** `gap:14` is not a new spacing value invented for this fix — it's the same value already used by `AuditColumn`'s drawer stack (`MarketIntelligenceScreen.jsx:2110`, confirmed by grep this session) and by the scroll body's own pre-existing internal `gap:14` between narrative sub-blocks. This fix reuses that existing convention rather than introducing a new one.

At `MarketIntelligenceScreen.jsx:1395`, replace:

```jsx
    <div style={{background:T.card,border:`1px solid ${T.line}`,borderLeft:`4px solid ${T.navy}`,borderRadius:0,position:"relative"}}>
```

with:

```jsx

    // body's available height (its parent is a flex column), instead of shrink-wrapping just its
    // text content. Leaves only the scroll body's own structural 14px gap between this box and the
    // pinned footer below, instead of a large borderless dead zone when content is short.

```

### Task 2 — Scroll body: drop trailing bottom padding

At `MarketIntelligenceScreen.jsx:1543`, replace:

```jsx
        <div style={{padding:16,display:"flex",flexDirection:"column",gap:14,overflowY:"auto",flex:1,minHeight:0}}>
```

with:

```jsx
        {/* FEATURE: CHI-18 — padding-bottom dropped to 0: the narrative card above now stretches
            (flex:1, Task 1) to fill this box, so its own trailing padding would otherwise stack on
            top of the outer card's structural 14px gap to the footer (30px total measured, more
            than the AuditColumn-matching 14px target). Top/side padding unchanged. */}
        <div style={{padding:"16px 16px 0",display:"flex",flexDirection:"column",gap:14,overflowY:"auto",flex:1,minHeight:0}}>
```

### Task 3 — Outer card: add the structural gap

At `MarketIntelligenceScreen.jsx:1542`, replace:

```jsx
      <div style={{background:T.cardAlt,border:`1px solid ${T.lineSoft}`,display:"flex",flexDirection:"column",flex:1,minHeight:0,overflow:"hidden"}}>
```

with:

```jsx
      {/* FEATURE: CHI-18 — gap:14 between the scroll body and the pinned footer, matching
          AuditColumn's (Column 3) drawer-stack gap value. The footer itself stays fully unchanged
          (padding, border, position as the flex column's last child) — it remains locked to the
          card's bottom regardless of content length; only the separation from the content above it
          is new. */}
      <div style={{background:T.cardAlt,border:`1px solid ${T.lineSoft}`,display:"flex",flexDirection:"column",flex:1,minHeight:0,overflow:"hidden",gap:14}}>
```
