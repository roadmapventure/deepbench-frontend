## Task 1 — `LAV_STATUS_PILL_CSS` export

At module scope, directly below the existing `MOB_TAB_CUE_CSS` export (~L512-515), add (mirroring that idiom exactly):

```js
// FEATURE: LAV-34 -- the desktop strip's live-status pill dot pulses only while the run is live;
// reduced-motion users get the pill with a static dot (same posture as MOB_TAB_CUE_CSS above).
export const LAV_STATUS_PILL_CSS = `
.lav-status-dot-live{animation:aiBlink 1.1s ease-in-out infinite}
@media (prefers-reduced-motion:reduce){.lav-status-dot-live{animation:none}}
`;
```

`aiBlink` already exists in `tokens.js` GLOBAL_CSS — do not redefine it.

## Task 2 — the pill

In the desktop status strip (`{/* ── Status strip ── */}` block near L1163), inject the CSS and replace **only the non-`awaiting` branch** of the status-message ternary (currently the `fontStyle:"italic"` div rendering `{status?.message || ""}`) with:

```jsx
<style>{LAV_STATUS_PILL_CSS}</style>
```
(first child inside the strip's flex div, before `<ModeBadge/>`), and:

```jsx
) : status?.message ? (
  <div style={{display:"inline-flex",alignItems:"center",gap:8,flex:1,minWidth:0,
    background:rgba(T.brass,0.14),border:`1px solid ${T.brass}`,borderRadius:16,padding:"4px 12px"}}>
    <span className={running ? "lav-status-dot-live" : undefined}
      style={{width:8,height:8,borderRadius:"50%",background:T.brass,flexShrink:0}}/>
    <div style={{fontFamily:mono,fontSize:12.5,color:T.brassDeep,fontWeight:600,minWidth:0,
      whiteSpace:"nowrap",overflow:"hidden",textOverflow:"ellipsis"}}>
      {status.message}
    </div>
  </div>
) : (
  <div style={{flex:1,minWidth:0}}/>
)
```

Constraints that are the point of this spec:
- **Empty message → the bare `flex:1` spacer div, no pill chrome.** An empty brass capsule sitting on the idle strip is the failure mode this three-way ternary prevents; the spacer keeps the meters right-aligned exactly as today.
- **Dot pulses only while `running` is truthy** (the screen's existing run-live boolean, already in scope at this JSX) — a pulsing dot on a terminal state would read as work in progress (same reasoning as ModeBadge's PULSING_MODES).
- **`rgba` is the file's existing module-scope helper** (used by HarnessTraceConsole the same way) — no new hex literals, no `rgba(...)` string literals (`.claude/rules/design-tokens.md`).
- **Do not use `T.brassGlow`** — its single documented job (tokens.js, CHI-05) is the "needs your input" surface; this pill is `T.brass`/`T.brassDeep` only.
- The pill (12.5px text + 8px vertical padding + 2px border ≈ 25px) must stay shorter than the ModeBadge (≈27px) so the strip's height does not change. Do not increase the pill's padding or font size beyond spec.
- The `awaiting` branch and everything else in the strip: byte-identical.
