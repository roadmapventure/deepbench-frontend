## CONTEXT

Every capability routed through the post-v6.0.0 `execute.js` loop logs a wrong `latency_ms` on its final, wrapper-level `ai_activity_log` row (the one `sendRequest()` writes itself, `ai_type: capability_slug`) — not just delegate-using capabilities. Found originally via a `quality-gate` smoke test returning `latency_ms: 49`, physically too fast for any real Anthropic round trip (`S-ARCH-AGENT-LOOP-01`, 2026-07-02).

**Root cause:** `execute.js`'s loop already makes the real model call and measures it correctly (`turnStart` → `logAgentTurn()`, `AA-120`). But when that turn is the terminal (non-delegating) one, the loop hands it to `sendRequest()` as `precomputed_turn` so the model isn't called twice. `sendRequest()` still does `const startTime = Date.now();` at its own top — *after* the real model call already happened — so its own `latency_ms = Date.now() - startTime` only measures guardrails + handler dispatch, silently excluding the actual model call.

**Reconfirmed live 2026-07-07** while diagnosing a real "Priya took ~2 minutes" report (John's own MI screen test, see `CLAUDE-STATE.md`): a direct `ai_activity_log` query showed Priya's real `hyp-hypothesis-test-intent` call (measured correctly by `logAgentTurn()` at 27,451ms) sitting right next to its own `sendRequest()` wrapper row reporting `latency_ms: 116` for the exact same call. This isn't a theoretical edge case — it's live on every single-turn and terminal-turn capability call on the platform today, and it's exactly the number AI Audit's By-Service/Avg-Latency views are built from.

**Fix:** thread the real turn's start time (`turnStart`, already captured in `execute.js`'s loop) into `sendRequest()` as a new optional `turn_started_at` param. `sendRequest()` uses it as its clock baseline when present; every existing caller that never passes it (`api/plan.js`, `confirmation.js`'s resolve path, and `sendRequest()`'s own non-precomputed path) is unaffected — `Date.now()` fallback, byte-identical to today.

**Scope note:** this fixes the *wrapper-level* row's own latency for the specific turn it represents. It does not — and is not meant to — give a single rolled-up total across an entire multi-hop delegation chain (Michelle's selection turn, Priya's own reasoning turns, Alex's format turn, etc. each still log their own correct latency separately via `AA-120`'s `logAgentTurn()`). That rollup is `AI-46` (new, `docs/FEATURES.md`), deliberately sequenced as its own session right after this one — bigger scope (schema + UI), not a one-file fix.

## TASKS (2)

### Task 1 — `api/prompt/request-receivable.js`: `sendRequest()` accepts `turn_started_at`

Change the function signature (~line 188) to add the new optional param:

```js
export async function sendRequest({ prompt_request, agent_id, capability_slug, tenant_id, precomputed_turn = null, delegation_occurred = false, turn_started_at = null }) {
```

Then change the `startTime` line (~line 222) from:

```js
  const startTime = Date.now();
```

to:

```js
  // FEATURE: AI-43 -- when execute.js's loop already ran the real callModel() call
  // (precomputed_turn path), turn_started_at carries that call's actual start time so
  // latency_ms below reflects the real model-call-through-dispatch cost for this row,
  // instead of restarting the clock here and silently excluding the model call itself --
  // the exact gap AI-43 found (a quality-gate smoke test logged latency_ms: 49, physically
  // too fast for any real Anthropic round trip; reconfirmed live 2026-07-07 on Priya's real
  // 27.5s hypothesis-test call, wrapper row logged latency_ms: 116 for the same call).
  // Callers that never pass this param (api/plan.js, confirmation.js's resolve path,
  // sendRequest()'s own non-precomputed callers) are unaffected -- Date.now() fallback,
  // byte-identical to today.
  const startTime = turn_started_at || Date.now();
```

Nothing else in `sendRequest()` changes — Step 1's `precomputed_turn` branch, guardrails, handler dispatch, and the final `ai_activity_log` write all stay exactly as they are; only the clock's starting point moves.

### Task 2 — `api/capabilities/execute.js`: pass `turnStart` through to `sendRequest()`

At the loop's terminal-turn `sendRequest()` call site (~lines 243-246), currently:

```js
      const result = await sendRequest({
        prompt_request: enriched, agent_id, capability_slug, tenant_id,
        precomputed_turn: turn, delegation_occurred: delegationOccurred,
      });
```

add the one new field, reusing the `turnStart` already captured at the top of this loop iteration (~line 197, the same value `logAgentTurn()` already uses correctly a few lines above):

```js
      const result = await sendRequest({
        prompt_request: enriched, agent_id, capability_slug, tenant_id,
        precomputed_turn: turn, delegation_occurred: delegationOccurred,
        turn_started_at: turnStart,
      });
```

No other call site in `execute.js` changes — this is the only place `sendRequest()` is called with a `precomputed_turn`.

// test-s-arch-latency-fix-01.mjs — AI-43 verification (pure Node)
import { readFileSync } from 'fs';

let failures = 0;
function check(label, cond) {
  if (cond) { console.log(`PASS: ${label}`); }
  else { console.error(`FAIL: ${label}`); failures++; }
}

// ---- Category B: source-text checks ----
const rrSrc = readFileSync('api/prompt/request-receivable.js', 'utf8');
const executeSrc = readFileSync('api/capabilities/execute.js', 'utf8');

check('request-receivable.js: sendRequest() accepts turn_started_at param', /sendRequest\(\{[^}]*turn_started_at = null/.test(rrSrc));
check('request-receivable.js: startTime falls back to turn_started_at when present', /const startTime = turn_started_at \|\| Date\.now\(\);/.test(rrSrc));
check('execute.js: sendRequest() call site passes turn_started_at: turnStart', /precomputed_turn: turn, delegation_occurred: delegationOccurred,\s*\n\s*turn_started_at: turnStart,/.test(executeSrc));

// ---- Category G: mocked sendRequest() latency behavior, no real network ----
function mockSupabaseFetch() {
  const loggedBodies = [];
  const realFetch = global.fetch;
  global.fetch = async (url, opts) => {
    const urlStr = String(url);
    if (urlStr.includes('/rest/v1/deliverables')) {
      return { ok: true, json: async () => ([{ id: 'test-deliverable-id' }]) };
    }
    if (urlStr.includes('/rest/v1/ai_activity_log')) {
      loggedBodies.push(JSON.parse(opts.body));
      return { ok: true, json: async () => ([]) };
    }
    return realFetch(urlStr, opts);
  };
  return { loggedBodies, restore: () => { global.fetch = realFetch; } };
}

function testPromptRequest(capability_slug) {
  return {
    prompt_request: {
      task_id: null,
      system_prompt: 'test prompt',
      format_contract: { output_type: 'json', skill_profile_slug: 'test_skill', schema: { type: 'object' }, handler: 'store', guardrails: { must: [], must_not: [] } },
      llm: { model: 'claude-haiku-4-5-20251001', max_tokens: 100 },
    },
    agent_id: 'test-agent',
    capability_slug,
    tenant_id: 'global',
    precomputed_turn: { tool_input: { title: 'Test', body: 'hi' }, usage: { input_tokens: 10, output_tokens: 5 }, retryCount: 0 },
    delegation_occurred: false,
  };
}

async function testTurnStartedAtUsed() {
  const { loggedBodies, restore } = mockSupabaseFetch();
  try {
    const { sendRequest } = await import('./api/prompt/request-receivable.js');
    const turnStartedAt = Date.now() - 5000;
    await sendRequest({ ...testPromptRequest('test-capability-with-start'), turn_started_at: turnStartedAt });
    const logRow = loggedBodies.find(b => b.ai_type === 'test-capability-with-start');
    check('ai_activity_log row written for the precomputed_turn call', !!logRow);
    check('latency_ms reflects turn_started_at elapsed time (>= 4900ms for a 5000ms-old start)', !!logRow && logRow.latency_ms >= 4900);
  } finally {
    restore();
  }
}

async function testBackwardCompatibleWithoutTurnStartedAt() {
  const { loggedBodies, restore } = mockSupabaseFetch();
  try {
    const { sendRequest } = await import('./api/prompt/request-receivable.js');
    await sendRequest(testPromptRequest('test-capability-no-start')); // turn_started_at omitted, like every existing caller today
    const logRow = loggedBodies.find(b => b.ai_type === 'test-capability-no-start');
    check('ai_activity_log row written when turn_started_at omitted', !!logRow);
    check('latency_ms falls back to Date.now()-based timing, stays small with no real work (< 1000ms)', !!logRow && logRow.latency_ms < 1000);
  } finally {
    restore();
  }
}

// ---- Category L: one live call, confirm the wrapper-level row's latency is now plausible ----
async function checkLiveCall() {
  const DEV_URL = process.env.DEEPBENCH_DEV_URL;
  const SUPABASE_URL = process.env.SUPABASE_URL;
  const SUPABASE_SERVICE_KEY = process.env.SUPABASE_SERVICE_KEY;
  if (!DEV_URL || !SUPABASE_URL || !SUPABASE_SERVICE_KEY) { console.warn('SKIP: live call -- env not set'); return; }
  const before = new Date().toISOString();
  const res = await fetch(`${DEV_URL}/api/capabilities/execute`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', 'x-vercel-protection-bypass': process.env.VERCEL_BYPASS || '' },
    body: JSON.stringify({
      capability_slug: 'channel-intelligence', intent_slug: 'ci-answer-display-intent', agent_id: 'marcus',
      task_context: { answer: 'Test answer for AI-43 verification.', citations: [], confidence_tier: 'sourced', needs_review: false, review_reason: null },
      tenant_id: 'global',
    }),
  }).catch(() => null);
  check('live call did not fail', !!res && res.ok);
  const headers = { apikey: SUPABASE_SERVICE_KEY, Authorization: `Bearer ${SUPABASE_SERVICE_KEY}` };
  const logRes = await fetch(`${SUPABASE_URL}/rest/v1/ai_activity_log?ai_type=eq.channel-intelligence&feature=eq.request-receivable&created_at=gte.${before}&select=latency_ms&order=created_at.desc&limit=1`, { headers });
  const rows = await logRes.json();
  check('wrapper-level ai_activity_log row found for this call', rows.length > 0);
  if (rows.length > 0) {
    console.log(`[info] wrapper-level latency_ms this call: ${rows[0].latency_ms}`);
    check('wrapper-level latency_ms is plausible for a real call (>= 300ms, not the old sub-100ms bug pattern)', rows[0].latency_ms >= 300);
  }
}

await testTurnStartedAtUsed();
await testBackwardCompatibleWithoutTurnStartedAt();
