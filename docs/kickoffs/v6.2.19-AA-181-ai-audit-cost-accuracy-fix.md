## 1. CONTEXT

John reported that AI Audit screen cost figures haven't moved in ~3 months despite real Anthropic spend (~$60+). Root-caused this design session, confirmed live against Supabase (`ai_activity_log`, project `rallojeqnkgtxgsdsnqm`):

- 9,143 of 9,186 rows (99.5%) have `cost_usd = null`. The last row with a non-null `cost_usd` is dated **2026-07-01** — the day the server-side Agent Loop / capability-execution architecture became the dominant traffic path.
- Every server-side write site — `api/capabilities/execute.js`'s `logAgentTurn()`, `api/prompt/request-receivable.js`'s two insert sites, `api/prompt/ai-enrichment.js`'s reflect/synthesis logging — captures `input_tokens`/`output_tokens`/`latency_ms` correctly but never computes or writes `cost_usd`. The only code that ever computed `cost_usd` is the client-side `logAICall()` in `useAIActivity.js`, used by legacy AI types (`chat`, `routing`, `goal_suggestion`, etc.) that carry almost none of today's real traffic.
- **Second, independent instance of the same bug found in `useAgents.js`**: `buildActivitySummary()` (feeds the MI screen's per-agent Agents drawer cost stats) also trusts `row.cost_usd` directly (`if (row.cost_usd) { d.totalCost += ... }`) and its Supabase `select()` doesn't even fetch `input_tokens`/`output_tokens`. Fixing only the AI Audit screen would leave the Agents drawer's per-agent costs equally frozen.
- Token counts ARE captured correctly everywhere in the last 30 days (e.g. `agent-turn`: 3,023 calls / 9.5M tokens; `channel-intelligence`: 674 calls / 4.0M tokens; `project-manager`: 671 calls / 5.6M tokens) — every model string in use (`claude-haiku-4-5-20251001`, `claude-sonnet-4-6`, `claude-haiku-4-5`, `text-embedding-3-small`) already has a matching key in `COST_PER_1K`, so this is a missing *calculation*, not missing pricing data.
- Real Anthropic pricing (verified this session): **Claude Haiku 4.5** = $1.00 / $5.00 per 1M tokens (input/output); **Claude Sonnet 4.6** = $3.00 / $15.00 per 1M tokens. The existing `COST_PER_1K` table uses one flat blended rate per model — Haiku's rate (`0.00025`/1K = $0.25/1M) understates the real input rate by 4x and has no output-rate concept at all; Sonnet's rate (`0.003`/1K) happens to match the real *input* rate but silently ignores the 5x output premium.

**Fix (per John's go-ahead — fold the input/output rate split in with the frozen-number fix):** move cost computation from write-time (which the dominant traffic path never does) to read-time, in both `useAIActivity.js` and `useAgents.js`, via one shared `computeCallCost()` function fed by real split input/output rates. This requires no schema change and no backfill migration — every existing and future row prices itself from the `input_tokens`/`output_tokens` it already has.

## 4. TASKS (max 4)

### Task 1 — `src/hooks/useAIActivity.js`: split cost table + shared `computeCallCost()` + read-time derivation

**1a. Replace the single-rate `COST_PER_1K` constant** (currently ~line 193-201) with two split-rate tables using the real per-1K rates (`$/1M ÷ 1000`):

```js
// FEATURE: AA-181 -- real Anthropic per-model input/output rates (verified 2026-07-14
// against published Claude pricing: Haiku 4.5 $1/$5 per 1M tokens, Sonnet 4.6 $3/$15 per
// 1M). Split input/output replaces the old single blended rate, which understated Haiku
// cost 4x and ignored Sonnet's 5x output premium entirely.
const COST_PER_1K_INPUT = {
  "claude-haiku-4-5": 0.001,
  "claude-haiku-4-5-20251001": 0.001,
  "claude-sonnet-4-5": 0.003,
  "claude-sonnet-4-6": 0.003,
  "text-embedding-3-small": 0.00002,
};
const COST_PER_1K_OUTPUT = {
  "claude-haiku-4-5": 0.005,
  "claude-haiku-4-5-20251001": 0.005,
  "claude-sonnet-4-5": 0.015,
  "claude-sonnet-4-6": 0.015,
  "text-embedding-3-small": 0.00002,
};
```

**1b. Add and export `computeCallCost()`, placed immediately after the existing `MODEL_ID_NORMALIZE` constant** (so it can resolve short-form aliases) and before `logAICall()`:

```js
// FEATURE: AA-181 -- single source of truth for call cost, used at both write time
// (logAICall(), for the legacy client-driven AI types) and read time
// (hydrateFromSupabase() below, and useAgents.js's buildActivitySummary()). Root cause
// this closes: every server-side ai_activity_log insert (execute.js, request-receivable.js,
// ai-enrichment.js) writes input_tokens/output_tokens but never a cost_usd value, so
// 99.5% of real rows had no dollar figure. Deriving cost from tokens at read time prices
// every existing and future row with no backfill migration.
export function computeCallCost(model, inputTokens, outputTokens) {
  const resolvedModel = MODEL_ID_NORMALIZE[model] || model;
  const inRate = COST_PER_1K_INPUT[resolvedModel] ?? COST_PER_1K_INPUT[model];
  const outRate = COST_PER_1K_OUTPUT[resolvedModel] ?? COST_PER_1K_OUTPUT[model];
  if (inRate == null && outRate == null) return null;
  return ((inputTokens || 0) / 1000) * (inRate || 0) + ((outputTokens || 0) / 1000) * (outRate || 0);
}
```

**1c. Update `logAICall()`'s `cost:` field** (currently `cost: tokens > 0 ? (tokens / 1000) * (COST_PER_1K[resolvedModel] || COST_PER_1K["claude-haiku-4-5"]) : null`) to use the shared function. Every existing call site of `logAICall()` passes `tokens` as output tokens only (see `DashboardScreen.jsx`'s `tokens: json.usage?.output_tokens || 0`) — treat `tokens` as `outputTokens`, `0` as `inputTokens`:

```js
cost: computeCallCost(resolvedModel, 0, tokens),
```

**1d. Update `hydrateFromSupabase()`'s row mapping** (currently `cost: row.cost_usd ? parseFloat(row.cost_usd) : null`) to prefer a real stored `cost_usd` (the 43 legacy rows that have one) and otherwise derive from tokens — this is the line that fixes the AI Audit screen's frozen total:

```js
cost: row.cost_usd != null
  ? parseFloat(row.cost_usd)
  : computeCallCost(row.model, row.input_tokens, row.output_tokens),
```

No other lines in this file change. `byType`/`byLLM`/`byService`/`byPattern`/`totalCost` aggregation logic is untouched — it already sums `e.cost || 0`.

### Task 2 — `src/hooks/useAgents.js`: same fix for the Agents drawer's per-agent cost rollup


**2b. Extend the Supabase `select()` in `fetchAll()`** (currently `.select('agent_id,ai_type,feature,model,latency_ms,cost_usd,created_at')`) to also fetch the token columns:

```js
.select('agent_id,ai_type,feature,model,latency_ms,cost_usd,input_tokens,output_tokens,created_at')
```

**2c. Replace the cost accumulation in `buildActivitySummary()`** (currently `if (row.cost_usd) { d.totalCost += parseFloat(row.cost_usd); d.costCount++; }`) with the same prefer-stored-else-derive logic as Task 1d:

```js
const rowCost = row.cost_usd != null
  ? parseFloat(row.cost_usd)
  : computeCallCost(row.model, row.input_tokens, row.output_tokens);
if (rowCost != null) { d.totalCost += rowCost; d.costCount++; }
```

This preserves the existing behavior of excluding logic-only rows with no priced model (`computeCallCost` returns `null` when neither rate table has an entry for `row.model`, e.g. `null`/`agent-directory`/`librarian` deterministic rows) from both the total and the average-cost denominator — same exclusion the old `if (row.cost_usd)` truthiness check produced, just now inclusive of every real AI-priced row instead of only the 43 legacy ones.

No changes to `classifyRow()`, the by-kind/by-model latency breakdown, or any other aggregation in this file.

## 7. NODE.JS TEST

Save as `test-AA-181.mjs` at the repo root, run with `node test-AA-181.mjs`, then delete the file.

```js
import { computeCallCost } from './src/hooks/useAIActivity.js';
import { buildActivitySummary } from './src/hooks/useAgents.js';

let failures = 0;
function assertClose(actual, expected, label) {
  const pass = actual != null && Math.abs(actual - expected) < 1e-9;
  if (!pass) {
    failures++;
    console.error(`FAIL: ${label} — expected ${expected}, got ${actual}`);
  } else {
    console.log(`PASS: ${label}`);
  }
}
function assertNull(actual, label) {
  if (actual !== null) {
    failures++;
    console.error(`FAIL: ${label} — expected null, got ${actual}`);
  } else {
    console.log(`PASS: ${label}`);
  }
}

// Haiku 4.5: $1/$5 per 1M => $0.001/$0.005 per 1K
assertClose(
  computeCallCost('claude-haiku-4-5-20251001', 1000, 1000),
  0.001 * 1 + 0.005 * 1,
  'Haiku canonical ID: 1000 in + 1000 out tokens'
);

// Legacy short-form alias normalizes to the same rates
assertClose(
  computeCallCost('claude-haiku-4-5', 500, 0),
  0.001 * 0.5,
  'Haiku short-form alias: 500 in tokens only'
);

// Sonnet 4.6: $3/$15 per 1M => $0.003/$0.015 per 1K
assertClose(
  computeCallCost('claude-sonnet-4-6', 2000, 500),
  0.003 * 2 + 0.015 * 0.5,
  'Sonnet 4.6: 2000 in + 500 out tokens'
);

// Logic-only / deterministic services (no model) must not be priced
assertNull(computeCallCost(null, 100, 100), 'null model returns null cost');
assertNull(computeCallCost('agent-directory', 100, 100), 'unpriced service slug returns null cost');

// Regression test for the actual bug: a row with null cost_usd but real tokens
// must now contribute a non-zero cost, and a legacy row with only cost_usd
// (no tokens) must still be honored as-is.
const rows = [
  {
    agent_id: 'marcus', ai_type: 'agent-turn', feature: 'channel-intelligence:ci-answer-intent:depth0',
    model: 'claude-sonnet-4-6', latency_ms: 1200, cost_usd: null,
    input_tokens: 3000, output_tokens: 400, created_at: '2026-07-14T00:00:00Z',
  },
  {
    agent_id: 'marcus', ai_type: 'chat', feature: 'Dashboard chat',
    model: 'claude-haiku-4-5-20251001', latency_ms: 300, cost_usd: '0.00042',
    input_tokens: null, output_tokens: null, created_at: '2026-06-01T00:00:00Z',
  },
];
const summary = buildActivitySummary(rows, new Map());
const marcus = summary['marcus'];
const expectedTotal = (0.003 * 3 + 0.015 * 0.4) + 0.00042;
assertClose(marcus.totalCost, expectedTotal, 'buildActivitySummary: derived + legacy cost_usd both counted');
if (marcus.costCount !== 2) {
  failures++;
  console.error(`FAIL: buildActivitySummary costCount — expected 2, got ${marcus.costCount}`);
} else {
  console.log('PASS: buildActivitySummary costCount includes both rows');
}

if (failures > 0) {
  console.error(`\n${failures} test(s) FAILED`);
  process.exit(1);
} else {
  console.log('\nALL TESTS PASS');
}
```
