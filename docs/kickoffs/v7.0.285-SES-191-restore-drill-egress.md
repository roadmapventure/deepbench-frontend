**Part 5 is the substantive addition, and it guards a claim the runbook already made with
nothing behind it.** §9 says the redaction *"is the only thing standing between a refresh and
a credential leak"* — and until now **nothing checked it**. The part asserts, on a real set:
every `runner_secrets` row has a null `value`; the rows keep their `name` (a set that nulled
whole rows would pass a leak check and lose the inventory of which credentials to re-enter);
and the manifest's `sha256` matches the redacted file.

**That last assertion is the one an editor will drop as pedantry, and it is load-bearing.**
Nulling the values changes the file's bytes, so a redaction that does not re-hash leaves a set
that fails its own `--verify-only` with *"file altered since backup"* — and the restore path
then refuses to run, mid-outage, on the one copy that was safe to publish.

## QA — discriminating, with the controls named

Four arms, all run:

| Arm | Set | Result |
|---|---|---|
| A | this cycle's fresh, redacted set | **PASS**, exit 0 |
| B | same set, one live-looking value restored, **manifest re-hashed** so only the leak assertion can fire | **FAIL** exit 1: *"carries 1 live secret value(s) of 5 rows"* |
| C | values correctly redacted, **manifest hash stale** | **FAIL** exit 1: *"was redacted but the manifest was not re-hashed"* |
| D (file-level) | **pre-change** guard from `origin/dev`, run against arm B's leaking set | **PASS**, exit 0 |

Arm D is the one that matters: the guard as it stood on `dev` reports green on a backup set
carrying a live credential. Arms B and C are separated on purpose — B re-hashes so a single
fixture cannot satisfy both assertions at once and let one of them ride along untested. The
in-test negative control repeats the same predicate against a synthetic leaking row, so a
green verdict on a set that happens to be clean still proves the predicate fires.

Build green. Regression suite **87/87** uncredentialed. Credentialed run (with
`DEEPBENCH_BACKUP_SET` + `DEEPBENCH_BACKUP_TOOLING` + live Supabase) reaches every part of this
guard rather than declaring them `notRun`.
