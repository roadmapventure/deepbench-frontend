### Task 1 — Scroll fade on the panel's content area (`src/components/AIActivityPanel.jsx`)

The scroll container is currently `<div style={{flex:1,overflowY:"auto",padding:…}}>` (~line 353). `ScrollFadeHint` renders `position:"absolute"` and needs a `position:"relative"` ancestor whose bounds match the visible viewport, so wrap it:

```jsx
// FEATURE: LOG-107 -- bottom-edge fade + bouncing chevron so the panel visibly continues below the
// fold (John: "not easy to tell you can scroll down"). Reuses the CHI-29 shared hook/component --
// no new keyframe, no new scroll math. The wrapper exists only to give the absolutely-positioned
// hint a correctly-bounded relative ancestor; it takes over `flex:1` and the scroll moves inward.
const scrollRef = useRef(null);
const { canScrollMore, onScroll } = useScrollFadeHint(scrollRef, [sections, classified.length, agentsSorted.length, platformServices.length]);
…
<div style={{flex:1,position:"relative",minHeight:0,display:"flex"}}>
  <div ref={scrollRef} onScroll={onScroll} style={{flex:1,overflowY:"auto",padding: isMobile ? "12px 14px" : "14px 16px"}}>
    … existing content, unchanged …
  </div>
  <ScrollFadeHint show={canScrollMore} bg={T.card}/>
</div>
```

`bg={T.card}` matches the panel's own background (the drawer is `background:T.card`), so the gradient fades into the real surface rather than a guessed colour. Import `useRef` from React and `useScrollFadeHint`/`ScrollFadeHint` from `./SharedUI.jsx` (that import already exists for `Corners`/`AuditRowSkeleton` — extend it). `minHeight:0` on the wrapper is required or the flex child will not scroll inside a column flex parent.

**Expanding/collapsing a drawer changes content height without a scroll event** — that is why `sections` is in the deps array above; the hook's own `MutationObserver` also covers content swaps, but passing `sections` re-attaches on the state change that matters most here.

### Task 2 — Item count on each drawer header (`src/components/AIActivityPanel.jsx`)

`SectionHeader` takes an optional `count`, rendered between the label and the chevron. Show it whenever it is a number — including `0`, which is itself honest information ("this drawer really is empty") — but **not** while that drawer's data is still loading, where a `0` would be a false zero of exactly the kind `LOG-98`/`LOG-105` removed. Pass `count={undefined}` in the loading case rather than `0`.

```jsx
function SectionHeader({ label, open, onToggle, first = false, count = undefined }) {
  const [hover, setHover] = useState(false);   // Task 3
  return (
    <div
      onClick={onToggle}
      onMouseEnter={()=>setHover(true)}
      onMouseLeave={()=>setHover(false)}
      style={{display:"flex",alignItems:"center",justifyContent:"space-between",padding:"10px 6px",cursor:"pointer",borderTop: first ? "none" : `1px solid ${T.lineSoft}`,marginTop:18,userSelect:"none",background: hover ? `${T.brass}0f` : "transparent",transition:"background 120ms ease"}}
    >
      <div style={{fontFamily:mono,fontSize:9,color:T.brassDeep,textTransform:"uppercase",letterSpacing:1.5,fontWeight:600}}>{label}</div>
      <div style={{display:"flex",alignItems:"center",gap:8,flexShrink:0}}>
        {typeof count === "number" && (
          <span style={{fontFamily:mono,fontSize:9,fontWeight:700,color:T.muted}}>{count.toLocaleString()}</span>
        )}
        <div style={{fontFamily:mono,fontSize:16,color:T.brassDeep,lineHeight:1,marginRight:2}}>{open ? "▲" : "▼"}</div>
      </div>
    </div>
  );
}
```

Note `padding` changes from `"10px 2px"` to `"10px 6px"` so the hover tint has a little breathing room around the text rather than clipping to it. That is the only geometry change permitted.

Wire the four call sites with the counts already in scope:

- By Pattern: `count={patternsLoaded ? classified.length : undefined}`
- By LLM: `count={logLoaded ? Object.values(byLLM).length : undefined}`
- By Agent: `count={logLoaded ? agentsSorted.length : undefined}`
- By Service: `count={platformServices.length ? platformServices.reduce((n, g) => n + g.services.length, 0) : undefined}`

By Service's value is the **total number of services across the layer groups** (31 today), not the number of groups — verify the shape of `platformServices` before writing this (it is an array of `{layer, services[]}`), and if the shape differs, use whatever yields the service count and say so in your report.
