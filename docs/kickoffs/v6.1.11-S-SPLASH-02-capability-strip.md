## 2. CONTEXT

John's live feedback: the splash modal's 4 animated stat counters ("6 tasks in progress," "4 agents working," "41 deliverables completed," "$372M in spend analyzed") aren't worth showing — they read as internal dashboard activity, not a reason to care, and "$372M in spend analyzed" is leftover procurement-specific language that contradicts the platform's confirmed general-enterprise positioning (`project-deepbench` memory, S-PM-05 design session, 2026-06-23).

The real problem, in John's words: **people don't understand what the agents actually do.** The fix isn't better stats — it's replacing the numbers entirely with a plain statement of capability, using real, already-shipped capability domains: Market Intelligence (Marcus/Priya/Owen's screen), Data Analysis (Nadia Farouk, `data-analysis`/`data-patch` capabilities), and Project Management (Michelle Manning). All three are confirmed real via `src/data/agents.js` (Michelle: `role: "Project Manager"`; Nadia: `role: "Data Expert"`, doing the platform's `data-analysis` capability) and the shipped Market Intelligence screen — not aspirational copy.

Approved copy/layout (confirmed with John this design session):

```
AUTOMATE
Market Intelligence  |  Data Analysis  |  Project Management
```

Same position in the panel as today's stat strip (bottom of the hero body, below the CTA button), same mono uppercase label treatment as the existing "Practice Live" label — but plain static text, no counters, no animation, no numbers.
