## 2. CONTEXT

The AI Audit can say **what** the platform did but not **who set it off**. John's CHI clicking, a regression run, and Claude's live QA all land in one undifferentiated pile; an outside visitor is invisible entirely. `LOG-121` closes that. This session captures the facts; `S-LOG-121b` displays them.

**Three findings from the design session that fix the mechanism — do not re-litigate them:**

1. **A per-call-site parameter will not work.** There are 45 `logActivity({…})` call sites across 15 source files (`lib/librarian.js` alone has 25). Threading a new argument through each is out of scope by an order of magnitude.
2. **Logging once per request and joining by `trace_id` will not work.** 58.3% of the last 30 days' rows carry no `trace_id`, spread across every `ai_type` including `agent-turn` at 30%. The join would drop most of the log.
3. **`logActivity()` is a genuine single choke point.** It wrote **27,948 of 27,948** rows in the last 30 days; the client-side browser insert in `src/hooks/useAIActivity.js` (~L779) wrote zero. So a request-scoped context read *inside* `logActivity()` covers 100% of traffic with no call-site edits.

Hence: **`AsyncLocalStorage`** (Node's standard request-context mechanism — all 12 routes are already `runtime: "nodejs"`). Verified absent from the repo, so there is nothing to reuse or extend.

**No history.** None of these five facts was ever written anywhere and none is derivable — the design session tested the most promising derivation (fingerprinting past regression runs by their `quality-gate`/`hypothesis-evaluation` rows) and it fails twice: the UI references those capabilities too, and there have been zero of either since 2026-07-18. Per §19i, historical rows stay NULL. **Every day this is undeployed is attribution that cannot be recovered** — that is why the capture side ships first and alone.

**Hand-off note for `S-LOG-121b`:** `visitor_id` is legitimately NULL for a visitor's first request and for every request from a cookie-rejecting client (see Task 1). The By Platform User drawer must therefore group NULL-`visitor_id` rows by `caller_ip` rather than dropping them or rendering them as one anonymous lump — that is a design constraint on `b`, not a defect in `a`.

**The migration is already applied** by the design session (`log_121a_caller_attribution_columns`). Five nullable columns on `ai_activity_log`: `call_source text`, `caller_ip text`, `device_type text`, `visitor_id text`, `request_host text`. **Do not write a migration.** `caller_org` is deliberately NOT a column here — it lives in an `ip_org_cache` table joined at read time in `S-LOG-121b`, so an org can be re-resolved later without backfilling log rows.

## 5. TASKS (4)

**Task 1 — new file `lib/request-context.js`: the request-scoped context.**

Exports exactly three things:

- `withRequestContext(handler)` — wraps a route handler. Returns `(req, res) => als.run(derive(req, res), () => handler(req, res))`.
- `getRequestContext()` — returns the current store, or `{}` when there is none (in-process callers, tests, anything off-request). **Never throws.**
- `runWithCallSource(source, fn)` — lets an in-process caller (a Category L session test importing `lib/` directly, which never makes an HTTP request) establish a context without a `req`.

`derive(req, res)` computes, from headers already in hand — **zero additional network calls**:

| Field | Source | Notes |
|---|---|---|
| `callSource` | `x-db-call-source` header, allowlisted to `ui` \| `regression` \| `session-test`; absent → `'ui'`; present but **not** in the allowlist → `null` | An unrecognized value must land as unattributed, never silently coerced to `'ui'` |
| `callerIp` | first comma-separated entry of `x-forwarded-for` | trim whitespace; null if header absent |
| `deviceType` | `sec-ch-ua-mobile: ?1` → `'mobile'`, `?0` → `'desktop'`; else UA regex `/Mobi\|Android\|iPhone\|iPad\|iPod/i` → `'mobile'`; else `'desktop'`; no UA at all → `null` | |
| `visitorId` | `db_visitor` cookie off `req.headers.cookie` — **only when the browser actually sent one**. A freshly minted id is set on the response but logged as NULL on that request (see below) | |
| `requestHost` | `req.headers.host` | separates the public site from the dev preview |

**Cookie minting.** When `callSource` resolves to `'ui'` and no `db_visitor` cookie is present, generate `crypto.randomUUID()` and set it on the response **only** — it does *not* become `visitorId` for this request (see the rule below; corrected 2026-08-01 after `S-LOG-121a` flagged that this sentence originally said "use it as `visitorId`", contradicting that rule two paragraphs later):

```
db_visitor=<uuid>; Path=/; Max-Age=63072000; HttpOnly; Secure; SameSite=Lax
```

**Set the cookie inside `derive()`, before the wrapped handler runs** — several routes stream SSE, and a header set after the response has begun is silently dropped. Do **not** mint a cookie for non-`ui` sources: Node's `fetch` does not persist cookies, so a regression run would mint a fresh useless UUID on every single request.

**A minted id is NOT logged on the request that mints it — `visitorId` stays `null` there.** Only an id the browser *sent back* is written. This is the whole cookie-rejection story, and it must not be treated as an edge case:

- **Cookie accepted (normal):** request 1 mints and sets, logs `visitor_id = NULL`. Requests 2..N carry the cookie and log the real id. Cost: the first row of each new visitor is unattributed. Acceptable.
- **Cookie rejected/blocked:** every request mints, sets, gets ignored, and logs NULL. That visitor collapses into one honest "no visitor id" bucket the drawer groups by IP.

Writing the minted id instead would render a single cookie-blocking visitor as **one distinct platform user per request** — the drawer's central number, silently and unfalsifiably wrong. `visitor_id IS NULL` must mean exactly one thing: *this browser has not demonstrably stored an identity.*

**Nothing in this path may throw or block.** Cookie acceptance is not observable server-side; the server sets a response header and moves on. An absent `req.headers.cookie` is `undefined` and must read as `null`, never an exception. The other four fields are wholly independent of the cookie and keep logging normally in every case.

**Do not reuse `src/hooks/useIsMobile.js`** despite the name match. It is a 768px viewport media query — a narrowed desktop window reports mobile. Different question, different answer; the two are expected to disagree and must not be wired together.

**Task 2 — `lib/activity-log.js`: read the context, write the five columns.**

- Import `getRequestContext` from `./request-context.js`.
- **Read the store as the first statement in the function body**, before the `fetch(...)` is constructed: `const ctx = getRequestContext();`. Reading it later — inside `.then()` or after an `await` — risks losing the async context. There is no `await` before the write today; keep it that way.
- Add to the POST body: `call_source: ctx.callSource ?? null`, `caller_ip: ctx.callerIp ?? null`, `device_type: ctx.deviceType ?? null`, `visitor_id: ctx.visitorId ?? null`, `request_host: ctx.requestHost ?? null`.
- These are **plumbing columns** exactly like `trace_id`/`span_id`/`dispatch_latency_ms` — **never** `call_facts` keys. A per-caller value in `call_facts` would make every row's §19k signature distinct (see the `LOG-91` comment in this file for the measured blast radius of that exact mistake).
- No new function parameters. Every existing caller is untouched and, off-request, writes five NULLs — byte-identical to today.
- `logActivity()` must stay `waitUntil()`-wrapped and fire-and-forget. Do not add validation that could throw.

## 8. NODE.JS TEST (full code — save as `test-log-121a.mjs`, delete before committing)
```js
// test-log-121a.mjs — S-LOG-121a (v7.0.34). Categories B, F, M.
import assert from 'node:assert';
import { readFileSync } from 'node:fs';
import { AsyncLocalStorage } from 'node:async_hooks';

// --- B: derive() semantics (mirror the exact rules specced in Task 1)
const ALLOWED = new Set(['ui', 'regression', 'session-test']);
function deriveSource(h) {
  const raw = h['x-db-call-source'];
  if (raw === undefined) return 'ui';
  return ALLOWED.has(raw) ? raw : null;
}
assert.equal(deriveSource({}), 'ui', 'absent header => ui');
assert.equal(deriveSource({ 'x-db-call-source': 'regression' }), 'regression');
assert.equal(deriveSource({ 'x-db-call-source': 'session-test' }), 'session-test');
assert.equal(deriveSource({ 'x-db-call-source': 'nonsense' }), null, 'unrecognized must be null, NOT ui');

function deriveIp(h) {
  const xff = h['x-forwarded-for'];
  return xff ? xff.split(',')[0].trim() : null;
}
assert.equal(deriveIp({ 'x-forwarded-for': '24.19.1.2, 10.0.0.1' }), '24.19.1.2');
assert.equal(deriveIp({}), null);

function deriveDevice(h) {
  const ch = h['sec-ch-ua-mobile'];
  if (ch === '?1') return 'mobile';
  if (ch === '?0') return 'desktop';
  const ua = h['user-agent'];
  if (!ua) return null;
  return /Mobi|Android|iPhone|iPad|iPod/i.test(ua) ? 'mobile' : 'desktop';
}
assert.equal(deriveDevice({ 'sec-ch-ua-mobile': '?1' }), 'mobile');
assert.equal(deriveDevice({ 'sec-ch-ua-mobile': '?0', 'user-agent': 'iPhone' }), 'desktop', 'client hint wins over UA');
assert.equal(deriveDevice({ 'user-agent': 'Mozilla/5.0 (iPhone)' }), 'mobile');
assert.equal(deriveDevice({ 'user-agent': 'Mozilla/5.0 (Macintosh)' }), 'desktop');
assert.equal(deriveDevice({}), null);

function readCookie(cookieHeader, name) {
  if (!cookieHeader) return null;
  for (const part of cookieHeader.split(';')) {
    const [k, ...v] = part.trim().split('=');
    if (k === name) return v.join('=');
  }
  return null;
}
assert.equal(readCookie('a=1; db_visitor=abc-123; b=2', 'db_visitor'), 'abc-123');
assert.equal(readCookie('a=1', 'db_visitor'), null);
assert.equal(readCookie(undefined, 'db_visitor'), null);

// --- B: cookie is minted for ui only (a non-ui caller minting one is the bug)
function shouldMint(source, existing) { return source === 'ui' && !existing; }
assert.equal(shouldMint('ui', null), true);
assert.equal(shouldMint('ui', 'abc'), false);
assert.equal(shouldMint('regression', null), false, 'node fetch drops cookies -- minting per request is waste');
assert.equal(shouldMint(null, null), false);

// --- B: cookie rejection. Only an id the BROWSER SENT BACK is logged; a minted one is not.
// Without this, one cookie-blocking visitor renders as one distinct platform user per request.
function loggedVisitorId(cookieHeader, source) {
  const sent = readCookie(cookieHeader, 'db_visitor');
  if (sent) return sent;                     // browser proved it stores the id
  if (shouldMint(source, sent)) { /* Set-Cookie issued as a side effect */ }
  return null;                               // minted-but-unconfirmed => NULL, never the new uuid
}
assert.equal(loggedVisitorId(undefined, 'ui'), null, 'first-ever request logs NULL, not the minted id');
assert.equal(loggedVisitorId('db_visitor=v-abc', 'ui'), 'v-abc', 'returned cookie is logged');
// a cookie-rejecting client, three requests in a row -- must be three NULLs, never three ids
const blocked = [1, 2, 3].map(() => loggedVisitorId(undefined, 'ui'));
assert.deepEqual(blocked, [null, null, null], 'cookie rejection must not manufacture distinct visitors');
assert.equal(new Set(blocked).size, 1, 'a blocked visitor collapses to ONE bucket, not one per request');
// and the other four fields are wholly unaffected by cookie rejection
const noCookieCtx = { callSource: 'ui', callerIp: '24.19.1.2', deviceType: 'desktop', visitorId: null, requestHost: 'h' };
assert.equal(buildLogBody(noCookieCtx).caller_ip, '24.19.1.2', 'IP still logs with cookies blocked');
assert.equal(buildLogBody(noCookieCtx).call_source, 'ui', 'source still logs with cookies blocked');

// --- F: the log body carries five columns; off-request writes five nulls
function buildLogBody(ctx = {}) {
  return {
    call_source:  ctx.callSource  ?? null,
    caller_ip:    ctx.callerIp    ?? null,
    device_type:  ctx.deviceType  ?? null,
    visitor_id:   ctx.visitorId   ?? null,
    request_host: ctx.requestHost ?? null,
  };
}
assert.deepEqual(buildLogBody(), {
  call_source: null, caller_ip: null, device_type: null, visitor_id: null, request_host: null,
});
assert.deepEqual(buildLogBody({ callSource: 'ui', callerIp: '24.19.1.2', deviceType: 'desktop', visitorId: 'v1', requestHost: 'deepbench.roadmapventure.com' }), {
  call_source: 'ui', caller_ip: '24.19.1.2', device_type: 'desktop', visitor_id: 'v1', request_host: 'deepbench.roadmapventure.com',
});

// --- B: AsyncLocalStorage survives the async hop logActivity() actually makes
const als = new AsyncLocalStorage();
await als.run({ callSource: 'regression' }, async () => {
  const readAtTop = als.getStore();            // how Task 2 reads it
  await new Promise(r => setTimeout(r, 1));
  assert.equal(readAtTop.callSource, 'regression');
  assert.equal(als.getStore().callSource, 'regression', 'context must survive an await');
});
assert.equal(als.getStore(), undefined, 'no context outside run() -- getRequestContext() must return {} not throw');

// --- M: every api/ route is wrapped, and the regression driver is tagged
const ROUTES = [
  'api/agent-configs.js','api/brief.js','api/extract.js','api/fetch-article.js',
  'api/load-entries.js','api/plan.js','api/rag-query.js','api/web-memory.js',
  'api/capabilities/execute.js','api/prompt/ai-enrichment.js',
  'api/prompt/db-assembly.js','api/prompt/request-receivable.js',
];
assert.equal(ROUTES.length, 12, 'Vercel Hobby function limit -- 12, no new api/ file');
for (const f of ROUTES) {
  const src = readFileSync(f, 'utf8');
  assert.ok(/export default withRequestContext\(handler\)/.test(src), `${f} is not wrapped -- its rows lose attribution silently`);
  assert.ok(!/export default async function handler/.test(src), `${f} still default-exports the raw handler`);
}
const drv = readFileSync('scripts/chi-true-regression.mjs', 'utf8');
assert.ok(/"x-db-call-source":\s*"regression"/.test(drv), 'regression driver not tagged');
assert.ok(!/call_source/.test(drv), 'call_source must be a HEADER in the driver, never a body field (SES-57)');

const logSrc = readFileSync('lib/activity-log.js', 'utf8');
assert.ok(!/call_facts[\s\S]{0,200}call_source/.test(logSrc), 'the five values must never enter call_facts (LOG-91 signature blowout)');

const ctxSrc = readFileSync('lib/request-context.js', 'utf8');
assert.ok(!/logActivity/.test(ctxSrc), 'request-context must never call logActivity -- infinite recursion');

console.log('ALL TESTS PASS');
```
