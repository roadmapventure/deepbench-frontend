`shared/agent-visibility.js` (new, pure, no imports; `src/` and `api/` both import `shared/` today) exports:
- `SHARING = Object.freeze({ PRIVATE: "private", USERS: "users", PUBLIC: "public" })`; `AGENT_ACCESS_COLUMNS = "owner_id,sharing,shared_with"`.
- `canSeeAgent(agent, viewer)`: no `agent` -> `false`. `viewer` `null`/`undefined` (no login exists) -> `true`. Else `sharing === "public"` -> `true`; no `viewer.id` -> `false`; `owner_id === viewer.id` -> `true`; `sharing === "users"` and array `shared_with` holds `viewer.id` -> `true`; else `false`.
- `visibleAgents(rows, viewer)` = `(rows || []).filter(a => canSeeAgent(a, viewer))`.
