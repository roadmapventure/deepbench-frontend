# TASKS (3)

## Task 1 — `scripts/check-format-skill-exclusivity.js` (new)

A check script in the shape of the two shipped SE-0x checks: pure exported functions, a CLI that
only runs when the file is the entry point, `--json`, and three exit codes.

**The allowlist is DERIVED, never hardcoded** (the `SE-03` lesson — a copied list gives one fact two
homes and keeps passing after the rule changes). Two derivation steps, both exported and both
asserted non-vacuous before any judgment is made:

1. `parseRuleSurfaces(architectureMd)` — locate §13's numbered item 14, take the parenthetical after
   `display/editor agents`, split on commas → `["Screen Controls", "HTML Display", "PDF Assembly"]`.
   Throw if the section, the item, or the parenthetical is absent, or if the list is empty. A rule
   that has been moved or reworded must fail **loudly**, never go quiet.
2. `resolveDisplayAgents(surfaces, agents)` — map each surface to the roster entry whose `role` is
   `"<surface> Editor"`, from `src/data/agents.js`. Throw unless every surface resolves to exactly
   one agent. Returns `{ allowed: Set<agentId>, resolution: [{surface, agentId, role}] }`.

`findViolations({ formatProfiles, capabilitySkillProfiles, assignments, allowed })` — pure. Joins
format profile → capability → agent and returns
`{ violations: [{skillSlug, capabilitySlug, agentId}], orphanProfiles: [slug], unassignedCapabilities: [{skillSlug, capabilitySlug}], examined }`.
A profile of any other `skill_type_slug` is never examined (the check must discriminate, or it
flags the whole roster).

CLI: env guard on `SUPABASE_URL` / `SUPABASE_SERVICE_KEY`; three PostgREST reads; prints the derived
allowlist and the orphan/unassigned observations on **every** run, pass or fail (the
`check-service-boundaries.js` precedent — a known gap must stay visible).

- exit **0** — every format profile is owned only by a derived display/editor agent
- exit **1** — a real violation
- exit **2** — could not run (missing env, REST failure, unparseable response, rule parse failed).
  Never a pass.

## Task 2 — `tests/regression/SE-04-format-skill-exclusivity.js` (new)

Guards the script by importing its real functions — never re-implementing them (`SES-45`, itself an
open member of this same epic). Six clauses:

1. **Parse is non-vacuous** against the real `ARCHITECTURE.md`: exactly 3 surfaces, and they are the
   three the rule names.
2. **Parse fails loudly** on a rule that has been reworded/removed (fixture) — it throws rather than
   returning `[]`.
3. **Resolution** against the real roster yields exactly `{alex, riley, claire}`; an unresolvable
   surface throws.
4. **Negative control** — the matcher fires on each violation shape: a content specialist holding a
   format profile; a second capability reaching the same profile; two agents on one violating
   capability. A `findViolations` that returned `[]` unconditionally fails here, which is what makes
   clause 5's silence mean something.
5. **Quiet on a clean fixture** — format profiles owned only by display agents produce zero
   violations, and a *non-format* profile owned by a content specialist is **not** a violation.
6. **Declared not run** — the live-data half. Credentials are not always present in the suite, and a
   conditionally-skipped half reads as a pass (`SES-180` / `SES-61` / `SE-03`).
