**The fingerprint** (Task 2), so one defect seen in three cycles groups as one:

```js
export function fingerprintFor({ agentId, kind, detail }) {
  const norm = String(detail ?? "").toLowerCase()
    .replace(/[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}/g, "<uuid>")
    .replace(/\s+/g, " ").trim().replace(/\.$/, "");
  if (!agentId || !kind || !norm) return { error: "agent, kind and detail are all required" };
  return { fingerprint: sha256(`${agentId}|${kind}|${norm}`).slice(0, 16) };
}
```

**The promotion query** — three *distinct* cycles, never three rows:

```sql
select fingerprint, agent_id, kind, count(distinct cycle_id) as cycles
  from public.runner_staff_findings group by 1,2,3 having count(distinct cycle_id) >= 3;
```
