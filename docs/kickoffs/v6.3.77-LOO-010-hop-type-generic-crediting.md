## CONTEXT

`LOO-009`'s own backlog note (`docs/FEATURES-ARCHIVE.md`) predicted `CHI-37`'s `hopEvents` mechanism would become fully removable once the harness emitted a real live completion event — true for Shape 2 (`agent_selection`/`display_format`, removed in `S-LOO-009b`). This session closes the remaining piece: Shape 1 (`qa_answer`/`proofreader`/`news_fetch`), which credits an agent independent of any delegation.

**The investigation this session was blocked on, now resolved by reading the code directly, not guessed:** `buildFinalDelegationResult()` (`execute.js`) always sets `display_agent_id` to the real completing agent whenever a call resolves via a final delegation — no exceptions. The ordinary direct-answer path only sets `display_agent_id` from a separate, unrelated param (the "format-last" override) — confirmed by direct grep that no current call site in this file ever passes it. So `finalResult.display_agent_id == null` (loose equality — the non-final path leaves it `undefined`, not explicitly `null`) is already a complete, reliable, zero-cost signal for "this agent answered directly, no delegation occurred" — nothing needed to build, it already exists on every resolved result.

**What this does NOT eliminate — a real distinction, not scope creep:** `hopEvents`' `type` string did two jobs, not one. Crediting *who* finished is now fully automatic (this session). Selecting *which descriptive template* renders (`describePipelineEvent`'s switch — Owen's rich critique text vs. a generic line) is unrelated and still needs a label. So `qa`/`gate` keep a single plain string (`hop_type`), down from an array of resolver functions to one string — a real simplification, not a literal zero-config outcome.

**`fetchNewsCards` needs no declaration of any kind, confirmed by re-checking its actual shape:** unlike `qa`/`proofreader`, its `hopEvents` entry was already hardcoded to credit `"alex"` — a *different* agent than the one the call itself is made as (`agent_id: "jordan"`) — because Jordan's capability always delegates to Alex, structurally identical in shape to the `display` call (which already needed zero Shape-1 declaration). Jordan's own `display_agent_id` will always be Alex's real id (non-null) once this call resolves, so the automatic-crediting check correctly never fires for Jordan, and Alex's own credit was already fully covered live (`onDelegationProgress` + the fixed pairing logic, `S-LOO-009b`) — `appendHopEvent`'s special always-append case existed only to work around the pre-`S-LOO-009b` pairing bug it no longer needs to work around.

function resolveHopEvents(hopEvents, result, t0) {
  const elapsed = Date.now() - t0;
  return hopEvents
    .map(({ type, resolveAgentId, resolveData }) => {
      const agentId = resolveAgentId(result);
      if (!agentId) return null;
      const data = resolveData ? resolveData(result) : result;
      const durationMs = NON_MEASURABLE_EVENT_TYPES.has(type) ? null : elapsed;
      return buildHopEvent(type, agentId, data, durationMs);
    })
    .filter(Boolean);
}

async function callCapability({ capability_slug, intent_slug, agent_id, task_context, runtime_context = null, format_skill_profile_slug = null, display_agent_id = null, onProgress = null, isStale = () => false, onEvent = null, hopEvents = null }) {
  if (onEvent && !hopEvents) {
    throw new Error(`callCapability: onEvent supplied without hopEvents for ${capability_slug}/${intent_slug} — every caller must declare how to resolve the completing agent(s). See LOO-009/CHI-37.`);
  }
  const t0 = Date.now();
  const res = await fetch("/api/capabilities/execute", { /* unchanged */ });
  if (!res.ok) throw new Error(`${capability_slug} ${intent_slug} failed: ${res.status}`);
  const first = onProgress ? await readSSEResult(res, onProgress) : await res.json();
  const result = await resolveInProgress(first, onProgress, isStale);
  const finalResult = result.status ? result : { ...(result.content || {}), patterns_used: result.patterns_used || [] };
  if (onEvent && hopEvents && !isStale()) {
    for (const evt of resolveHopEvents(hopEvents, finalResult, t0)) onEvent(evt);
  }
  return finalResult;
}

// AFTER (resolveHopEvents() deleted entirely; callCapability() gains automatic crediting):
// FEATURE: LOO-010 — resolveHopEvents()/the hopEvents array shape are gone. Agent-crediting is now
// fully automatic: finalResult.display_agent_id is set, always, by buildFinalDelegationResult()
// whenever this call resolved via a final delegation (confirmed live in code, no exceptions across
// any current call site) — that single existing field is a complete signal, no caller-supplied
// resolver function was ever needed to answer "did an internal delegation happen." What still
// varies per call site is only the DESCRIPTIVE label (hop_type), unrelated to crediting — a plain
// string, not a function, passed only by a caller whose own agent might legitimately answer
// directly (qa_answer/proofreader — Jordan's news-search and the display call always delegate, so
// neither needs one).
async function callCapability({ capability_slug, intent_slug, agent_id, task_context, runtime_context = null, format_skill_profile_slug = null, display_agent_id = null, onProgress = null, isStale = () => false, onEvent = null, hop_type = null }) {
  const t0 = Date.now();
  const res = await fetch("/api/capabilities/execute", { /* unchanged */ });
  if (!res.ok) throw new Error(`${capability_slug} ${intent_slug} failed: ${res.status}`);
  const first = onProgress ? await readSSEResult(res, onProgress) : await res.json();
  const result = await resolveInProgress(first, onProgress, isStale);
  const finalResult = result.status ? result : { ...(result.content || {}), patterns_used: result.patterns_used || [] };
  // FEATURE: LOO-010 — fires only when this call's own agent genuinely answered directly
  // (finalResult.display_agent_id is null/undefined — loose equality intentional, both mean "no
  // delegation resolved this call"). When a delegation DID resolve it, display_agent_id is always
  // set and the harness's own live delegation_complete event (LOO-009) already credited the real
  // completing agent — nothing to do here in that case.
  if (onEvent && hop_type && !isStale() && finalResult.display_agent_id == null) {
    onEvent(buildHopEvent(hop_type, agent_id, finalResult, Date.now() - t0));
  }
  return finalResult;
}

// test-loo-010.mjs
import assert from 'node:assert/strict';

function creditIfDirectAnswer({ onEvent, hop_type, agent_id, finalResult, isStale = false }) {
  if (onEvent && hop_type && !isStale && finalResult.display_agent_id == null) {
    onEvent({ type: hop_type, agentId: agent_id, data: finalResult });
    return true;
  }
  return false;
}

const events = [];
const onEvent = (e) => events.push(e);

// Direct answer (display_agent_id absent) — must credit.
assert.equal(creditIfDirectAnswer({ onEvent, hop_type: "qa_answer", agent_id: "marcus", finalResult: { answer: "..." } }), true);
assert.equal(events.length, 1);
assert.equal(events[0].agentId, "marcus");

// Final delegation (display_agent_id set) — must NOT credit; harness's live event already did.
