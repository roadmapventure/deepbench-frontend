## CONTEXT

**Found (John, live, 2026-07-27):** in the theory/forecast flow, the test-completion status renders as a **standalone chat bubble** reading "Full Agent Routing & Answer Given in 1m 12s" — visibly inconsistent with every other message's close-status, which is the centralized `HopSummaryLine` **caption** ("[hop badge] Full Agent Routing & Answer in N hops total, Xs (expected < 2m)").

**Root cause (verified by code read):** two mechanisms exist. The centralized one is `formatHopSummary`/`HopSummaryLine` (L1079–1108) — a caption under a message. But the hypothesis-test completion ([L3614](src/screens/MarketIntelligenceScreen.jsx:3614)) hand-formats a bare string into a plain `non_qa` message body:
```js
setMessages(prev => [...prev, buildMessage({ kind: "non_qa", text: `Full Agent Routing & Answer Given in ${formatElapsed(chiTestElapsedMs)}` })]);
```
It carries no `hopStart`/`hopEnd`/`estimate`, so no caption renders — the status *is* the bubble body. `CHI-58` created this bubble (moving the Result drawer's elapsed line into chat); `CHI-74` (v6.3.148) then standardized the *other* grounded-work bubbles (routing ack, theory candidates) onto `HopSummaryLine` but did not include this one — so it is the last straggler. All the data the centralized caption needs is already computed on the lines just above (`hopCountBeforeTurn`, `currentHopCount(...)`, `chiTestElapsedMs`).

**Fix (John's explicit direction — "make it consistent with our centralized completion status, the single line under the bubble"):** render the completion via the centralized `HopSummaryLine` caption, exactly like the Q&A completion bubble (a Marcus sentence + caption underneath). Because the test result content itself lives in Column 2, the chat bubble carries a short Marcus completion sentence (John-approved copy below) and the caption shows the real hop/time/estimate. The test *is* an answer, so it reads "…& Answer in…" (`isAnswer: true`) — the default `MessageBubble` branch currently hardcodes `isAnswer={false}` (a `CHI-74` assumption that all non-qa grounded-work bubbles are non-answers), so that is made message-driven.

**Not in scope:** the start-ack bubble (L3583, already correct); any other message shape; the general status-ownership work (`CHI-75`, shipped). Copy is John-approved verbatim (below) — do not reword.

```js
// test-chi-76.mjs — pure Node, no app imports.

let pass = 0, fail = 0;
function assert(cond, label) {
  if (cond) { pass++; console.log(`PASS: ${label}`); }
  else { fail++; console.log(`FAIL: ${label}`); }
}

// --- Mirror of formatHopSummary (L1079) ---
function formatElapsed(ms) { const s = Math.max(0, Math.floor(ms/1000)); const m = Math.floor(s/60); return m>0 ? `${m}m ${s%60}s` : `${s}s`; }
function formatHopSummary(hopEnd, totalElapsedMs, isAnswer = true) {
  if (hopEnd == null || totalElapsedMs == null) return null;
  const hopWord = hopEnd === 1 ? "hop" : "hops";
  const lead = isAnswer ? "Full Agent Routing & Answer" : "Full Agent Routing";
  return `${lead} in ${hopEnd} ${hopWord} total, ${formatElapsed(totalElapsedMs)}`;
}
// --- Mirror of the default branch's message-driven isAnswer (L1593 after fix) ---
function bubbleIsAnswer(msg) { return msg.isAnswer ?? false; }

// The hyp-test completion message (Task 1c) renders the centralized "& Answer" caption
{
  const msg = { kind:"non_qa", hopStart:11, hopEnd:16, totalElapsedMs:72000, isAnswer:true };
  const caption = formatHopSummary(msg.hopEnd, msg.totalElapsedMs, bubbleIsAnswer(msg));
  assert(caption === "Full Agent Routing & Answer in 16 hops total, 1m 12s", "completion caption reads '& Answer in N hops total, 1m 12s' (matches John's 1m 12s repro)");
  assert(!caption.includes("Given in"), "no more bare 'Given in' wording");
}
// Existing non-answer bubbles (ack, candidates) still drop '& Answer' (no isAnswer field)
{
  const ack = { kind:"non_qa", hopStart:10, hopEnd:10, totalElapsedMs:2000 };
  const caption = formatHopSummary(ack.hopEnd, ack.totalElapsedMs, bubbleIsAnswer(ack));
  assert(caption === "Full Agent Routing in 10 hops total, 2s", "ack/candidate bubble unchanged: 'Full Agent Routing in ...' (no '& Answer')");
  assert(bubbleIsAnswer(ack) === false, "message with no isAnswer field defaults to false");
}
// isAnswer flag flips only the lead phrase
{
  assert(formatHopSummary(5, 1000, true).startsWith("Full Agent Routing & Answer"), "isAnswer=true -> '& Answer'");
  assert(formatHopSummary(5, 1000, false).startsWith("Full Agent Routing in"), "isAnswer=false -> no '& Answer'");
}

console.log(`\n${pass} PASS, ${fail} FAIL`);
if (fail > 0) { console.log("ALL TESTS PASS: NO — fix before committing"); process.exit(1); }
console.log("ALL TESTS PASS");
```
