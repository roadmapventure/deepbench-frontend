## 2. CONTEXT

**What John asked for:** annotate each Product Focus Area with its current release state, muted (small, gray, parenthesized) so it reads as a quiet suffix, not part of the title:

| Focus area | Status |
|---|---|
| Channel Sales Intelligence | **Beta** |
| Project Management | **Alpha** |
| Spend Analysis | **Alpha** |

Two surfaces per John: (1) the Work dropdown, after each item; (2) each focus area's screen homepage title.

**Homepage title reality (verified this session):** only Channel Sales shows its focus-area name as the page title. John's decision (confirmed live): **append the status to whatever title is already there.**

| Focus area | Route | Homepage title becomes |
|---|---|---|
| Channel Sales Intelligence | `/` — `MarketIntelligenceScreen.jsx` | Channel Sales Intelligence **(Beta)** |
| Project Management | `/work` — `DashboardScreen.jsx` | Your work... Defined **(Alpha)** |
| Spend Analysis | `/work/:taskId/analyze` — `AnalyzerScreen.jsx` | Spend Analyzer **(Alpha)** |

The Spend homepage title is `Spend Analyzer` on the data-source landing screen (`DataSourceScreen`, desktop + mobile) — John confirmed that's the target; confirm live in QA it's the first heading seen at the Spend route.

**Single source of truth (the design point):** the three status values are rendered in 5 spots. Inlining `(Beta)`/`(Alpha)` at each would scatter the values and re-declare the muted styling five times, so a graduation (Alpha→Beta, or →GA) means hunting five sites. Instead, one `FOCUS_AREA_STATUS` map + one `FOCUS_STATUS_STYLE` object in `tokens.js` (the repo's established home for shared maps like `FLAG_COLORS`/`PALETTE`). Every site reads the same value and same style; render is guarded so a `null` status makes the tag disappear everywhere at once — that's how a focus area graduates to full release: set its value to `null`, one edit.

### Task 1 — `src/tokens.js`: add the shared status map + style

Add after the font exports (after the `body`/`mono` lines, ~L34 — must be below `export const T` at L8 and `body` at L33 since the style object references both):

```js
// FEATURE: SH-23 -- single source of truth for Product Focus Area release status.
// Rendered muted (T.muted, 0.72em relative to the title it sits beside, weight 400) in the Work
// dropdown, the mobile nav, and each focus area's homepage title. Graduating a focus area to full
// release is one edit: set its value to null and the guarded render drops the tag everywhere.
export const FOCUS_AREA_STATUS = {
  channelSales:  "Beta",
  projectMgmt:   "Alpha",
  spendAnalysis: "Alpha",
};
export const FOCUS_STATUS_STYLE = { color: T.muted, fontSize: "0.72em", fontWeight: 400 };
```

Note: `FOCUS_STATUS_STYLE` deliberately does **not** set `fontFamily` — the tag inherits each title's own font (John's call: reads as a quiet suffix, not a foreign chip). `0.72em` keeps it proportionally small at every size (13px dropdown row → ~9px; 32px "Spend Analyzer" → ~23px) with no per-site pixel tuning.

## 6. DESIGN RULES

- **Muted treatment only.** Tag = `T.muted` (#786d52, from `tokens.js` — never a hardcoded hex, per `.claude/rules/design-tokens.md`), `0.72em`, `fontWeight:400`, parenthesized with a single leading space `" ("`. It must read as a de-emphasized suffix, not compete with the title.
- **Inherit the title's font** — do not set `fontFamily` on the tag (John's explicit call).
- **Guarded render everywhere** — every site is `{status && <span…>}`; a `null`/empty status renders nothing (no empty parens, no stray span). This is the graduation mechanism, not just defensiveness.
- **No layout shift** — the tag is inline text in the existing title element; it must not wrap to a new line or change the title's box on desktop or mobile. Check both.
- Do **not** restyle, resize, or reposition any existing title text — only append the tag.
