# SES-136 — the briefing rebuild contract's template trap

`public.backlog_items`' `SES-136` row is the pointer; this file holds the full self-filed report and
the ship record. Written at close-out because the row crossed the 2,000-char cap
`scripts/check-session-docs.js` check 3d enforces — the detail moves here, the row keeps a pointer,
nothing is deleted.

## The defect, as cycle `f0acf9ab` self-filed it (2026-08-23, `v7.0.170`)

Regeneration step 4 of `docs/runbooks/briefing-page.md` exists to forbid one thing: shell-processing
the fetched page out of `~/.claude/projects/…/tool-results/`, because any Bash command against that
path fires a harness permission prompt only a human can see (`SES-96` — John captured the
screenshot; a cycle sat parked on *"Allow Claude to run Extract reusable head, code prologue, code
epilogue?"*). Having forbidden it, step 4 offered a replacement that named **no executable**:

> *"…parse the `briefing-state` JSON in context, and rebuild the page structurally from
> `docs/runbooks/briefing-template.html` + the `runner_` tables (the contract below already says
> this)"*

Followed literally that is a hand rebuild of a template carrying **sample** rows — masthead
*"Aug 19, 2026 CST / v7.0.94"*, card 5.1 the retired `item-ses78a`. `f0acf9ab` took the other
branch: it read the published page with Bash and node, diffed it against the template, and applied
its own change plus 20 asserted substitutions onto the live code. A correct page, by a method the
same step forbids — and it reported itself rather than leaving it to be found. **No permission
prompt fired**, which that cycle correctly recorded as an observation and not a licence.

*Followed literally it wipes the live page; followed sensibly it breaks the written rule* — the
ticket's own title.

## Why the fix is a pointer and not the decision the ticket asked for

The ticket put a choice to John: **(a)** make the template the real source by regenerating all
fourteen sections from queries every rebuild, or **(b)** sanction reading the previous page through
the Artifact tool's own read action (cheaper, no `~/.claude/` path — but it makes the published page
the source of truth for its own next version, the drift the template was meant to prevent).

**(a) shipped while the ticket waited**, under two other tickets, without this one being closed:
`SES-149` (`v7.0.200`) built `scripts/build-briefing.mjs`, and `SES-163` (`v7.0.207`) moved every
mechanically derivable section into it, leaving five authored prose fields. Measured 2026-08-24
rather than recalled:

| Sample marker | in `briefing-template.html` | in the page built and published at `v7.0.234` |
|---|---|---|
| `item-ses78a` | present | **absent** |
| `v7.0.94` | present | **absent** |
| `Aug 19, 2026` | present | **absent** |

Every builder substitution is anchored and a moved anchor is **exit 2** — a refusal, never a page
with a section still reading *"Sample value"*. So the failure mode is closed in practice, and
**(b)'s permission-gate exposure never has to be granted.**

What was still owed: the doc already carried step **1a** (*"THE REBUILD HAS A BUILDER NOW — USE
IT"*), but **step 4 — the step a cycle reaches while it is being told what not to do — still pointed
at the hand rebuild.** That is precisely the moment the contract most needs to hand a cycle the
thing it should do.
