# AGT-348 — a shorter path than manual connector setup

Research done 2026-10-05 (session `connect-claude-link`) against public sources; claude.ai itself
could not be opened from the cloud session (Cloudflare challenge on `curl` and headless Chromium,
no signed-in account), so nothing below about claude.ai's live behaviour is verified first-hand.

## 1. Claude — pre-filled "Add custom connector" link (shipped, slice 1)

- `https://claude.ai/customize/connectors?modal=add-custom-connector` opens the Add custom connector
  dialog. The settings page moved from `/settings/connectors` to `/customize/connectors`.
- Pre-filling Name and URL is **undocumented** and reported with two param pairs:
  `mcpName` / `mcpServerUrl` (anthropics/claude-ai-mcp issue #74, closed without a visible Anthropic
  reply; technochicken/BewerbungDB PR #4) and `connectorName` / `connectorUrl` (i2mint/py2mcp #9).
- Slice 1 sends **both** pairs. Worst case the dialog opens empty and the copy box beside the link
  covers it, so the link can only shorten the path, never break it.
- Our agent addresses need no sign-in, so a filled dialog is one click (**Add**) from done:
  8 steps → 2.

## 2. Other tools

- **ChatGPT:** no known deep link that opens or pre-fills "Create MCP app". The ChatGPT pill stays
  manual.
- **Claude Code:** one line — `claude mcp add --transport http <name> <address>`. Candidate third
  pill; not in slice 1.
- **Cursor / VS Code:** both support install deep links (`cursor://anysphere.cursor-deeplink/mcp/install?…`,
  `vscode:mcp/install?…`). Candidate pills; not in slice 1.

## 3. Directory listing (true one-click "Connect")

Anthropic's Connectors Directory gives a listed server a single Connect button. Requirements
(public sources): submitted from a Claude Team/Enterprise org, a public remote MCP server, a working
auth flow, a reviewer test account, Anthropic review. It does **not** fit per-agent private addresses:
a listing is one server, so DeepBench would need one address plus a sign-in that decides which
agents a user sees. That is a product/auth decision for John, not a slice of this ticket.

## 4. Open check

reads (or neither). If one pair is dead, drop it from `src/lib/connectLinks.js`; if neither fills,
reword the button's note to "then paste the URL".
