  direction that could manufacture a false *approve*, and a not-run set of 71 tests on a credentialed
  run is a very wide hole to open. The Auditor's wording — "neither standing nor newly red — the
  absolute exit code stands" — is the fail-closed reading, and it matches the function's four existing
  fail-closed exits.

  the primary fix: it is an instruction-level guard on a doc this slice cannot touch, and after the
  code can be handed a mismatched baseline by anyone, "we told them not to" is not a mechanism.
  pattern:10. Kept as the *secondary* guard instead: task 3(d) adds `SUPABASE_SERVICE_KEY` to the
  existing conditional `ARMED` needles, so the day someone arms the runbook, an uncredentialed capture
  line fails the guard before it can grade a ship.

  reason: the file states twice that a new fact reaches the ledger through the free-text column or the
  payload, a migration would spend a file slot, and `reasoning` already carries the delta line.
