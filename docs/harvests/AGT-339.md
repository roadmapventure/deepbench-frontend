## Design choices and what they do not do

1. **Pure module plus additions-only screen edit.** The logic and both reads live in `src/lib/personnelActivity.js` with the supabase client passed in, so the test imports it with plain Node. The alternative (a `.jsx` tab file compiled with esbuild, as `log-143b` does) was dropped after the baseline: that test exits 3221226505 after printing `[PASS]` in 4 of 5 runs on this machine.
2. **The view returns finished strings** (`cards` of `[key, value]` rows). The screen only maps them, so every number John sees is asserted by the test, including Central-time day boundaries.
3. **Cost rule** mirrors `buildActivitySummary()` in `src/hooks/useAIActivity.js` (session rows cost 0; stored `cost_usd` first; `computeCallCost` fallback). That hook cannot be imported by Node (it imports the supabase client), so the three-line rule is restated over the shared pricing function rather than shared. It omits the pre-2026-07-16 pairing dedup, which cannot apply to an agent created after that date.
4. **Lessons taught** reads the `entries` the screen already loads for the Training tab (`/api/load-entries`), counting `status === "active"` — the same rows the bundle hands over — so no third read.
5. **Pattern names** come from `PATTERN_CATALOG` (`RAG`, `Embeddings`), the catalog the screen's `AI_PAT` badges already use. `pattern_vocabulary` has no row for either slug.
6. **No feature flag.** The session is attended and the layout is John's recorded decision; `.claude/rules/autonomous-surface-changes.md` binds Automated mode only. The edit still deletes no line of the screen.
7. **Not done here:** no realtime refresh, no per-connection list, no index on the log, nothing for `AGT-340`/`AGT-341`.

## Things I was unsure of

- **Tab icon.** Every sidebar tab carries a glyph and the recorded layout names none. I chose `◉` from the same Unicode block as the existing four. It is a visible element John did not explicitly see.
- **`embeddings` vs `Embeddings`.** John's approved line reads "RAG, embeddings (1 call)"; the catalog name is capitalised. I kept the catalog name so one pattern has one name everywhere.
- **`patterns_used` is called frozen legacy** by `.claude/rules/ai-pattern-signature.md` ("never read for classification"). John approved reading it for this line on 2026-10-03, and the tab displays it rather than classifying with it, so the kickoff follows his decision. The rule's path list does not include the new file.
- **Library access wording.** `denied-no-access` and `denied-no-config` both show as `No access`.
- **`?tab=activity` on a non-private agent** falls back to Profile through one added effect.
- **The 1000-row page loop** is specified but untested by the fixture; no private agent is near 1000 rows today (`bob` has 657 and is not private).
