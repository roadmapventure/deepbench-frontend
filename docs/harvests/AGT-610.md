## 2. The calls (mine, reversible — JOHN-0925-DESIGNER-DECIDES)

1. **Attempts are counted per `backlog_id`.** A split part is its own ticket with its own ledger; the parent's attempt 1 *is* the split. The directive says "per original ticket"; a parent/child grain would need a column no existing structure carries and would double-count the parent's parts. Reversal: add `parent_backlog_id` later and group by it.
2. **No runbook edit.** The refusal hook is `record_skip()`'s own refusal (a cycle cannot miss a 23514 that names the next call); the pickup hook is the cycle card's `gate` note. `runner-cycle.md` is untouched and the ceiling is not spent.
3. **No new waste cause** (see §1). The brief group reads the ledger function, not the vocabulary.
4. **The ballot is reported, not built.** A disagreement between the Designer and the Development Manager's cap ruling is recorded by the DM's ruling itself (it is a reversible decision with a handle) and surfaced in the brief; the ballot capability is a clause-7 act John must create. Named in the STOP LINE, not asked.
5. **Anthropic `/feedback` is attempted, never asserted.** `--diagnose` spawns the Claude Code CLI the same way `scripts/read-usage-meter.js` spawns `/usage` and records the first 400 characters of what came back in `feedback_result`; the brief prints the text paste-ready either way (pattern:33: show only what was verified).
6. **State is derived, never written twice.** `shipped` comes from `backlog_items.status`; `parked` from the ledger; nothing writes `design_status` (QA 4's "the diagnostic changes nothing" would otherwise be false by construction).
7. **The risk block is a fenced block, like `anchors`** (AGT-226's shape), not an eighth section: the seven-section rule (STANDARDS §3) stays at seven.

## 3. Alternatives weighed

- *A new cause `permission_refused`* in `runner_cycle_cause()`: the function is immutable over cycle columns and a refusal is not on the cycle row. Rejected; join on `refused_cycle` instead.
- *Make refusal-parked tickets pickable again* via `pick_blocking_flags()`: the ordinary pick would rebuild the same kickoff and meet the same refusal — guard 4 by another road. Rejected; the pickup is a Designer redesign first.
