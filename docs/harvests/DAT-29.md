### Part C — RLS on the 33 tables, with policies that mirror today's grants
- **Touches:** `ALTER TABLE … ENABLE ROW LEVEL SECURITY` on 33 tables; one permissive policy per (table, privilege) that anon/authenticated hold today.
- **Reach:** 14 browser-read tables directly and 8 browser-read views through their base tables (finding 4), 19 further exposed tables the browser does not read, and the 61 public-key tests. This is the part the ticket parked.
- **How the "blank bench" risk is engineered out (the answer to the parking reason):**
  1. *The policy list is derived from the grants, not from a reader survey.* For every table where `pg_class.relacl` gives anon or authenticated SELECT / INSERT / UPDATE, create `USING (true)` / `WITH CHECK (true)` for exactly that privilege and role. A grant plus an always-true policy returns exactly what the grant alone returned, so behaviour is preserved by construction, including for a reader nobody surveyed. Zero-grant tables get no policy. Column-list grants (LOG-124) are untouched — RLS filters rows, never columns.
  2. *The migration proves itself or does not commit.* DDL is transactional. A trailing `DO` block does `SET LOCAL ROLE anon`, counts rows on every granted table and through every one of the 11 views, and compares with the counts taken as anon at the top of the same transaction; any difference, or any 42501, raises and the whole migration rolls back. The live site never sees a wrong policy. This is the same pattern `ses315_ship_decision` used (the rule file's SES-315 addendum).
  3. *After commit:* the real publishable key over the 27 relations, both directions, then the 24-case CHI live regression.
- **Open facts this depends on (M2, M5):** that the owner of every definer view and definer function bypasses RLS (table owner, or `rolbypassrls`) — if a view's owner is a different non-bypass role, the view goes empty; the in-transaction check in step 2 catches it, but the design must know before it writes.
- **Undo:** `ALTER TABLE … DISABLE ROW LEVEL SECURITY` + `DROP POLICY`, from the captured down. Seconds, no data touched.
