## 2. Alternatives considered and rejected

1. **(a) Wrap the `ingestFindings` call in try/catch in `record()`.** Rejected: it converts a real ledger failure into a silent non-append — exactly the state the ticket exists to end. The defect is a parse of a body that was never going to be JSON, so the fix belongs at the parse site (pattern:8 — the narrowest layer that actually works).
2. **(a) Switch the injected poster to `return=representation`.** Rejected: it hides the class of bug rather than removing it, and leaves `get()`/`post()` still unable to say which read came back empty — which is what the ticket's own Fix clause asks for.
3. **(b) Drop `asked_at` from the insert and let the column default, keeping `on_conflict`.** Rejected: `uniq_card_ask` still contains `asked_at`, and the question text moves with the cycle count, so no unique index on this table can express "one unanswered ask per fingerprint". The guard has to be a read.
4. **(b) Widen `uniq_card_ask` to `(target_kind, target_id)`.** Rejected: it would forbid a legitimate second ask after John answers the first, which is behaviour the platform wants (pattern:1 — eliminate the duplicate, don't forbid the recurrence).
5. **(c) A new `status='superseded'`.** Rejected: a CHECK widening plus a new vocabulary word on a surface John reads (pattern:53, one name per object; pattern:57, size the vocabulary to what occurs).
6. **(c) Write `answer` on the 33 rows.** Rejected: `answer` is John's ruling on a `skill-edit` ask. The platform filling it in would be recording a decision he never made (pattern:99).
7. **(c) A `--dedupe` mode on `staff-watch.js`.** Rejected: a one-time data fix does not earn permanent script surface, and once (b) is guarded the condition cannot recur (pattern:65).
8. **(d) Follow the ticket's second branch.** Rejected on the rows above and B37.

- It does not reroute `--record` so the raw write and the raise share one transaction; a ledger append that fails still leaves the counter's row, which is the ordering AGT-131 chose deliberately.
