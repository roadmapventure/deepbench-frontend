# AGT-232 — the premise, measured

## 1. The premise is ALIVE

AGT-183 (v7.0.625) shipped a `passed_over` answer shape but did not retire this ticket. Read live this cycle:

- `scripts/run-project.js` — the `stop` branch (~L1118) and the `report` branch (~L1123) each carry the literal `recorded: false` and the prose `Nothing was written.`. The off-pick `assign` is refused at check (c) (~L1040) with `Exiting ${EXIT_CANNOT_RUN} -- nothing was written.` So **all three** shapes a correct read of an unbuildable head can take write nothing.
- `passOverErrors()` condition 3 requires every passed-over id to be in `state.blockers`, which is `public.project_blockers` read verbatim.
- `pg_get_viewdef('public.project_blockers')` — ten structural `CASE` arms only: project not executing, no priority class, no queue number, `design_status='needs-desktop'`, `defer_status in (yes,stuck)`, no scope rationale post-cut, `blocked_by` unresolved, milestone design gate unresolved, claimed inside 24h, delivered. A head unbuildable for a reason none of those ten arms can express — a dead premise, a dependency nobody filed as `blocked_by`, a decision that is genuinely John's and not yet on a card — has **no recordable shape at all**. The manager names it and loses the whole answer, or names the head and builds something unavailable. Live cost seen an hour before this design turn: a manager turn named an off-head ticket, the driver refused, ~120k tokens bought no row.

## 3. Alternatives weighed and rejected

- **Widen `project_blockers` to carry unresolved `runner_skips` rows.** Rejected: it hands the manager exactly the re-ordering power AGT-183's condition 3 exists to withhold — write a skip, then pass over it. Also checked: `prime_directive_queue()`'s `buildable` CTE does not read `project_blockers` at all, so the widening would not even move the pick.
- **Teach `dm-run-intent` / `dm-guardrails` a new answer key.** Rejected as unbuildable here: AGT-203 recorded that a Skill row is John's call and nothing in an unattended run edits one. The chosen design needs no Skill row, because `report` is already required on every answer.
- **A new `record_unbuildable()` function or a `runner_unbuildable` table.** Rejected (pattern:17, pattern:8): it would duplicate `record_skip`'s before-image, its `skip_count` dedupe, its unblock-action map and its briefing reader, and it would engage both `.claude/rules/*` SQL invariants for no gain.
- **Record on `report` only.** Rejected: the ticket's own sentence is about the refusal, and a fix that leaves the refused turn writing nothing does not satisfy it (pattern:95).

## 4. What this ship does NOT do

It does not let the cycle build the off-head row — the refusal, its exit code and its `answer_errors` lines are unchanged, and the head keeps its slot. It only makes the declined read **recordable**, so the turn buys a row and John gets a question. Whether a recorded skip should eventually move the pick is a separate question and is not decided here.
