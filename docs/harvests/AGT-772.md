## Premise (measured 2026-11-21 05:24Z = 2026-11-20 23:24 Central, tree 3a58953a = origin/dev)

## Decisions (mine, reversible; JOHN-0925-DESIGNER-DECIDES)

- **D1 -- where the figures live.** Three `numeric not null` columns on `runner_settings` (defaults 10 / 25 / 35, CHECK > 0). Undo: the columns are read only by `platform_budget_status()`; leave them or drop attended.
- **D2 -- one function.** `platform_budget_status()`, SQL, STABLE, `search_path = public`, execute revoked from public/anon/authenticated, granted to service_role (a new function is executable by PUBLIC by default). Returns the three totals, the three limits and the three reopening instants (local midnight + 1 day / Monday + 7 days / 1st + 1 month, converted back to UTC, so DST is handled by Postgres). One scan of the wider of the week and month windows; three sums over it. Undo: drop function (captured down).
- **D3 -- where the check sits.** Step 3a: after the IP derivation and the env check, before the key gate (3b). So it covers keyless visitors, keyed sites, passed end users, `unlimited` addresses and `unlimited` keys alike, and never runs for `OPTIONS`, the two browse-safe GETs, the `x-db-gate-bypass` header, or a request with no derivable IP (local `vercel dev` only; Vercel always sets x-forwarded-for). The platform's own `MCP_API_KEY` is an outside caller (default YES per the ruling: outside callers only, John's address not exempt) -- John's Claude connector and the scheduled personal agents that call `/api/mcp` are refused while a period is spent. Today that connector reaches production, which does not get this until a release to main.
- **D4 -- refusal precedence.** When several periods are spent, the one whose `reopens_at` is latest is reported (scope item 5). The check runs before every other refusal, so a spent budget reads `budget` even for an unknown key or a blocked address.
- **D5 -- failure posture.** Any non-2xx, timeout, non-object body or non-finite field throws inside `fetchBudget()`/`spentPeriod()`; the catch prints one `[AGT-772 gate] budget lookup failed, check skipped ...` line and the rest of the gate runs unchanged (fails open on the budget only -- a stored block still refuses). Distinct prefix so the HAR-33 "did fail-open fire" grep stays honest.
- **D6 -- the popup.** Copy is exactly John's (97dcfccb), built by pure `budgetCopy(period, reopensAt)` in gate-intercept.js so node can assert it without JSX. Day: "at midnight Central"; week: "Monday"; month: `toLocaleDateString('en-US', { timeZone: 'America/Chicago', month: 'long', day: 'numeric' })` of `reopens_at` (2026-12-01T06:00:00Z -> "December 1"). An unknown period, or a month with an unparseable date, falls back to the day copy (the gate never sends either). No badge: John's wording names none, and adding one would be unrequested copy (pattern:90); same frame, close button, Escape, Keep browsing and tokens. No stat tiles, no IP line, no email/mailto/link.
- **D7 -- tests.** One new file; the two existing gate tests stay unedited (5 files, under the waived cap of 6).
- **D8 -- sequential, not parallel.** The budget RPC is awaited before the key/row lookups rather than raced with them: one extra round trip per gated call, simplest to read and to test. Running it concurrently with the key lookup is the follow-up if edge latency matters.

## Alternatives rejected

- A new one-row `platform_budget` table: a second singleton beside one that fits.
- A running spend counter: drifts the moment any write path misses an increment (the HAR-33 rule: spend is computed, never stored).
- Rolling 24 h / 7 d / 30 d windows: John ruled calendar periods (87c74e79).
- Exempting `MCP_API_KEY` or John's address: contradicts 6c6c7725 / d2aaa881.
- Caching the status at the edge: edge middleware has no shared memory across isolates; a per-isolate cache would refuse inconsistently.

```sql
-- AGT-772 up: platform budget (additive only)
alter table public.runner_settings
  add column if not exists platform_budget_day_usd numeric not null default 10,
  add column if not exists platform_budget_week_usd numeric not null default 25,
  add column if not exists platform_budget_month_usd numeric not null default 35;

do $$ begin
  if not exists (select 1 from pg_constraint where conname = 'ck_runner_settings_platform_budget') then
    alter table public.runner_settings add constraint ck_runner_settings_platform_budget
      check (platform_budget_day_usd > 0 and platform_budget_week_usd > 0 and platform_budget_month_usd > 0);
  end if;
end $$;

create index if not exists ai_activity_created_at_idx on public.ai_activity_log (created_at);

create or replace function public.platform_budget_status()
returns table(
  day_spent_usd numeric, week_spent_usd numeric, month_spent_usd numeric,
  day_limit_usd numeric, week_limit_usd numeric, month_limit_usd numeric,
  day_reopens_at timestamptz, week_reopens_at timestamptz, month_reopens_at timestamptz)
language sql stable
set search_path = public
as $function$
  with b as (
    select date_trunc('day',   now() at time zone 'America/Chicago') as d0,
           date_trunc('week',  now() at time zone 'America/Chicago') as w0,
           date_trunc('month', now() at time zone 'America/Chicago') as m0
  ), r as (
    select l.created_at at time zone 'America/Chicago' as lt,
           (coalesce(l.input_tokens,0)/1000.0) * p.input_per_1k
         + (coalesce(l.cache_creation_input_tokens,0)/1000.0) * p.input_per_1k * 1.25
         + (coalesce(l.cache_read_input_tokens,0)/1000.0) * p.input_per_1k * 0.10
         + (coalesce(l.output_tokens,0)/1000.0) * p.output_per_1k as c
    from public.ai_activity_log l
    join public.model_pricing p on p.model = l.model
    cross join b
    where l.created_at >= (least(b.w0, b.m0) at time zone 'America/Chicago')
  )
  select
    coalesce((select sum(c) from r, b where r.lt >= b.d0), 0),
    coalesce((select sum(c) from r, b where r.lt >= b.w0), 0),
    coalesce((select sum(c) from r, b where r.lt >= b.m0), 0),
    s.platform_budget_day_usd, s.platform_budget_week_usd, s.platform_budget_month_usd,
    (b.d0 + interval '1 day')   at time zone 'America/Chicago',
    (b.w0 + interval '7 days')  at time zone 'America/Chicago',
    (b.m0 + interval '1 month') at time zone 'America/Chicago'
  from public.runner_settings s cross join b
  where s.id = 1;
$function$;

revoke execute on function public.platform_budget_status() from public, anon, authenticated;
grant execute on function public.platform_budget_status() to service_role;
```

```js
// FEATURE: AGT-772 -- one platform-wide budget over EVERY priced ai_activity_log row, by calendar
// day / week / month in America/Chicago (runner_settings.platform_budget_*_usd). Address and key
// ceilings stay lifetime; this total is what a caller arriving from new addresses cannot reset.
// One RPC per gated request; any infra error skips the check (one console.error line) and the rest
// of the gate runs exactly as before.
const BUDGET_PERIODS = ['day', 'week', 'month'];

async function fetchBudget(url, key) {
  const res = await fetch(`${url}/rest/v1/rpc/platform_budget_status`, {
    method: 'POST',
    headers: { ...supabaseAuth(key), 'Content-Type': 'application/json' },
    body: '{}',
    signal: timeoutSignal(SUPABASE_TIMEOUT_MS),
  });
  if (!res.ok) throw new Error(`status ${res.status}`);
  const body = await res.json();
  const row = Array.isArray(body) ? body[0] : body;
  if (!row || typeof row !== 'object') throw new Error('empty budget');
  return row;
}

// The spent period that reopens LAST, or null. Throws on any missing or non-numeric field.
function spentPeriod(row) {
  let hit = null;
  for (const p of BUDGET_PERIODS) {
    const spent = Number(row[`${p}_spent_usd`]);
    const limit = Number(row[`${p}_limit_usd`]);
    const at = Date.parse(row[`${p}_reopens_at`]);
    if (!Number.isFinite(spent) || !Number.isFinite(limit) || !Number.isFinite(at)) throw new Error(`budget field ${p}`);
    if (spent >= limit && (!hit || at > hit.at)) hit = { period: p, at };
  }
  return hit;
}

function refuseBudget(period, at) {
  const body = { deepbench_gate: true, reason: 'budget', period, reopens_at: new Date(at).toISOString() };
  return new Response(JSON.stringify(body), {
    status: 403,
    headers: { 'Content-Type': 'application/json', ...CORS_HEADERS },
  });
}
```
