## 4. Design choices

- Two files, three tasks, caps 40/41. No split, no cap case.
- New test file, not a fourth arm in `agt-567-meter-stop-blocks.test.mjs`: that guard is built around one shared literal (the 2026-10-17 paragraph) and this routine runs a different one. A separate file leaves a shipped guard untouched.
- The test pins its own literal by sha256, so a Builder typo in the 529-byte line fails the `literal` arm instead of silently agreeing with a mistyped block.
- No version header on the runbook: `agt-452-victoria-rows.test.mjs` arm C asserts line 1 is the `v7.0.848` stamp. The four block edits since (`v7.0.864` to `v7.0.937`) added none either.
- One sentence replaced outside the block (line 76): it says the live prompt equals the block, "checked 2026-10-02, exit 0". That has been false since 2026-10-14. The same sentence in `personal-agent.md` belongs to another routine and stays.
- The `Redesign:` line is there because `scripts/redesign-pickup.js --open` refuses a kickoff without one. It claims no refusal: the ticket has 0 skips, 0 gated cards and 0 refusal attempts, and the line says exactly that. The `needs-desktop` flag is mis-set, the same finding `AGT-567` recorded as its D1.
- Model: the live `orchestrator` row of `runner_model_lanes` reads `claude-opus-5`.
