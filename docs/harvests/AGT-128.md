## 3. Why a conditional does not fire, and what carries the real case

A conditional STOP LINE sentence is an instruction to the close-out, not a declaration about the ship. Evaluating it would need the run's outcome, which the reader does not have and must not guess (`pattern:3`). The branch that actually happened already has a channel: trigger 4, `--remainder=`, which the operator passes and which the runbook documents. So the rule delegates rather than guesses, and `Close as: partial` stays the unconditional form a design uses when it means it.

Marker set kept to `if` / `unless` / `in case` deliberately. `when` was considered and dropped: it narrates as often as it conditions ("report the counts when the suite finishes"), and a false skip is a `delivered` on a real remainder — the expensive direction.
