## Why "no ticket id in the sentence" still fires

The live STOP LINE corpus says partial three ways: own id (`Close SES-423 \`partial\``,
`SES-422 stays \`partial\``), no id (`the ticket stays \`partial\`` — AGT-70 ×4, AGT-79 ×5), and
another ticket's id (AGT-109 → AGT-88, the only instance). A rule that fires only on the own id
would silently settle nine shipped-partial slices `delivered` in check 12's census, and fixture
`tests/fixtures/agt-79/board.json:22` (*"Close the ticket `partial`."*, ticket QA-79-04) would stop
filing `remainder-stranded`, turning `agt-79-ticket-owner` red. A sentence naming a ticket is about
that ticket; a sentence naming none is about this one. That is the whole rule. `Close as: partial`
is accepted as the structured form the ticket asks for; no kickoff on disk uses it yet and the
kickoff template is not changed here (pattern:65).
