## 3. Why this shape, and what it is not

- **No new route.** ARCHITECTURE.md line 902 is explicit that a new capability is "Skill Profile rows + `capability_skill_profiles` + `agent_capability_assignments`", and warns against treating `db-assembly.js`/`ai-enrichment.js` as "a precedent to copy" rather than code to import. So the build imports both and seeds rows; it writes no new assembly code.
- **No behavior Skill Profile.** `db-assembly.js` slugs a section by its skill type (`:414`), so a second `behavior` profile would collide with `prompt-reflect`'s section in `renderedMap`. Passing `enrichment_capability_slug: 'dan-ai-enrichment'` (`db-assembly.js:704-719`) brings REFLECT in the same way `api/plan.js:159` and `api/capabilities/execute.js:1849` already do.
- **No Intent or Format profile.** The GET returns an assembled prompt to Brent's out-of-repo browser runner; nothing here sends it to a model, so there is no output contract to declare. `assemblePrompt()` drops intent profiles when `intent_slug` is null (`:684-696`) and `format_contract` falls back to the default.
- **Retrieval is not re-implemented.** `db-assembly.js:214-236` → `ai-enrichment.js:345-352` calls `queryRAG({queryText, agentId, matchCount, scope})` — the identical function `lib/agent-run.js:64` calls, with `match_count` 10 restored from `traits`.

## 4. Alternatives rejected

- **Migrate both legs and delete `assembleContext()` this ship.** Files would be exactly 3 (`web-memory.js`, `brief.js`, `agent-run.js`), but the data is not: five analysis agents hold no capability rows, so it would need five capabilities seeded and a live A/B of the briefing output. Well past 4 tasks, and it puts the live briefing path at risk in the same ship that moves Brent.
- **Swap in `assemblePrompt()` with no seed** (agent-only assembly, no `capability_slug`). It runs, but with zero Skill Profiles there is no Knowledge section, so Brent silently loses his portal-history RAG. A regression dressed as a migration.
- **Keep `queryText` as a second RAG input.** `ai-enrichment.js:347` passes `task_context.goal` as the query; adding a parallel input would mean a conditional in the enricher — the exact thing §19's Founding Principle bans.

## 5. Residue this ship does NOT close

`api/brief.js:111` still calls `assembleContext()` for chloe/mike/bob/robyn/christy, so `lib/agent-run.js` keeps the function and all three `FALLBACK_*` blocks. **AGT-017 is not closeable by this ship** and must stay open at "Brent migrated, brief.js leg remaining" — its own second sentence ("retire it") is unsatisfied, and refiling that sentence under a new id would be the defect pattern:95 names. The remaining leg needs its own cycle: five capabilities seeded, `brief.js` rewired, then the function and its fallbacks deleted.
