## 3. Alternatives considered and not taken

- **Verifier auto-discovers a cycle-keyed file in `os.tmpdir()` by `--cycle-id`** (no flag, no runbook edit): rejected — AGT-170's first fence is "a baseline that was HANDED to it"; an implicit path is a convention nobody can read off the row.
- **Pre-build writes its block INTO the kickoff** (no flag, `readKickoffBaseline` already wired): rejected — the SES-376 cap grades bytes mechanically and this kickoff's predecessor shipped at 8,187 of 8,192; a 61-name block appended after the fact would block the delivery.
- **A hand-written `before:` field on `NOTES` rendered as a card fence**: rejected — rewrites the card's one doctrine (every fence is the runbook's bytes) and `ses-377` arm D would need weakening.
- **`agent-prompt.js --agent=builder` running the measurement while assembling**: rejected — a prompt assembler spawning a minute-long test run is a side effect in the wrong layer.
- **Running `run-all.js --only-from=` instead of `baseline-red-set.js`**: the ticket names `baseline-red-set.js`, and its block is the shape every kickoff already carries; the `[FAIL]` lines are appended so one file serves both readers.
