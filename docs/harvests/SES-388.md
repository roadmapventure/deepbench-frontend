## Alternatives weighed

- **A. Headers mode on GitHub Actions (chosen).** Two one-token calls, no CLI, no login, nothing to refresh; the token is the one John already minted.
- **B. Copy John's interactive credentials (refresh token) into a secret.** Would work today; rotates on refresh and puts the whole account's session in a secret. Rejected.
- **C. An always-on box logged in interactively.** Works; a machine to manage. Held as the fallback if Anthropic ever drops the headers.
- **D. The harness rate-limit status as a hard wall inside each cycle.** Still worth doing (no percentages, but the account's own truth); left in SES-388's text as a follow-on, not built here.
