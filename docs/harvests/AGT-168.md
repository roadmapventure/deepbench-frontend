The phone goes with the address: the ruling said "or say why not", and there is no reason to keep it. - **`%USERPROFILE%`** for the two home-directory paths — the form earlier slices used; the sentences stay true. Whether `docs/vision/` has a governed reviewer was not established in pass one; the ruling ordered the edit, and it changes no claim.
- **One placeholder, one transform**: `<REDACTED:VERCEL_AUTOMATION_BYPASS_SECRET>`, skipped by both detectors by construction. Line counts do not move (45 insertions, 45 deletions).
- **The purge script derives the value at run time and never holds it.** It asserts exactly 1 distinct value and exactly 44 files before writing anything, and prints the files still holding the value afterwards. It lives outside the repo and is not committed (a tracked one-off would be file 49).
- **Two commits, one push.** Commit 1 = parts A–C (4 files); commit 2 = the purge (44 files + one assert line in the test). The ruling kept part E out because a revert of the purge re-adds the value and the gate refuses it; the same reasoning applies to part A, which changes the detector every audit and CI run reads. Split this way, commit 1 can be reverted cleanly and the purge never has to be. The test file is touched in both commits so the suite is green at each commit (measured at both).
