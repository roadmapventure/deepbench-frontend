## The design, and why this one

The refusal exists because a red graded against a measurement nobody took gets mis-charged. It is kept whole. What changes is that the instrument stops being silent about the one thing it can know for certain before the build: a test file the kickoff declares that its own tree does not hold. It writes `- <path> — ABSENT pre-build`. That is a measurement (a file-system fact about the measured tree), not a claim by the kickoff.

- The line deliberately does not match `PER_TEST_LINE`, so the name is never in `measured`. Coverage skips it; `regressionDelta()` is not edited, so a red in that test lands in the existing `neverMeasured` bucket: status stays the suite's own exit code, the ship blocks, the red is not charged. The exemption therefore cannot turn any red green.
- Any graded name that is neither measured nor marked absent still refuses exactly as today. That covers the case AGT-457 was built for (a pre-existing test the baseline skipped) and also an existing test that only became related because the build edited it.

Alternatives weighed and not taken:
1. AGT-529's variant, exempt what `--changed-files` reports ADDED. Since SES-336 the Builder owns the push, so at 7a origin/dev is HEAD and a git-derived changed list is empty (environment fact, cycle 601227fb). The fact would have to be passed in by the caller, which is the caller vouching for itself.
2. Count the absent name as `measured`, so a red in it is charged as newly red. Defensible (the build created the file, so its red is the build's), but it edits the one red-to-green function for a third time and changes who is charged. Left as is; the ticket's own text asks for the never-measured bucket.
3. A kickoff keyword ("NEW") read by the verifier. That is the Designer's word, not a measurement, and costs kickoff bytes.
4. A git check at 7a that the name is absent at the baseline header's tree sha. Stronger, but it is AGT-541's fence and CI clones at depth 1. Not built.

## What this does not do (named in the STOP LINE)

- A new test the kickoff does not name is still refused. The remedy is to name it in the kickoff.
- `readKickoffBaseline()` and step 6's `kickoff-baseline-narrower` check are unchanged; both ends there are pre-build.
- The refusal's printed remedy still says "measure over the SAME set ... hand that one file to both ends" without saying which tree. Cut for the byte cap; AGT-541's text already owns that sentence.
- The verdict row does not name the exempted test (a `gateDetail` note was prototyped and cut for the cap). The baseline file names it.
- The absent line is honoured from any baseline file `readRegressionBaseline()` reads, with no instrument condition (prototyped, cut for the cap). A hand-written line could claim absence, exactly as a hand-written `— green` line can claim a measurement today.
- The runbook is not edited: no command changes.
- This delivery's own 7a will refuse once more: step 7 runs the pre-fix instrument, so its file has no ABSENT line.
