## Decisions (mine, reversible; JOHN-0925-DESIGNER-DECIDES)

- **D1 -- how the route trusts the end-user header.** The route cannot see the gate's verdict, and a client header alone must never be trusted. The gate, only after a KNOWN key and a valid pair, forwards `x-deepbench-end-user-proof` = hex HMAC-SHA256 keyed by `SUPABASE_SERVICE_KEY` over `agt771:<ip>`, using the request-header override. `lib/request-context.js` uses the end-user address for `caller_ip` only when the proof timing-safe-equals its own HMAC. A forged, replayed-for-another-address, or missing proof logs the server's address as today. Standard practice: a signed internal header between an edge proxy and its origin. Why HMAC and not just "strip the header on every other path": stripping depends entirely on the override being honoured on every pass path; the HMAC fails closed (no proof arrives -> server address, never a spoofed one). No new env var: both runtimes already hold `SUPABASE_SERVICE_KEY`. Undo: git revert.
- **D2 -- server address column.** New `ai_activity_log.server_ip text`, nullable, written only when the end-user address replaced `caller_ip` (spread, never `?? null`, so every other insert body is byte-identical and a deploy ahead of the column cannot 400 the web path -- the AGT-341 rule). Undo: the column is unread; leave it, or drop it attended.
- **D3 -- IPv6 at the edge.** Dependency-free `isIpLiteral()` (STUB code). Zone ids (`%eth0`) are refused: they are link-local and never a person's public address. No normalisation beyond trim: the gate and the log use the same trimmed string, and the HMAC binds that exact string, so `get_ip_stats` sums the same value the gate read.
- **D4 -- tests.** `tests/regression/agt-297-mcp-caller-gate.test.mjs` stays unedited and must stay green (its keyless, unknown-key, keyed-no-header arms are exactly the "behaves as before" half of Done). The new arms go in ONE new file. 5 files = the waived cap.
- **D5 -- edge semantics.** A key at `unlimited` still meters the person (the ticket's "whichever is reached first"; unlimited means the key's own budget never binds). Country without an ip, an empty header, or a non-two-letter country is `end_user_invalid`. Country is case-insensitive and stored upper-case. Order: key `site_blocked`, key `site_cap` (unless unlimited), then the pair's validation, then the address rules -- the site key's budget is checked first (John's scope item 6).

## Alternatives rejected

- Trust the header whenever the request carries a key on an MCP path (AGT-770 already 401s an unknown key): breaks on the failed-lookup path, which falls to the IP gate -- a wrong key plus a forged address would then log under the forged address.
- Re-validate the key in the route: needs a DB round trip inside synchronous `derive()`.
- Put the server address in `call_facts`: anon-readable (LOG-124) and §19k reserves it for the signature.
- Two test files (new + agt-297 re-pin): 6 files, a cap case for no gain.

## STUB code (build input, verbatim)

`middleware.js`, after `fetchCallerGate()`:
```js
const END_USER_IP_HEADER = 'x-deepbench-end-user-ip';
const END_USER_COUNTRY_HEADER = 'x-deepbench-end-user-country';
const ALLOWED_COUNTRIES = new Set(['US', 'CA']);
const V4 = /^(25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)(\.(25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)){3}$/;
const HEX = /^[0-9A-Fa-f]{1,4}$/;
function isIpLiteral(s) {
  if (typeof s !== 'string' || !s || s.length > 45) return false;
  if (V4.test(s)) return true;
  if (!s.includes(':')) return false;
  let body = s;
  const last = s.lastIndexOf(':');
  if (s.slice(last + 1).includes('.')) {
    if (!V4.test(s.slice(last + 1))) return false;
    body = s.slice(0, last + 1) + '0:0';
  }
  const halves = body.split('::');
  if (halves.length > 2) return false;
  const all = halves.flatMap(h => (h === '' ? [] : h.split(':')));
  if (!all.every(g => HEX.test(g))) return false;
  return halves.length === 2 ? all.length <= 7 : all.length === 8;
}
async function endUserProof(secret, ip) {
  const enc = new TextEncoder();
  const k = await crypto.subtle.importKey('raw', enc.encode(secret), { name: 'HMAC', hash: 'SHA-256' }, false, ['sign']);
  const sig = await crypto.subtle.sign('HMAC', k, enc.encode('agt771:' + ip));
  return Array.from(new Uint8Array(sig), b => b.toString(16).padStart(2, '0')).join('');
}
function passWithProof(request, proof) {
  const fwd = new Headers(request.headers);
  fwd.set('x-deepbench-end-user-proof', proof);
  const headers = new Headers({ 'x-middleware-next': '1' });
  const keys = [];
  for (const [k, v] of fwd) { headers.set('x-middleware-request-' + k, v); keys.push(k); }
  headers.set('x-middleware-override-headers', keys.join(','));
  return new Response(null, { headers });
}
```

export function endUserProofHex(secret, ip) {
  return createHmac('sha256', secret).update('agt771:' + ip).digest('hex');
}
function deriveEndUserIp(headers) {
  const raw = headers['x-deepbench-end-user-ip'], proof = headers['x-deepbench-end-user-proof'];
  const secret = process.env.SUPABASE_SERVICE_KEY;
  if (!raw || !proof || !secret) return null;
  const ip = String(raw).trim();
  const want = Buffer.from(endUserProofHex(secret, ip)), got = Buffer.from(String(proof));
  return ip && want.length === got.length && timingSafeEqual(want, got) ? ip : null;
}
