## The finding that changed the design

The ticket's remedy (2) says to "widen the identifier row to accept mixed-case identifiers." Measured:
the live value is itself 32 mixed-case alphanumerics, so `/^[A-Za-z][A-Za-z0-9_]+$/` matches **42 of
42** live-value hits. Read literally, the ticket's own fix is the blanket mute its own item (3) forbids
— it deletes the detector. `loadBypassSecret` and the live value are indistinguishable by value shape;
they differ only in syntactic role (one is a callee, one is an operand). So the mixed-case class is
discriminated in the CAPTURE, with `(?!\s*\()` on row 2, not in the allowlist.

## Alternatives considered and rejected

1. **Exclude `,;)` from row 1's character class** (the ticket's option 1b, as `secret_assignment`
   already does). Works for the comma class, but it truncates the reported text's fidelity and leaves
   every other trailing punctuation form (`.`, `]`, `}`) to recur. Stripping before the allowlist test
   covers the whole class in one place and keeps the reported line intact. Chosen.
2. **`/^[a-z][A-Za-z0-9]*$/` — lowercase-first camelCase.** Would allowlist `loadBypassSecret` and, if
   the live value happens to begin with an uppercase letter, spare the 42. That is a coin flip on a
   random secret, not a rule. Rejected.
3. **A length ceiling on the identifier row** (e.g. allowlist mixed-case under 20 chars). Rejected:
   it encodes today's secret length as a security boundary; a 16-char rotation defeats it silently.
4. **Fix the count in the card.** Explicitly forbidden by the ticket and by the AGT-86 slice 5
   detector-table decision — the card is an output of the scan.

## The fix, prototyped and measured before it was written into the kickoff

Allowlist half (strip trailing `[,;.:)\]}]+` before the rows run, plus a `^\$VAR` reference row):
48 → **43**, suppressing exactly the five punctuation/`$VAR` lines. Capture half (row 2's `(?!\s*\()`):
43 → **42**. Both together: **42 live-value lines in 42 files reported, 0 false positives.**

The allowlist is shared by every detector, so its change was measured across all of them:
`secret_assignment` 46 → 46, `personal_path` 2 → 2, `personal_email` 1 → 1, `vercel_bypass` 48 → 43.
The only newly suppressed hits anywhere on the tree are the five named lines. Nothing else moves.
