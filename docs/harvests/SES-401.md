## 2. The finding the ticket did not know about: `SES-386`'s handler is dead code

`ses-281` lines 357-384 (`SES-386`, v7.0.487) exist to turn an all-claimed lane into a `notRun()`.
The discrimination is `live.has(String(i.claimed_by))`, where `live` is built from
`runner_cycles.id`. Measured:

- `information_schema.columns`: `backlog_items.claimed_by` is **`text`**; `runner_cycles.id` is
  **`uuid`**, and `runner_cycles` has **no `session_name` column at all** (its text identity is
  `stamp`).
- Live values of `claimed_by`: `design-app-shell-0915`, `run-project:moat-support:1`,
  `design-app-shell-0915`.
- Live counts: **3 claimed tickets, 2 live cycles, 0 held by a live cycle.**

A text session label is tested for membership of a set of uuids, so the branch can never be taken.
It has never fired and never could. The join that does work is on the cycle's own
`item_id`: cycle `0535feab-37fc-41ee-afb4-3d8ef479db93` (`ended_at IS NULL`) carries
`item_id = 'SES-401'`, and `SES-401` is claimed. That correction is task 1 of the kickoff, and the
fixture proving it is the wrong-key control in task 4.

This matters beyond tidiness: `SES-386` was shipped believing the all-claimed case was handled, so
the ticket's "all-claimed" half was never actually closed.

## 3. Why the fix is one shared module and not five edits

Three of the five carry near-identical prose ("the selfbuild lane came back empty — either …"),
which is the signature of copy-propagation between test files. `_lib/self-run.js` records the same
mechanism directly (`SES-207`: the ticket named five sites, the live count was seven, because two
later tests copied the string from a neighbour). Correcting N sites by hand does not stop the next
author copying from whichever file they open. One `classifyBoard()` that every guard calls is the
shape that holds, and it is pure, so the permanent guard can drive the real function over fixtures
rather than restating the rule (`SES-45`).

## 4. Alternatives considered and rejected

- **Blanket `notRun()` on any empty lane.** Cheapest, and wrong: it turns a board where nothing is
  executing — or where the project fence has broken — from a red into a silent green. It would have
  passed the very SES-340 regression the fence exists to catch. Rejected; this is what the
  four-state split and the `starved` case exist to prevent, and the QA's starved clause is what
  proves the builder did not quietly take this path anyway.
- **Change `scripts/build-briefing.mjs:541` so the builder tolerates an empty pick list.** Rejected:
  the `die()` is correct and says so in its own words — "a genuinely empty pick list is the PARKED
  state (§2(d)), not a page." The page should refuse to publish. It is `SES-135` that must stop
  reading a correct refusal as a broken builder, so the change belongs in the test.
- **Gate the five on an environment flag (`ALLOW_EMPTY_QUEUE=1`).** Rejected: the condition is a
  fact about the board, discoverable from the board. A flag makes it a fact about who invoked the
  suite, and an unattended cycle would have to know to set it — which is the thing that fails.
- **Delete or `.skip` the offending clauses.** Forbidden outright by `STANDARDS.md` §4 clause 1.

## 5. Declared residue

- **A lane emptied solely by an unresolved `M_ design gate%`** classifies `starved` and still
  FAILS. Telling it apart would mean re-deriving the gate predicate in JS, which is the `SES-45`
  second-implementation violation the suite keeps catching. Named in the kickoff §4 as a boundary
  rather than discovered later. If it turns out to fire in practice, it is a fresh ticket, not a
  quiet widening of `classifyBoard()`.
- **`drained` is judged from the executing project's open/partial queued count**, not from a
  re-derivation of the picker. Measured today: `moat-support` (executing) holds 8 such tickets while
  the lane serves 4 — so the two numbers legitimately differ, and `drained` deliberately means
  "zero left," never "fewer than the lane shows."
- The other 223 files in `tests/regression/` were not surveyed for the same pattern. The three
  shared phrasings were found by grepping `came back empty`; a wider sweep for board-shape
  assumptions is a separate item.
