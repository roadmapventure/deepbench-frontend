## Recorded Designer decisions (reversible; written into the kickoff; I made these calls myself and did not route them to John)
1. Name/signature: public.rule_capped_ticket(text, text, text, text[], uuid, text) returning jsonb. It is a new name, so no overload exists, and the GATE asserts there is exactly 1.
2. SECURITY INVOKER plus REVOKE from PUBLIC/anon/authenticated. The default ACL grants EXECUTE to PUBLIC (environment fact SES-384). apply_design_rulings is SECURITY DEFINER and live-granted to anon and authenticated, which is a separate finding (below).
3. Parts must already be filed, open, and in the parent's epic. The function never INSERTs a ticket because filing is the Development Manager's intake path (check-findings-intake FILING_ALLOWLIST). Whoever calls it in AGT-448 files them.
4. An unscored parent (need_score < 3) is refused. Copying NULL would declare a drain whose every member the pick rejects, which is a silent dead drain.
5. Part 1 inherits the parent's own blocked_by. Parts 2..n chain. The parent gets blocked_by = the last part and status 'partial'. Without that, a partial parent is still pickable and would be built again in parallel with its parts. That would also deadlock if part 1 kept a blocked_by that points at the parent, as AGT-446->AGT-445 does today.
6. The drain scope is exactly the parts, not the parent, so the drain retires when the last part is done ("declares a drain over exactly the parts").
7. A waive records only the ticket-scope decision. The Designer stop (AGT-448) consumes it.
8. The order of the validations puts the shape checks before the parent lookup, so the live refusal arm stays meaningful whatever AGT-445's status is later.
