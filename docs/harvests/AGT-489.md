## §CALLS — the Designer's calls (JOHN-0925-DESIGNER-DECIDES, each reversible)

(a) **What "graded" means.** A grade STANDS when the ticket's NEWEST `requirement-check` decision (by `decided_at`, reversed or not) is unreversed AND the before-image taken under it carries today's `description`. This gives d.13 all three reopeners with no new column: a description change (the image differs), John asking (he reverses the newest grade — one `reverse_decision`), and AGT-493's rewrite (a description change). Taking "any unreversed grade" instead would make John's reversal meaningless against 19–22 standing rows per ticket. A charter change re-checks FIT only (d.13), and fit is already re-judged every run for an unplaced graded ticket, so it needs no mechanism. Rejected: a `graded_at`/`graded_by` column (d.36 says the date comes from the record; a column is a second copy).

(b) **"A ticket John named"** = `scope_origin = 'john-named'`. A `john:` need_source is John recording a NEED, not placing the ticket; d.25 says AGT-450 already homes those and d.12 says every source moves on the same terms. The ticket says "never moves a ticket John named into another project": a john-named row is refused any home at all (same-project moves are not a case today).

(c) **The home epic of a project with several.** AGT-480's `v_rc <> 1` makes two of three executing projects unreachable. The oldest epic (`created_at, id`) is the project's original list; the Victoria Fill epics of 2026-10-13 are John-named drains (`326f062f`, `7a7dcfbe`) and must not receive placements. One function, `placement_target()`, is the only place this rule lives.

(d) **Vocabulary.** `move` and `hold` are LIST-only, like `no-fit`: `VERDICTS` (the single-ticket door) stays `["pass","not-needed"]`, because the single door grades one ticket against one source and never meets an already-graded one it did not just grade. `apply_requirement_verdict()` nevertheless owns the `move` write, so the door token keeps naming the one function that sets it (AGT-480's design) and the lock and `scope_origin_door()` are untouched.

(e) **What is offered to the turn.** Ungraded tickets (grade + place in one `pass`), graded tickets scored 3+ (place with `move`, wait with `hold`, or `no-fit`), and any graded ticket a parent lifts (d.11). A graded ticket under 3 with no parent cannot move (d.3: only 3+ fill) and must not be re-graded, so putting it to her buys nothing; it returns when its grade reopens.

(f) **The parent rule is deterministic** (pattern:9/10): `parent_project_of_blockers()` names the project; the context carries it as `parent_home`, the validator refuses any other `home`, and `placement_target()` refuses it again at the write. A `hold`/`no-fit` on such a ticket is refused: d.11 says it "cannot be graded low and left behind".

(g) **The move's record** is a `runner_decisions` row of kind `placement` — a kind, never `requirement-check` (that would count as a grade in `countable_tickets_per_project()` P3 and in F1), with a full-row before-image so one `reverse_decision()` puts `epic_id` and `scope_origin` back together, as AGT-480's pass does.

Alternatives set aside: a separate `victoria_move_ticket()` function (would need a second token value and two trigger edits); accepting `pass` with an echoed score as "no re-grade" (the writer would still insert a grade row — the Done-when's "grades nothing already graded" is measured by that count); a time-based re-grade (d.13 forbids).

### (1) the three functions

```sql
create or replace function public.grade_standing()
returns table(backlog_id text, decision_id uuid, need_score smallint)
language sql stable
set search_path = public, pg_catalog
as $$
  -- AGT-489 (a): a grade STANDS while the ticket's NEWEST requirement-check decision is unreversed
  -- and the before-image taken under it carries today's description (d.13: a text change, John
  -- reversing the newest grade, or AGT-493's rewrite reopens it; nothing else does).
  select b.backlog_id::text, d.id, b.need_score
    from public.backlog_items b
    join lateral (
      select d.id, d.reversed_at
        from public.runner_decisions d
       where d.kind = 'requirement-check' and d.backlog_id = b.backlog_id
       order by d.decided_at desc
       limit 1
    ) d on true
   where b.status in ('open', 'partial')
     and d.reversed_at is null
     and exists (
       select 1 from public.runner_before_images i
        where i.decision_id = d.id
          and i.row_data ->> 'description' is not distinct from b.description)
$$;

create or replace function public.parent_project_of_blockers()
returns table(backlog_id text, project_slug text)
language sql stable
set search_path = public, pg_catalog
as $$
  -- AGT-489 (f), d.11: a ticket that an open/partial ticket of an executing project is blocked_by
  -- belongs in that project. The shape of effective_need_score() (AGT-483), which lifts its SCORE.
  select distinct on (b.backlog_id) b.backlog_id::text, pj.slug::text
    from public.backlog_items b
    join public.backlog_items w on w.blocked_by = b.id and w.status in ('open', 'partial')
    join public.epics e on e.id = w.epic_id
    join public.projects pj on pj.id = e.project_id and pj.status = 'executing'
   where b.status in ('open', 'partial')
   order by b.backlog_id, pj.priority nulls last, pj.slug
$$;

create or replace function public.placement_target(p_ticket uuid, p_home text)
returns uuid
language plpgsql stable
set search_path = public, pg_catalog
as $$
declare
  v_bid text; v_origin text; v_parent text; v_epic uuid;
begin
  select b.backlog_id, b.scope_origin into v_bid, v_origin
    from public.backlog_items b where b.id = p_ticket;
  if v_bid is null then
    raise exception 'AGT-489: no backlog_items row has id %', p_ticket using errcode = 'check_violation';
  end if;
  -- (b) d.10: she never moves a ticket John named into a different project.
  if coalesce(v_origin, '') = 'john-named' then
    raise exception 'AGT-489: % is a ticket John named; it is never moved', v_bid
      using errcode = 'check_violation';
  end if;
  -- (f) d.11: a blocker goes where its parent is, and nowhere else.
  select p.project_slug into v_parent from public.parent_project_of_blockers() p where p.backlog_id = v_bid;
  if v_parent is not null and v_parent <> coalesce(p_home, '') then
    raise exception 'AGT-489: % blocks a parent in project %; it moves there, not to %',
      v_bid, v_parent, coalesce(p_home, '(none)') using errcode = 'check_violation';
  end if;
  -- (c) d.10: never a paused project (only executing qualifies); the project's OLDEST epic is its list.
  select e.id into v_epic
    from public.epics e join public.projects pj on pj.id = e.project_id
   where pj.slug = p_home and pj.status = 'executing'
   order by e.created_at, e.id
   limit 1;
  if v_epic is null then
    raise exception 'AGT-309: home_project % is not an executing project with an epic',
      coalesce(p_home, '(none)') using errcode = 'check_violation';
  end if;
  return v_epic;
end
$$;

revoke all on function public.grade_standing() from PUBLIC, anon, authenticated;
grant execute on function public.grade_standing() to service_role;
revoke all on function public.parent_project_of_blockers() from PUBLIC, anon, authenticated;
grant execute on function public.parent_project_of_blockers() to service_role;
revoke all on function public.placement_target(uuid, text) from PUBLIC, anon, authenticated;
grant execute on function public.placement_target(uuid, text) to service_role;
```

## §RULES — `validateListVerdict()` V1–V7 (each refusal names the ticket, as the existing ones do)
