## Mechanism
- New `refuseKey(status, reason, stats)` beside `refuse()`: same CORS headers, no `ip` field. Keeps `refuse()` (IP path) byte-identical.
- `lookupFailed` flag distinguishes "lookup threw" (fall to IP gate, fail open on the key path as before) from "lookup answered no row" (401 unknown_key).
- Browser surfaces (src/lib/gate-intercept.js, src/components/AccessGateModal.jsx) never send the MCP key header, so the new reasons do not reach them; no UI change.
