## 3. Why the probe is a build task and not a design measurement

This container's outbound proxy refuses every careers host: `curl` returns
`CONNECT tunnel failed, response 403` for `www.amazon.jobs`, `jobs.apple.com` and
`www.metacareers.com`. A design that named a JSON shape on that basis would be asserting from
memory. `pg_net` egresses from Supabase's network, not this one, and it is the network the weekly
job will actually use — so the endpoint measurement belongs there, ahead of the data write, which is
why Task 1 probes and writes nothing. Jerry's own row history is the candidate evidence:
`amazon.jobs search.json is readable` (2026-09-23), `jobs.apple.com renders by JavaScript`,
`metacareers.com returned an error page to automated reads`, NVIDIA's `Workday JSON endpoint reads
with a session cookie`, Google's careers search read only through titles. On that reading Amazon is
the one GET+JSON candidate among the six, and the 2026-09-27 rows record even amazon.jobs refusing
the agent's own browser — which the probe settles either way.

## 4. Alternatives weighed

- **Widen `BOARDS` in `scripts/personal-agent.js` as well.** Rejected: two code paths would then
  compute the same careers-page fetch (pattern:14), and the weekly job is already the database's
  (the script's `--fetch-postings` predates it). The DB job is the one thing on a cron.
- **A per-company `CASE` in SQL, the shape the three ATS arms use.** Rejected: pattern:2/pattern:11
  — six company names in a migration means a migration per company forever. The `json_map` on the
  row makes the seventh company a data edit, and the SQL never learns a company name.
- **A generic HTML scraper for the JS-rendered sites.** Rejected as scope: pattern:65/66. `search_only`
  states the gap on the row today, which is what the ticket's second sentence asks for, and a
  renderer is its own ticket if John ever wants those five sites read.
- **Marking all 19 rows `search_only` and stopping.** Rejected: it satisfies the ticket's second
  half by giving up on its first. The probe costs one task and settles whether Amazon is readable.
