## Design notes (kickoff v7.0.791, 2026-10-05) — appended by The Designer

### Premise, measured

At `b5a1c754` `src/screens/TestAiScreen.jsx` renders "Talking to your agent", "Teaching your agent" and "Comparison test" and ends at the comparison `</ol>` (line 34): no tabs, no `useState`, no drawer. Alive.

### Why the shape is what it is (the pins)

Six tests pin these two files and all six are green on the unchanged tree (`scripts/baseline-red-set.js`: red set 0 of 6). The 3-file cap means none of them can be edited, so the design keeps every pin green by construction:

- agt-385 (b) counts `<Drawer title=` exactly 5 and `useState(null)` exactly 1 in ConnectAgentPopup.jsx, and requires `expectTitle}` < `disconnectTitle}` < `talkTitle}` < `testTitle}` < `quickAdd.fallback}` by first occurrence. So the three shared mounts MOVE into `FaqDrawers` (3 + 2 remaining = 5), `ToolTabs` is stateless (the state stays in `ConnectSteps`), and `FaqDrawers` is defined above `ConnectSteps`.
- agt-338 (c) requires `fill(tool.step2)` < `teamStep}` < `step3Heading === null`, i.e. `TalkBody` before `DisconnectBody`. The new functions go AFTER `DisconnectBody`, so nothing moves relative to that order.
- agt-385 (c) and agt-384 (f) pin TestAiScreen.jsx: the five-name import line byte-exact and `CONNECT_TOOLS` 0 times. So Test AI imports the two new names on a SECOND import line from the same module (valid ES, no lint config in the repo), and `FaqDrawers` takes a `toolId` and does the `CONNECT_TOOLS.find` itself so the page never names `CONNECT_TOOLS`. The orientation note expected the `CONNECT_TOOLS 0` arm to change; it does not have to, and not changing it is what keeps the file count at 3.
- agt-348 requires `<QuickAddLink href={tool.openLink.href}` before `<Step1List `: both stay inside `ConnectSteps`, untouched.

### Alternatives measured and dropped

- A new `src/components/ConnectFaq.jsx` holding `Drawer` and the bodies: moves `<details` out of ConnectAgentPopup.jsx (agt-385 pins it at 1) and needs a 4th file. Dropped.
- Editing agt-385 to accept a widened import line: a 4th file, and a second home for the same pin. Dropped.
- Copying the three drawer lines into TestAiScreen.jsx: two homes for one wording; the harvest says reuse, never copy. Dropped.

### Connect page identity proof

`ToolTabs` and `FaqDrawers` are pure moves of JSX; the one line that changes is the pill `onClick` (`setToolId(t.id)` → `onPick(t.id)`, the same setter passed as the prop). The kickoff's §6 asks the Builder to show, from `git diff origin/dev`, that every removed line of ConnectAgentPopup.jsx reappears verbatim as an added line except that one, which is the offline proof that `/bench/connect` renders the same bytes. A render-to-string comparison was not chosen: the drawers render only after a click, which server rendering cannot perform.
