## 7. The intake command, and the CHECK constraints it must satisfy

`scripts/audit-ledger.js` is the one intake (AGT-131). Its contract:
`--ingest=<json> --week=<YYYY-Www> [--found-by=<s>] [--type=<t>] (--cycle-id | --session-name) --apply`,
input shape `{week, found_by, findings:[…], carried:[…]}`. `toRow()` throws when neither the finding
nor the run supplies `finding_type`. Live constraints on `public.audit_findings`:
`finding_type ∈ {defect, gap, proposal, security}`; `kind ∈ {duplicate, contradiction, redundant,
stale-or-irrelevant, competing-purpose, other}` → a proposal takes `other`;
`locations` a JSON array of length ≥ 1; `confidence ∈ {high, medium, low}`;
`UNIQUE (fingerprint, iso_week)`; `found_by !~ ' \+ '`. Attribution is exactly one of `--cycle-id` /
`--session-name`, mirroring `runner_before_images.ck_before_image_attribution`; the routine has no
`runner_cycles` row, so it uses `--session-name=researcher-<week>`, the Auditor's pattern.
