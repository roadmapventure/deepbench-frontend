### 14.5 Designer's recorded calls (JOHN-0925-DESIGNER-DECIDES, reversible)

1. **A release-candidate oracle grades the rule, not the day.** It names every assignment holding a newer, undeprecated, same-family `claude-` model, and the NEWEST such model, derived from the live rows at run time; the frozen pair list is removed. What it does NOT do, stated plainly: it does not prove the runbook's SQL and the test's `releasePairs()` mirror agree — arm C grades the SQL text and the arm's own `notRun` already declares that PostgREST cannot execute the statement. The oracle is written differently from `releasePairs()` (a reduce-max inside `filter`, against a filter-then-sort-then-first) so that any change to the function under test breaks the equality, which the three mutation probes confirm.

The stronger control is also the simpler one.
