## Design decisions (mine, reversible — JOHN-0925-DESIGNER-DECIDES)

1. **Script flags, not a `curl` block.** `scripts/cycle-heartbeat.js` is already the REST door to `runner_cycles` (headers, `landed()`, exit contract, SES-176 import guard, injected `doFetch`); two flags reuse all of it and are testable without a network (pattern:14, 17). A prose `curl` block (6 files) would make every cycle hand-compose JSON with `<now>` placeholders and leave the `[]`-is-a-miss rule untested — the shape AGT-303 is already filing against. Reverse by replacing Task 1 with a fenced `curl` PATCH pair in R3.
2. **The two-reading rule lives in step 0b**, the only place a heartbeat/timeout rule exists, so a cycle meets it at the first wall it can hit; step 9's R3 points back to it rather than restating it (one home, pattern:93).
3. **`--close` mirrors the (6) statement's semantics**: the lease release is best-effort (`[]` = TTL-stolen, as the SQL's `lease_released_at NULL`), the cycle close is the fatal half; `ended_at=is.null` keeps SES-194's resume guard on the REST path.
4. **`--append-notes` reads then writes** (GET + PATCH) because PostgREST cannot express `notes = notes || …`; a closed row is appendable (runbook L4291).
