## Why the two halves are one slice, not two

Slice 4's Designer flagged it and the measurement confirms it: widening the constraint makes
`--promote --apply` file an ask that no surface renders — an open row with no reader. Rendering the
group without the widening leaves a table whose only promotion path is still refused. Each half alone
ships a half-mechanism; together they close the loop the ticket names.

## Why widening cannot break the briefing build

`scripts/lib/briefing-derive.mjs:283-290`, `unregisteredAskTargets()`, filters
`.filter(t => /^item-/.test(t))` before the orphan check. `scripts/build-briefing.mjs:329` reads every
`runner_card_asks.target_id`, and `:338-344` dies on an unregistered one. A `skill-edit` ask's
`target_id` is a 16-hex fingerprint (`c31d654e8558c2b5`), which fails the `/^item-/` test and is
dropped before the guard sees it. Confirmed by reading both files, not by pattern recall.

## Alternatives considered and rejected

- **Widen D1 only (1 file, 2 tasks).** Cheapest, but ships an ask nobody can see. Rejected: it
  creates the exact "open ask displayed nowhere" state slice 4 warned about.
- **Brief group only.** Renders the findings but leaves `--promote --apply` dead at 23514, so the
  watch still cannot become an ask. Rejected.
- **Add a repo migration file.** `supabase/migrations/` does not exist in this clone; DDL has been
  landing through `apply_migration`. Adding the directory would be a new convention this ticket did
  not ask for, and would spend the third file slot.
- **Widen to a broad `text` column / drop the CHECK.** Rejected: the QA's "not-a-kind is still
  refused" assertion exists precisely to prove the vocabulary is a vocabulary, not an absence.
- **Promote-path-as-discriminator.** `--promote --apply` was considered as the discriminating QA,
  but the promotion bar is 3 distinct cycles and the table holds 1 finding from 1 cycle, so
  `promotions.length` is 0 and the command exits 0 on the unchanged tree too. It discriminates
  nothing. The direct INSERT probe does.
