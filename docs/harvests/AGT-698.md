## 3. Design calls and what was rejected

**D1 -- CI publishes `skipped`, not a new word.** `skipped` is in runbook step 4a's third row ("anything else (`cancelled`, `skipped`, an empty array, no row) -> could not tell -- invoke nothing") and in `tests/regression/SES-255-ci-conclusion-reporting.js`'s `GITHUB_CONCLUSIONS` (which asserts every live row's conclusion is one of success/failure/cancelled/skipped). Measured: `select public.ci_conclusion_is_green('[{"conclusion":"success"},{"conclusion":"not-run"}]')` is false, and the same function gates `trg_anchor_green_from_ci`, so any non-success writes no green anchor. `scripts/heal-engine.js` reads only `failure`; `regradable_ships()` needs `success`; `rollback-on-red.js isRunGreen()` needs all success. So `skipped` needs zero reader edits. Rejected: a new value `not-run` -- more precise, but SES-255's live-row arm would go red on the first such row, forcing a fourth file and a repin for no reader that distinguishes the two. The `checks` job has no `needs`, so GitHub itself never concludes it `skipped`; the value is unambiguous on this table. Rejected: failing the step with a distinct code -- a GitHub job can only conclude success/failure/cancelled/skipped, and `failure` is the defect. Rejected: `continue-on-error` -- forbidden by ci.yml's own header and by three tests.

Consequence stated in the STOP LINE: on a not-run the job shows GREEN in the GitHub UI (the step exits 0); the honest grade is the row in `ci_run_conclusions`, which is what the runner reads. `dev` has no branch protection, so nothing merges on that green.

The mechanism: step output `regression=not-run` -> job output -> `report-conclusion` maps (success, not-run) to `skipped`. A `failure` from the tripwire or the scan in the same job still publishes `failure` (the mapping only fires on `success`).

Fail-closed inside the step: exit 2 with any `[FAIL] ` line in the log is NOT treated as not-run; it falls through to `ci-new-reds.js`, which passes 2 through and fails the step.

**D2 -- at 7a, not-run alone is verifier exit 2 (cannot-run), no row.** The verifier's own table: "1 is a judgement about the change, 2 is the absence of a judgement". Runbook step 7 (L3143-3146): "Anything else -- a block, an ineligible ticket, an exit 2 -- writes `delivered` exactly as before", so no runbook edit is needed and none is made (the runbook is 380,973 bytes against the 381,000 ceiling). `runner_verdicts` CHECKs admit only green/red/skipped per gate and `approve` only when all three are green, so a fourth stored value would need a migration; none is designed. When build or hygiene is NOT green beside a not-run suite, a real red is known: the verdict is a block and the regression column is written `skipped` (the ledger's existing "could not run" value).

`gradeDelivery()` returns the full grade plus `notRun` (not `{ notRun }` alone) on purpose: its second caller `scripts/regrade-current.js outcomeFor()` reads `gateResults` and maps a regression of `not-run` to `ungradable` through its existing final branches, with no edit to that file. Checked by reading outcomeFor: pair mode -> "the pair's regression gate is not-run and NOTHING is charged"; dev-head mode -> "regression is not-run ... UNGRADABLE". An ungradable inserts no verdict row.

**D3 -- only the regression gate is armed.** `gateStatus()` takes `notRunExit` and `fails`; `runGate()` passes them for `gate.key === "regression"` only. `npm run build` or the tripwire exiting 2 stays red. An exit 2 whose output names a failing test stays red. An exit 1 naming nothing stays red with `regressionDelta()`'s "named NO failing test ... fail closed" words (arm D asserts it).

**Not done (D4 in my notes, named in the STOP LINE):** `gradeDelivery()`'s `taken.ran ? ... : { status: "red", detail: taken.notRun }` -- a refused test slot is still red. It is a second could-not-run read as red, but its cause is AGT-299 (open) and the ticket's fix (b) names exit 2 only. Left as is, by pattern:65.

## 6. Reference test (the file that passed on the scratch copy)

The Builder words its own; this is the tested shape, for comparison only.

```js
// DeepBench v7.0.1103 | tests/regression/agt-698-not-run-is-not-red.test.mjs | AGT-698 -- a suite exit 2 naming no failing test is a run that did not happen: CI publishes it `skipped`, 7a exits 2 and records nothing; a real [FAIL] still reds both.
import assert from "assert";
import fs from "fs";
import os from "os";
import path from "path";
import { spawnSync } from "child_process";
import { fileURLToPath } from "url";
import { selfRun, notRun } from "./_lib/self-run.js";
import { gateStatus, gradeDelivery, regressionDelta, runGate, SUITE_NOT_RUN_EXIT } from "../../scripts/verifier.js";

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), "../..");
const CI_REL = ".github/workflows/ci.yml";
const VERIFIER_REL = "scripts/verifier.js";
const NOT_RUN_LINE = "  [NOT RUN] x.test.mjs -- transport: 1 incident(s); first: HTTP 500 57014";
const FAIL_LINE = "  [FAIL] a.test.mjs -- boom";

// The shipped lines between `# AGT-698 <tag> >>>` and `# AGT-698 <tag> <<<`, dedented.
export function marked(yaml, tag) {
  const lines = String(yaml).replace(/\r\n/g, "\n").split("\n");
  const a = lines.findIndex(l => l.trim() === `# AGT-698 ${tag} >>>`);
  const b = lines.findIndex(l => l.trim() === `# AGT-698 ${tag} <<<`);
  assert.ok(a !== -1 && b > a, `${CI_REL} lost its \`# AGT-698 ${tag}\` markers`);
  return lines.slice(a + 1, b).map(l => l.replace(/^ {10}/, "")).join("\n");
}

const bash = (script, env) => spawnSync("bash", ["-c", `set -euo pipefail\n${script}`],
  { encoding: "utf8", env: { PATH: process.env.PATH, ...env } });

function armA(yaml) {
  for (const clause of [
    "      regression: ${{ steps.regression.outputs.regression }}",
    "        id: regression",
    "          CHECKS_REGRESSION: ${{ needs.checks.outputs.regression }}",
    '            --arg checks "${CHECKS}" \\',
  ]) assert.ok(yaml.includes(`\n${clause}\n`), `${CI_REL} does not carry \`${clause.trim()}\``);
  assert.ok(!yaml.includes('--arg checks "${CHECKS_RESULT}"'),
    "the reporter still publishes needs.checks.result unread -- a not-run could only be success or failure");
  const src = fs.readFileSync(path.join(ROOT, VERIFIER_REL), "utf8");
  assert.ok(src.includes('error: "regression-not-run"'), "7a has no cannot-run exit for a suite that did not run");
  console.log("  [arm A] ok");
}

function armB(yaml, fx) {
  const log = path.join(fx, "head-run.txt");
  const out = path.join(fx, "github-output.txt");
  const step = `${marked(yaml, "not-run").split("/tmp/head-run.txt").join(log)}\nexit 7`;
  const go = (code, text) => {
    fs.writeFileSync(log, `${text}\n`);
    fs.writeFileSync(out, "");
    const r = bash(step, { HEAD_CODE: String(code), GITHUB_OUTPUT: out });
    return { code: r.status, stdout: r.stdout, output: fs.readFileSync(out, "utf8") };
  };
  const notRan = go(2, NOT_RUN_LINE);
  assert.strictEqual(notRan.code, 0, `exit 2 naming no failing test must end the step 0, got ${notRan.code}`);
  assert.strictEqual(notRan.output, "regression=not-run\n");
  assert.ok(notRan.stdout.includes("[NOT RUN] x.test.mjs"), "the NOT RUN line must be printed, not swallowed");
  const both = go(2, `${NOT_RUN_LINE}\n${FAIL_LINE}`);
  assert.strictEqual(both.code, 7, "exit 2 beside a [FAIL] line must fall through to the grader");
  assert.strictEqual(both.output, "");
  const red = go(1, FAIL_LINE);
  assert.strictEqual(red.code, 7, "a real [FAIL] (exit 1) must fall through to the grader");
  assert.strictEqual(red.output, "");
  // The suite's own could-not-run path, as the ticket reproduced it: a name it does not have.
  const real = spawnSync(process.execPath, ["tests/regression/run-all.js", "--only=agt-698-no-such.test.mjs"],
    { cwd: ROOT, encoding: "utf8" });
  assert.strictEqual(real.status, SUITE_NOT_RUN_EXIT, `run-all.js must exit 2 on a name it lacks, got ${real.status}`);
  assert.strictEqual(go(real.status, `${real.stdout}${real.stderr}`).code, 0);
  console.log("  [arm B] ok");
}

function armC(yaml) {
  const map = `${marked(yaml, "publish")}\nprintf %s "$CHECKS"`;
  const pub = (result, regression) => bash(map, { CHECKS_RESULT: result, CHECKS_REGRESSION: regression }).stdout;
  assert.strictEqual(pub("success", "not-run"), "skipped");
  assert.strictEqual(pub("failure", "not-run"), "failure");
  assert.strictEqual(pub("cancelled", "not-run"), "cancelled");
  assert.strictEqual(pub("success", ""), "success");
  console.log("  [arm C] ok");
}

function armD() {
  const armed = { ran: true, notRunExit: SUITE_NOT_RUN_EXIT };
  assert.strictEqual(gateStatus({ ...armed, exitCode: 2, fails: [] }), "not-run");
  assert.strictEqual(gateStatus({ ...armed, exitCode: 2, fails: ["a.test.mjs"] }), "red");
  assert.strictEqual(gateStatus({ ...armed, exitCode: 2, fails: null }), "red");
  assert.strictEqual(gateStatus({ ...armed, exitCode: 1, fails: [] }), "red");
  assert.strictEqual(gateStatus({ ...armed, exitCode: 0, fails: [] }), "green");
  assert.strictEqual(gateStatus({ ran: true, exitCode: 2 }), "red", "unarmed (build, hygiene): exit 2 stays red");
  const named = regressionDelta({ absolute: "red", baseline: [], post: [] });
  assert.strictEqual(named.status, "red");
  assert.ok(named.reason.includes("named NO failing test"), "an exit-1 run naming nothing keeps its fail-closed words");
  console.log("  [arm D] ok");
}

async function armE() {
  const say = (line, code) => `console.log(${JSON.stringify(line)}); process.exit(${code});`;
  const grade = scripts => gradeDelivery({
    repoRoot: ROOT, graded: null, baselineRead: {},
    slot: async (_env, fn) => ({ ran: true, value: await fn() }),
    run: (gate, root, env) => runGate({ ...gate, cmd: process.execPath, argv: ["-e", scripts[gate.key]] }, root, env),
  });
  const ok = say("ok", 0);
  const a = await grade({ build: ok, hygiene: ok, regression: say(NOT_RUN_LINE, 2) });
  assert.ok(a.notRun && a.notRun.includes("exit 2"), "a transport-only NOT RUN must come back as notRun, with its detail");
  assert.strictEqual(a.gateResults.regression, "not-run");
  const b = await grade({ build: ok, hygiene: ok, regression: say(FAIL_LINE, 1) });
  assert.strictEqual(b.notRun, null, "a real [FAIL] is never a not-run");
  assert.deepStrictEqual([b.gateResults.regression, b.verdict], ["red", "block"]);
  const c = await grade({ build: say("boom", 2), hygiene: ok, regression: say(NOT_RUN_LINE, 2) });
  assert.strictEqual(c.notRun, null, "a red build beside a not-run suite is still a block");
  assert.deepStrictEqual([c.gateResults.build, c.gateResults.regression, c.verdict], ["red", "skipped", "block"]);
  const d = await grade({ build: ok, hygiene: ok, regression: ok });
  assert.deepStrictEqual([d.notRun, d.verdict], [null, "approve"]);
  console.log("  [arm E] ok");
}

async function run() {
  const yaml = fs.readFileSync(path.join(ROOT, CI_REL), "utf8").replace(/\r\n/g, "\n");
  armA(yaml);
  armD();
  await armE();
  if (spawnSync("bash", ["-c", "exit 0"]).status !== 0) {
    notRun("arms B and C -- the shipped step and reporter lines executed in bash", "no bash on this machine");
    return ["A", "D", "E"];
  }
  const fx = fs.mkdtempSync(path.join(os.tmpdir(), "agt-698-"));
  try { armB(yaml, fx); armC(yaml); } finally { fs.rmSync(fx, { recursive: true, force: true }); }
  return ["A", "B", "C", "D", "E"];
}

selfRun(import.meta.url, run);
export default run;
```
