## The design, and why this shape

- **One migration, two decision handles.** The rule rows go under kind `rule` (the shape `b383cb00` and `b84e133d` used for MANAGER-DECIDES-BY-DEFAULT and MANAGER-AUTHORITY-MATRIX), with a `row_data NULL` image per INSERT so `reverse_decision()` deletes them; the Skill rows go under kind `agent-row` with full-row images (the shape of the 36 existing agent-row decisions, `f38d0291` the newest). Two handles because a reversal of the Skill wording should not have to delete the registry rows, and vice versa (pattern:19).
- **Where the Auditor's rulings live.** `au-knowledge-homes`, not `au-guardrails`: arm E of `agt-86g` pins the guardrail arrays byte-for-byte, and the rulings are knowledge (what John decided about the findings pipeline), not a new must. The Designer's ruling is a must/must_not because it changes what the Designer does with a question; the Researcher's is knowledge because the routine it describes is AGT-138's build and the pass still runs at step 4b today — a must_not "never run inside the build routine" would contradict the live runbook until then (pattern:89 — surface, never silently implement the wrong string).
- **Why `claude-md-hard-rules` and the matrix anchor.** The CHECK admits no new group; the three existing John-ruling rows use this group and this doc. The doc gains one pointer paragraph and no rendered blocks: John's ruling is that the rulings live in the database, and check 12 would rightly flag a restated statement as a second home (pattern:93). Check 10 only needs the anchor to resolve, and `#decision-authority-matrix` does.
- **Verbatim where it exists, honest absence where it does not.** Four of seven rows quote John from `runner_decisions 32091fdb` or the AGT-134/136/138 descriptions; three say "as recorded by session auditor-unblock-0924". Inventing quotation marks around a paraphrase would be a fabricated record (pattern:33, pattern:112).
- **The agent-row gate.** The CLI's `gated` is expected and is not a stop: its own line says it judges on `scope_origin` alone and that an unreversed decision naming the ticket and the change makes it build work. That decision exists (`32091fdb`). The Builder still owes the images — verdict `build` is never a licence to skip them (§19v).
- **The one-line fix to `agt-86g`.** Fixing now, not filing: AGT-137's ship left arm C red; this ticket's own guard is arm E of the same file, and a file red for another arm's reason would be read as this ticket's regression. One string in `ALL_ASSIGNMENTS`; the `JOBS` map is left alone (it drives arm C's per-capability checks and `audit-run-review`'s intent section is AGT-137's to pin).
