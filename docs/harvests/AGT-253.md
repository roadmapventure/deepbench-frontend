## Decisions

**D1 — no stamp rotation.** `agt-133:157` asserts the file starts with `<!-- DeepBench v7.0.658 |` and `ses-424c`'s `LATER_STAMP` asserts the same. AGT-245 slice 5 already edited this runbook without stamping (its own note sits in ses-413d's comment), so a stamp is not a mechanical requirement — only a convention those two tests would punish. Adding one costs 106 B this edit cannot afford and reddens two green tests. The record lives in the guard test and the kickoff.

**D2 — John's yes makes the build attended.** The ticket's last sentence asks that the charter's branch-off-main rule be honoured when the BUILD later runs. The charter, read live, says: *"Branch off MAIN, not dev… NOTHING is pushed to main without John's explicit go-ahead."* The runner pushes `HEAD:dev` and cannot push main. Alternatives considered: a second project flag (a knob for a rule the charter already carries — pattern:67); a verifier refusal (a new gate for a case the platform already has a word for); leaving it to a second cycle (a real safety hole, because John's yes is asynchronous and would arrive before that cycle). Taken: the yes branch writes `design_status = 'needs-desktop'`, which the blocked-prefix table already means "the remaining work is on a surface an unattended cycle may not touch." `kickoff_link` is kept, so the design is not lost. Scoped deliberately to today's single design-only project; a second one without that charter clause is its own ticket.
