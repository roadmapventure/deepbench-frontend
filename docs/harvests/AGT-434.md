## 3. The draft `d2c27da3` and its two corrections

The build on `origin/session/cycle-20261009-1150` (+704 lines across exactly Part 1's three files) is sound as a starting point. Its migration header, decision reasoning and gate say 48 and devmanager 5 — all become 49 and 6. Two corrections the ruling names:

PINNED WINS drops every loaded row whose slug is pinned and prepends one PIN ROW per distinct pinned slug — exactly once in both paths whether or not the links exist. The pinned row renders first among Knowledge, matching the `display_order 0` the links carry today, so the prompt's section order is unchanged for every pinned agent. An agent with no pin row gets the same array reference back, so susan's assembled prompt is byte-identical (QA 2: susan 0 → 0).

The draft's live arm C asserted `5b4f3dd2` reversed and "48 links gone after the reversal" — both replaced: links 0 (because T5 removed them), and `5b4f3dd2` status ≠ `reversed` (because the ticket must never reverse it).
