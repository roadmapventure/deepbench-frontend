## What I designed, and why this shape

- D1. The fence is one pure function, `baselineTreeFinding({ tree, gradedSha })`, called in 7a's `main()` after `baselineGate()` and before `gradeDelivery()`, so it refuses before any gate runs: exit 2, `kind: cannot-run`, no row. It is not inside `gradeDelivery()` because that function does not know the graded sha and its second caller, `scripts/regrade-current.js`, measures its own base tree at a sha `pickMode()` resolves as distinct from the ship. Putting it inside would have meant a new parameter and a second edited file for a lane that cannot hit the case.
- It reads HEAD itself (`gradedShaFor(repoRoot)`) before the gates. The SES-345 read at `:4820` stays where it is; I did not hoist it, because its comment ties it to the diff the gates ran against and moving it is a different ticket's decision.
- Only `readRegressionBaseline()` gains the `tree` key. A kickoff's own block cannot name the commit that contains it, so comparing its tree with HEAD can never match; I dropped that reader's edit, which also bought back bytes.
- D2. The second half ships in the same commit: `addedSinceBaseline()` asks git (`git ls-tree --name-only <tree>:tests/regression`) which related tests had no file at the baseline's tree, and adds them to `baselineRead.absent`, the list AGT-629 already exempts from the coverage refusal. Such a test then falls into `regressionDelta()`'s existing `neverMeasured` bucket; if it is red the suite's own exit code stands and the ship blocks. If git cannot answer (unknown sha, shallow clone) nothing is exempt and today's refusal stands. I staged the two together because the fence alone would close the only door the coverage refusal points an undeclared build-added test at today, a re-measure after the build.
- D3. No exemption for a delivery that commits nothing. Its baseline tree would equal HEAD and the fence would refuse an honest file. I measured 0 of 130 in history and the refusal is a cannot-run that costs no streak, so I left it out rather than add a rule keyed on the header's own "0 declared files" wording, which a self-measured file could also carry. If it ever bites, that is the exemption to add.
- D4. No runbook edit. `docs/runbooks/runner-cycle.md` is 380,973 bytes against the 381,000 ceiling, and a byte moved there drags the card and BYTES_AT_SHIP.
- D5. The ticket says land with or after AGT-529 and AGT-537. AGT-529 reads `removal proposed` in the snapshot (AGT-629 shipped its class at v7.0.991). AGT-537 is open and is about the byte cap at `--check-kickoff`; nothing here touches that clause, so I did not wait for it.
- The remedy at `:1056` gains "on the UNCHANGED tree (never the one being graded: AGT-541)". I kept it to an insertion so no test or doc that quotes the rest of the sentence moves.
