**Class argued:** P2 - Inventive — nobody ships it, it is not an expected surface, and a competitor cannot copy the record even if they copy the mechanism.

**Verdict:** UNIQUE. Competitors lack: staff, ledger, ladder.

**Size:** S (1 predicted cycle). **Skill set proven:** Agentic software engineering; CI/CD and release engineering; AI governance.

**Depends on (Moat Support):** SES-345.

## The demo an evaluator cannot reproduce elsewhere

Open the public record of the last shipped version and see which governance agent prioritized it, which designed it, which built it, which verified it, and what each step cost.
