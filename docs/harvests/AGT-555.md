## 2. What made the design cheap

`scripts/regrade-cohort.js:245` `readCohortVerdicts(base, key)` **is** the live four-column
predicate, already exported, already the function `freeze()` used to build the file. The board leg
therefore re-measures the predicate by *calling the existing one* rather than restating it
(pattern:14, pattern:17) — the one thing that must never be duplicated is the predicate itself.

Likewise `parseLog` / `ownCommitRange` / `cohortRow` are exported and pure, so a board row's
base/ship pair is derived by slice 1's own code and its refusals keep slice 1's own reasons
(`no-version`, `no-own-commit`, `interleaved: <shas>`). The ticket's *"do not loosen the AGT-245
refusal reasons"* is satisfied by construction, not by a promise.

Running that derivation over the 40 unanswered predicate rows: **7 resolve** — `AGT-432`,
`AGT-434`, `AGT-446`, `AGT-447`, `AGT-451`, `AGT-482`, `AGT-494` — and **33 refuse
`no-own-commit`**, because this clone holds **364 commits back to 2026-10-07** and their own commits
predate that floor.

## 3. Alternatives considered and dropped

- **A new `--board` / `--cohort-refresh` flag.** Dropped. Step 7a-ter runs `--next` and nothing
  else, so a flag fixes the script and leaves the *lane* still reporting DRAINED — which is the
  actual defect. Reaching the lane then costs `docs/runbooks/runner-cycle.md` and
  `docs/runbooks/cycle-card.md` as a 4th and 5th file.
- **Re-freezing the cohort file (a second frozen list).** Dropped. It reproduces the bug on a later
  date and contradicts pattern:145's inverse: the *cohort* was a fixed list by John's design, but
  the *lane's drained claim* must be live. A re-freeze also discards the 15 refusals' provenance.
- **Editing the runbook anyway.** Dropped on measurement, not preference. `runner-cycle.md` is
  380,920 B; three EQUALITY pins hold that number (`ses-413d-questions-scoreboard`:273
  `BYTES_AT_SHIP`, `agt-253-design-only-lane`:73, `agt-525-tail-push`:57 `RUNBOOK_BYTES`) and
  `agt-138-researcher-routine`:63 ratchets `bytes < 380980`; `docs/runbooks/cycle-card.md` line 1
  carries `sha256 1f6b2d7177cf761f` and `ses-377-cycle-card`:224-226 asserts it equals
  `runbookSha()` of the live runbook. A byte-neutral edit still re-renders the card, and the card's
  re-render also orphans the live `skill_profiles` Knowledge row whose
  `traits.source_sha256` pins it (`scripts/render-cycle-card.js`:248, :304), which needs
  `--sync-knowledge --repin` under `AGENT-ROW-AGREED-TICKET`. Five files and an agent-row write for
  one sentence. `AGT-423`, `AGT-424`, `AGT-457`, `AGT-475`, `AGT-532` each dropped the same edit on
  the same merits.
- **Keeping the kind string `cohort-drained`.** Dropped. Measured 1 tracked occurrence (the emitter
  itself); nothing reads it, and the rename is the whole point of the ticket.

**Why no cap case.** The fix lands in 3 files of 3 and 4 tasks of 4 *because* the runbook stays out,
and it stays out without anything becoming false: L4277's *"`--next` takes the frozen cohort's first
still-eligible row"* remains true (T2 leaves the file leg first and byte-identical) and becomes
*incomplete*, which is the standard `AGT-423` accepted — distinct from becoming false. Its
*"**3** = DRAINED"* line also stays true; DRAINED simply stops being a claim about a file. If a later
reader wants the clause written down, that is `AGT-288`'s one-governor work, not this ticket's.

## 4. Two findings to file — reported, not folded (pattern:96)

1. **`deps-changed` cannot be told apart from a clone that lacks the commits.**
   `scripts/regrade-delivered.js`'s `depsClean` is
   `d.status === 0 && !d.out` — a `git diff` that *fails* returns false, which the walk records as
   `deps-changed`. In this shallow clone that is exactly what happened to **6** in-file rows: their
   dependencies did not change, their commits are simply absent. The skip reason names a cause that
   was never measured (pattern:34 — render honest absence). Its own ticket: a failed diff is
   `pair-not-in-clone`, not `deps-changed`.
2. **The reachable board is a function of clone depth.** 33 of the 40 unanswered predicate rows
   refuse `no-own-commit` only because the cycle clone is 364 commits deep. The board leg reports
   that honestly rather than hiding it, but a deeper fetch at pick time would move the reachable
   count from 7 toward 40. That is an environment lever for the runner, not a code fix here.

Neither is `AGT-555`'s sentence, and neither blocks it.
