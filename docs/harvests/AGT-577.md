## Design and the alternatives I did not take

Chosen: one column, `text_updated_at`, moved by a BEFORE UPDATE trigger only when `text` changes; the playbook compares `researched_at` to it. Three files, five tasks, against caps of 34 and 35.

- A text hash stored at research time. It needs a column too, and it makes the Researcher responsible for writing a third column correctly. A trigger is writer-independent, which matters because the Napkin page's writer is not in this repo.
- A side table for the stamp. Every object would be new, so the captured down would be `auto-downable` instead of `refused`. I did not take it: a second table for one timestamp is a parallel structure, the due rule becomes a join in a prompt, and a new public table is born readable by `anon` (environment fact, SES-384) on a private subject. The column inherits the table's ACL, which holds `postgres` and `service_role` only. The cost is stated in the kickoff: the down is card-only, as it was for `agt543_napkin_dilbert_note` on this same table.
- Rewriting `updated_at` on the 41 rows. This is the literal reading of "re-stamp". I did not take it: `updated_at` is the Napkin page's own column and recorded a real write, Nathan's Wednesday filter reads it, and overwriting it is the one part of this ticket that would destroy information. The ticket's stated purpose for the re-stamp is "so the next run opens with the real due set", and the new column's seed value delivers that.

## The re-stamp, as designed

The migration seeds `text_updated_at` for all 62 rows: the 41 rows whose `updated_at` falls in `[2026-10-17 14:52:00+00, 2026-10-17 15:16:00+00)` take `created_at`; every other row takes `updated_at`. No existing column is written. A checksum over `id | updated_at | researched_at` for the whole table was identical before and after in the dry run. There is no before-image because there is no prior value: the column does not exist until the migration creates it, and dropping it restores the table exactly.

Residual risk, stated: if John edited the text of one of the 24 unproven rows during that pass, it will not be re-researched until its text changes again.
