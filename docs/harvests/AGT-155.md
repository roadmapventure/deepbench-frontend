## 4. Alternatives weighed

1. **A top-level `leads[]` array the model composes** (the ticket's wording "inserts a lead ... with public facts only"). 3. **Nathan's Skill rows carry the LEADS discipline** (pattern:7) instead of the routine prompt. Rejected for this cycle: it needs an agent-row seed applied over the MCP with before-images, and the ticket names the routine prompt and runbook as the homes.
