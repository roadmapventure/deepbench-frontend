## 2. The Designer's calls (JOHN-0925-DESIGNER-DECIDES; each reversible by editing the kickoff before the build or reversing the migration after)

1. **No new decision kind.** The ticket asks for "a recorded decision per ticket for placed and for turned down." `placement` (AGT-489/490) IS placed; `fit-stamp` (AGT-486) IS turned down for fit; a `not-needed` turn-down leaves arm 2 by status (`removal proposed` is neither `open` nor `partial`). Inventing a third kind would be a second home for a fact that already has one (pattern:17, pattern:93). Undo: a later ticket may add a kind if a turn-down appears that none of these records.
2. **Arm 2 reads the stamp through `victoria_charter_state()`'s `stamped`**, never a second copy of the summary-equality predicate. The fingerprint rule (a stamp lives exactly as long as the charter set it was taken under) has one home; copying it into the daily check would let the two drift (pattern:14). Cost: one extra STABLE call per check — negligible, it runs once a day.
3. **No `placement` predicate.** A moved ticket's epic is in an `executing` project, so it leaves arm 2 by scope; a parked 0 leaves by P2 (score ≠ 5) and P5 (`PARKED` reasoning); a `park` after a `no-fit` carries the `fit-stamp` P9 reads. Every extra element must justify itself against a bound that already exists (pattern:67); this one does not.
4. **No hand re-read of the ten.** The ticket's "re-read the fifteen once" is the routine's job: the weekly list run of 2026-10-20 already read the lists and wrote the 4 stamps; the ten remaining fives drain through the same door on the next run. A hand write under this cycle's name would be a board write the design never asked for (pattern:90), and the daily routine's creation and switch stay John's (d.35).
5. **A probe function rather than a one-shot gate alone.** AGT-483's closing slice (`v7.0.858`) recorded why: a migration gate that asserts the discriminator rolls away with the transaction, and the standing guard then grades the identity case only. With 0 stamped fives on the board, arm C would pass with or without P9 — so `victoria_daily_probe()` stands up one live stamp on one current five in a rolled-back sub-block (sentinel `P0516`) and returns before/after/residue, and arm E grades it every run. Zero residue by construction; nothing a parallel cycle can collide with (SES-382).
