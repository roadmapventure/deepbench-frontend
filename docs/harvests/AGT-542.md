## Why it still fits the cap

The seed is already tracked and the ruling says it is applied verbatim; applying a tracked file over the MCP changes no repo file. The changed set is therefore exactly three: the new agt-542 test and the two coupled censuses. The migration's repo mirror would be a fourth file, so per the ruling the migration text lives in the kickoff instead. A seed edit would also be a fourth file, so the ruling's 'edit only if the DO block refuses' becomes 'stop and report if it refuses' -- the build may not widen its file list, and the seed's Skill text is design content in any case. No split is forced; no cap waiver is assumed.
