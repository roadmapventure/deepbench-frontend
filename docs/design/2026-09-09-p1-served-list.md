# The P1-served list — 84 open tickets

**What this is.** The Prioritizer's first run classed every one of the **567** open and partial
tickets on 2026-09-09 (`SES-332`, cycle `a8000000`). These are the ones it ruled **serve**
`P1 - Improves John's Skills` under the served-class test (`VC-MISSION-033`): finishing them
changes what an evaluator sees or can verify on a named P1 artifact — the live Channel
Intelligence run and its reasoning trail, or the briefing page as proof of governed autonomy
(`VC-MISSION-031`/`032`).

**A served class is not the ticket's own class.** Every row below keeps the priority class it
already had — this run never overwrote one (`SES-332`'s rule; the distribution across all ten
classes is byte-identical before and after). *Serves P1* is the second, independent question:
what does finishing this change, for someone looking. Read it as a ranking input, not a promotion.

**The ask.** Skim for rows that do **not** belong. A wrong *serves P1* is the failure mode that
matters — it moves work up the order on a claim nobody checked. The class disagreements are a
separate file: `docs/design/2026-09-09-prioritizer-class-disagreements.md`.
